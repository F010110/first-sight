# V2仓库审查与整理清单

## 结论

**功能链路可以清楚定位，但工程上还不是完全解耦、可部署的成品。** V2整理首先消除入口和文档错位，不用大规模重命名掩盖耦合，不恢复已回退的通信实验。当前启动见[运行手册](../application/v2-realtime.md)，分层见[系统图](../product/v2-system-map.md)。

## 本轮已整理

- package.json与lockfile版本统一为2.0.0；新增V2发布说明、系统图、运行手册、审查清单。
- 根README／docs索引以8884实时＋8885接收为主，8880视频、8765手机明确为历史入口。
- cam README改正“当前串口固件／尚未实机Wi-Fi”等过期说明，旧实验保留历史身份。
- 维护规则把实时链路与sim评测分开；TODO顶部明确V2冻结与暂停规则，不抹掉旧过程记录。
- 增加src与web导航，指向当前与历史模块；无源码目录大搬迁，无协议／算法／固件变更。
- 当前固件／Python接收仍是53afa22基线，前端switch与只读回放分段是5469a9d恢复内容。后加持久设备诊断、Android／iPhone中继不作为V2功能。

## 核实的实际边界

|问题|当前事实|后续处理（暂停，本轮不实现）|
|---|---|---|
|实时与历史入口混杂|src/desktop含实时API、视频API和评分实验；src/agent含多代算法|按明确依赖清单再拆product／evaluation，不直接删“未使用”文件|
|src/hardware职责过多|接收适配、Session编排、SQLite、空间和QA同目录|先抽稳定接口，再移动application／storage／adapters，保留兼容与回归|
|前端与API合同|手写DOM／HTTP字段，无共享生成契约；只读回放依赖开关事件|独立schema／类型及契约测试，不能只改网页标签|
|启动不自足|npm realtime不设push／host；首次state请求才启动接收器|后续专用启动器／配置检查；V2手册明确，不暗中改回退基线|
|IP与平台绑定|硬编码Windows Python路径、默认校园IP；USB配置限制10.122|外部配置与跨平台适配；不把曾配置10.21成功等同于基线配置器支持|
|设备网络|单摄、校园AP切换／覆盖／可达性失败，没有离线图片补传|接受现有限制；未来改独立随身本地采集＋蜂窝，不继续跑路线|
|进程生命周期|接收器失败后不会自动重建；网页服务无Windows自启守护|未来监控／恢复要保留失败与预算语义，不隐式重置账本|
|资源管理|记录JPEG＋PNG＋SQLite长期增长；内存保留历史对象|容量告警、可验证归档／保留策略；禁止直接删原始证据|
|恢复／预算|历史回放可读，不代表当前Session空间状态跨重启恢复；预算是会话估算|持久恢复和全局账本另设计，不以暂停／重启清零风险|
|时间语义|push收据是host-receive-start，设备捕获时钟未对齐；有些内部字段沿用request命名|统一语义／延迟测量要另迁移schema，不重写既有回执|
|安全边界|LAN JPEG用HTTP bearer，配对及校园凭据NVS未加密|生产TLS／设备密钥与配置安全；不开放8884到公网|
|回放边界|按有效记录事件分组，不按boot；未写关闭事件可能显示“未记录关闭”|可恢复事件日志与闭合策略需独立设计，不凭最后帧伪造关闭时间|
|测试可移植性|TS部分测试依赖本机冻结校园数据，UI依赖外部Playwright／Chrome|公共脱敏fixture、分层CI、依赖说明；保留原冻结评测独立身份|
|历史文档|旧文件保留当时“当前”与后续实验计划|顶层入口明确优先级，再逐份加历史标识，不批量改实验结论|
|TODO积累|包含历史完成项及旧行动项|另做完整归档再精简，不丢未提交工作；V2冻结说明优先|

已发现`RealtimeSession.stop()`审计备注仍写旧180秒radio bound，与当前持续网络固件不符；此为历史注释遗留，非真实超时配置，本轮只记录，不扩展运行行为变更。

## 不应清理掉的内容

- `run/`的原图、请求、响应、失败、SQLite、未知计费预留和冻结分数。
- `dist/`中历史冻结构建；当前只重建dist/current。
- cam/local与设备NVS中的私有配置、现场固件备份：本轮不擦除、不导出整片Flash。
- 旧手机／串口／模拟／graph实验源文件和报告：不是默认入口，不因未使用就删。
- 未跟踪的需求PDF与此前未提交的历史缺口核查说明：保持原状，不擅自收进发布。

检查`git ls-files -- cam/local run dist android`无条目，未把本地录像、配置、APK或构建环境纳入V2源码。不能据此声称已做全仓秘密历史扫描。

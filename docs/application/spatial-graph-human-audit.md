# 63地点图：如何判断是否准确

## 现有数据能做什么

我们有851个原始三视图观察对应的**原生XYZ位姿**与10段轨迹来源，可以把冻结的63个预测地点标到真实采样轨迹上；不是根据VLM文字猜坐标。当前本地材料没有完整学校平面图、房间多边形或可用建筑mesh，因此不能把轨迹包络画成墙，也不能声称已有完整地图真值。

审核页：<http://127.0.0.1:8879/school-spatial-63-v6/>。这是`window-context-full-replay-v6`的63地点图，不是随后90题穿插回放会生成的新图。原始数据库不改，显示P1—P63只是UUID的固定别名。

页面提供：

- 原生XY轨迹，按预测地点着色；不同录像绝不连线。
- 按录像筛选及原生Z范围筛选；Z明确不是认证楼层号。
- 地点列表、观察数量、跨录像情况和空间跨度。
- 点击任意轨迹点看当时左/前/右原图、时间和模型判断理由。
- 点击“几何接近但不同地点”候选，并排对比两组三视图。
- 按地点记录“目前一致/疑似合并/疑似拆分/不确定”、相关P号与依据；本机保存、JSON导入导出，记录绑定冻结图fingerprint。

审核意见不会自动修改算法、私有标签或已冻结分数。浏览器本机记录必须导出才便于持久保存/分享。

## 哪些地方优先人工看

| 可疑类型 | 检查方法 | 不能直接得出的结论 |
|---|---|---|
| 疑似过度拆分 | 不同P号在同段低高度差且XY接近，查看原图及区域边界 | 接近不等于同一区域，墙两侧可能很近 |
| 跨段重访未合并 | 不同段在相同XY附近，核对稳定结构、开口和楼层 | 跨段原生Z受采集高度影响，不能直接判同层 |
| 疑似错误合并 | 同P号分布很散、跨层或对应不相容布局，查看每次访问 | 一个开放区域可很大，同P号多段出现也可能正确重访 |
| 边界抖动 | 同一段短距离内反复换P号，逐帧看跨门/楼梯/开放区域边界 | 旋转或物体出现不是换地点的充分条件 |
| 转换边错误 | 检查边的两端原图与中间轨迹、录像断点 | 转换边不是导航可通行保证 |

当前启发式队列：同段近距离不同地点对8组；跨段仅XY接近对221组；26个地点XY包围跨度超过20m。**这些是复核优先级，不是229个错误或26个错误地点。**距离阈值为XY≤0.75m，同段另要求原生Z差≤0.3m；跨段不假定高度已对齐。

## 推荐的人工审核顺序

1. 先单看一段轨迹，明确入口、门口、楼梯、开放大厅等可见边界。先约定“具体地点”粒度，不纠缠走廊这个功能词。
2. 对每个P号抽查首次、末次和中间转折处；再查看该P号其他访问。
3. 对同段8组近距离候选逐对标“同一具体区域/不同区域/边界可接受/证据不足”。
4. 选择几个明确重访的稳定地标，跨段核对身份与高度，再审跨段候选。先不要全局按原生Z自动分楼层。
5. 对一个P号出现不相容空间的情况标注应拆分的观察区间；对多个P号对应同一区域标注应合并的P号，而不只是“这个P错了”。
6. 对不确定/开放区域边界保留等价解释，不为了让地点数接近某个数字而强制合并。

## 有完整地图以后怎样升级

最佳形式是**同坐标系的分楼层平面图＋原生轨迹＋预测地点颜色**：

- 先验证地图与轨迹的坐标、尺度、朝向、楼层基准，必要时用多个可靠地标配准并记录误差。
- 给审核确认的房间/开放区域边界画多边形；楼梯和边界带单列。
- 将851个观察投影到地图，点击原图核对“观察者所在区域”，不按隔门可见物体归属。
- 将63地点与人工区域交叉对照，得到一个预测地点混入多个真实区域、或一个真实区域被多个预测地点拆散的表。

拿到mesh也不能直接认为mesh房间名就是任务真值：开放空间的划分粒度仍需要约定。若没有原地图，可由人工按可见证据建立有限区域草图，但必须标“人工审核草图”和不确定边界，不能当原生精确地图。

## 真正应该计算的指标

在独立人工确认区域/同地关系之后，再报告：

- 地点归属覆盖率与unknown率，和准确性分开。
- 同地点配对精确率/召回率或B-cubed聚类指标，避免只比较预测地点总数。
- 错误合并（一个预测ID跨多个真实区域）与过度拆分（一个真实区域多ID）分别统计。
- 重访身份保持率；楼层错误率（仅在楼层真值可靠的样本上）。
- 转换边是否有真实连续经历支持，另报而不是混入问答分数。
- 边界容忍带/可接受等价分区单独处理。

在此之前，63不是准确率，90题答得好也不能证明63个物理地点划分正确。

## 空间组还有什么问题

9道非满分：6道内容正确但仍缺当前证据或引用未实际inspect的ID，1道对比回答/证据不足，1道场所称谓半分，1道跨楼层错误。

仅加反馈重试，**没有完全解决引用问题**。模型仍会用其他时间的相似房间图替代当前图；部分重试把缺的当前ID写入引用却未实际inspect，照样被拦。两次尝试耗尽后保留失败，不继续重采样。原10道被修复题中还包含文字拒答/flag冲突，不都是空间错误。

因此不能把90.6分以外的全部损失归为空间算法；首先应解决输入中当前图来源与工具inspect认定不一致。可信分略降主要与新尝试非法引用被按重大风险计入有关，不等于用户实际收到更多错误答案；原始自动评分设计的局限仍需披露。

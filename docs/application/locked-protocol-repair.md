## 为什么之前反馈重试无效

不是没有重试：每题已有最多两次反馈修复。但每次重建回答流程，仍要求模型重新输出整个答案；事实、工具过程、引用和flag混在一起。比较题连续三次漏当前来源ID；模型容易把字段名`historicalEvidenceIds`理解为排除当前图。反馈虽然指出漏ID，却没有缩小模型输出空间或强制保护正确正文。

校验本身也有缺陷：非句首“我无法确认…”未被识别为flag冲突，反馈反而要求添加证据；“当前视野中未检测到抽屉”又被当作确定的隐藏内容回答。另有一题是检索调用耗尽，没有任何原答案，不是重试JSON字段能解决的。

## 本次方式

`src/sim/repair-memory-protocol-locked.ts`为独立选择性修复器，调用`locked-answer-repair.ts`：

1. 协议通过记录直接逐行复制，不调用模型；不读取标准答案，不修改原始运行目录。
2. 锁定失败记录最终原答案及其他控制字段，向模型给出公开问题、具体校验失败、原已查看来源及hash核验原图（最多3组9图）。不补取没看过的图、不开放新检索。
3. 只准输出`historicalEvidenceIds`和`abstained`两个字段。明确当前图也是有效来源，比较题两个部分都需引用。引用由VLM选择，程序不自动填充。
4. 本地只合并允许字段，再校验引用权限、明确来源齐备和拒答一致性；越权改正文、瞎编ID、假拒答和无效patch全部拒收。最多两次，失败保留原记录，不选较高分答案。
5. 正文不通顺、事实不支持或根本无答案，不允许借“协议修复”改答案。图像已查看也不等于证明内容正确；这里没有新增事实正确性认证。

修复器是可复用的开发后处理入口，**未默认替换RequestAgent线上流程或旧全量评测**。它需要输入原始来源查看记录，不能无凭据拿ID凑引用。JSON完全不能解析、没有可锁定答案的情况会明确保留失败，不声称全部协议问题均可用此法解决。

## 实测与不回退审计

源均为已完成的`*-runtime-fixed-v4`90题结果。空间输出`spatial-memory-locked-protocol-v1`；Oracle首轮`memory-oracle-locked-protocol-v1`保留，修正可见性拒答校验后仅重跑Oracle两个失败，输出`memory-oracle-locked-protocol-v2`。

|组|原最终失败|纯元数据修复|保留失败|原有效记录逐字保留|
|---|---:|---:|---:|---:|
|空间|5|4|1（无答案/检索耗尽）|85/85|
|Oracle|2|2|0|88/88|

最终6个修复均只需一次模型patch。空间4请求；Oracle最终2请求；包括保留的Oracle首轮3请求，总共9请求，公开价估算约USD0.00275。所有修复记录的正文、confidence、shouldSpeak、done等所有非元数据字段均精确相同；空间另1条无答案原样保留，故90条中86条完全相同，Oracle88条完全相同。

审计`run/school-spatial-oracle-v1/locked-protocol-preservation-audit.json`；原图hash验证和每次模型原始patch/usage均留存。4项锁定修复单元测试覆盖保真、越权/伪造/漏来源拒收、非句首拒答和视野限定拒答，另相关协议和真实HTTP工具循环测试通过。

这是**选择性开发诊断，不是新90题分数**。未重新判分、未替换88.9等v4全量成绩，也不证明oracle语义上限已校准或空间算法已可生产使用。当前结论仅为：已验证这6个元数据错误可在不改原正文、不触碰已通过答案的前提下修复；余下无答案问题需单独调查检索流程。

## 用户要求计入回退后的离线重算

`sim/report_locked_protocol.py`使用原评分公式、原judge语义credit/harm回执，核验所有改动记录非元数据字段完全相同，仅重算协议影响；无VLM调用。报告`locked-protocol-rescored-report.json`。

|三卡|空间+锁定回退|Oracle+锁定回退|
|---|---:|---:|
|实际问题解决|93.3|80.0|
|长程与干扰|94.1|75.0|
|回答可信|97.2|83.3|

空间当前/短/长90.0/93.3/96.7。空间4题原语义均满分，修正元数据后均恢复效用。Oracle两题只有1题恢复效用：抽屉题patch仍选择`abstained=false`，虽有有效当前引用而通过运行校验，但在原评分规则中不可回答题必须拒答，仍计0并有风险惩罚。因此此前“6个元数据错误全部修复”的表述只指运行校验通过，**不是6题全部恢复得分**；不能自动把flag改成true或假设加上引用就正确。

本表可称“原90题结果＋已验证协议回退的离线重算”，不能称全新独立90题测量。已通过记录及其原等级均保留，不改变原答案；修复实现还改正了两类校验误判，不是字面上仅新增重试次数。

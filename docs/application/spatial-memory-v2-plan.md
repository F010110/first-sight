# 模拟器长期记忆开发闭环

## EAM核对（2026-10-15）

已阅读`../EAM/README.md`、`具体设计参考.md`、`docs/visual-system-status.md`、`src/eam/visual_memory.py`和`controller.py`。

实际主线是SQLite帧/片段/状态/提升记录＋SHA256内容寻址媒体；固定窗口均匀代表帧，原始成员保留。查询按world/session/as-of授权，search→recover→inspect→answer；只有读过的帧才能引用，图片与轮数有预算。控制器真实模型只做了连通诊断，不能移植其结果作为本项目准确率。

借鉴：原证据优先、历史时间截止、代表→恢复、读取预算、引用校验、明确历史非当前。暂不移植：oracle room/pose/object服务、视锥检索、整个历史Python过滤、自动重试策略。EAM也没有已经验证的通用视觉相似召回；不能把其空间真值索引误称无位姿retrieve算法。

## 本轮实现顺序

1. 独立v2检索器读取v1 SQLite，不修改冻结文件/源码hash；按库、recording、服务器atMs截止检索。词项命中、时间和显式地点筛选，恢复被首末代表遗漏的原观察。无词项命中不偷换成近期地点。
2. 模拟器专用本机调试服务/面板，不接实际产品前端，不做语音或自由聊天。
3. RequestAgent工具接有界历史图片，SceneChangeAgent从同地点严格早于当前的原证据建立基线；结果保留来源，不把未知视角当确认变化。
4. `建议9.md`协议：五种会话、三同步相机、算法输入与GT分文件、建筑级划分、成本与四任务独立报告。先接已有录制，下载/渲染许可和可编辑变化必须实测后再标完成。

词法检索不等于视觉向量检索；元数据找到的图必须经模型查看才支持视觉判断。SQL条件限制返回行数/内存，但短词和reason LIKE可能扫描磁盘，不宣称亚线性延迟。建筑多会话数据不足时保留缺口，不复制轨迹冒充新路线。

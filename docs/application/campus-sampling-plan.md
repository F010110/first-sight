# 校园多会话采样草案

本轮用户授权下载无需身份验证的学校场景到D盘，优先AI2-THOR路线；不再等待MansionWorld许可澄清才下载。保留原始许可，不将下载授权解释为公开分发、云端处理授权。下载目标`D:\Datasets\MansionWorld\8dd4f01dbf78`，脚本`sim/download_mansionworld.py`固定revision并校验大小/SHA256，下载未完成不标成功。官方目前以整库zip提供场景，因此先下载场景库及patch，非全部Objaverse依赖。

## 第一道门：选出实际学校

下载完列zip目录，检查学校/high-school及其元数据；如目录没有用途标签，读取场景描述而非凭文件名猜测。建立候选表：scene ID、用途原文、楼层、房间数量、依赖asset ID、室外区域、地图和可视化抽查。先选一个中小学校主场景，一个备用；整库1000栋不是1000栋学校。

检查patch与定制THOR版本，使用独立环境和独立资源目录；不运行会覆盖现有`~/.ai2thor`/`~/.objathor-assets`的setup脚本。此前THOR5.0三摄成功只证明内核备选可行，不能保证MANSION定制版本可用。仅下载选定学校真正缺失的资产，先统计大小；不默认下载整套Objaverse。

## 第二道门：场景验收

- 实际加载，检查三摄非黑帧、纹理、碰撞、门与室内外出口，保存截图和失败动作。
- 统计可达点/连通分量、房间和室外覆盖、路线距离；记录网格精度，不把离散点数直接当真实面积。
- 校园应包含教室、走廊及可走室外区域；楼梯/楼层若靠加载切换，明确记录transition事件和录制边界，禁止当作连续爬楼或推断视觉相邻。
- 若学校只有楼内，诚实标为“学校楼内基线”，继续寻找校园补充，不把独立室外场景拼接成同一个校园。
- 环境GT标签只是初始标签；抽查门口/开放区/相似房间并允许unknown。地图只供采集规划/评测，不送给Agent。

## 五会话（继承建议9.md，不用同一视频切片冒充多次探索）

| 会话 | 真实独立采集要求 | 评测 |
|---|---|---|
| S1 初探 | 从入口访问部分区域，保留未见区域 | 初始建图、证据与路径保存 |
| S2 换路重访 | 独立seed/动作序列，不同起点/方向，与S1部分重叠 | 重访准确率、错误拆分、跨会话检索 |
| S3 相似区域 | 多间相似教室、走廊分叉；若可用再加入其他楼层/室外入口 | 错误合并与拒识 |
| S4 真实变化 | 可重放编辑脚本，先前后截图验证物体移动/移除或门状态改变；另设未变对照 | 变化准确率、过时记忆使用率 |
| S5 记忆任务 | 只查询截止前四会话的可见历史，包含不存在/未见对象问题 | Recall@K、答案/引用正确率、拒答、历史路径恢复 |

若不能编辑，S4标为未实现而非更改文本标签伪造变化；路径恢复不等于导航成功。只有实际执行可达路线并验收终点，才报告导航成功率。

## 采集与数据边界

三摄同一世界状态，front/left/right相对yaw 0/-90/+90，初始FOV90°；分辨率先做320/640质量与成本比较。原始逐帧数据和派生采样分开；采用距离/转角关键帧加低频兜底，参数由小规模试采后冻结，不以固定视频总时长限制会话。保留回访与相似区域难例，不能只选“好辨认”的图片。

Agent包：原图、源时间戳、recording/observation ID；评测私有包：真实位姿、房间/校园区域、动作成功失败、状态版本、实例ID与编辑日志。时钟包括session内源时间和跨会话逻辑时间；不能用修改图片时间伪造独立经历。沿用现有dataset packager，manifest固定源场景/patch版本、asset列表、哈希、seed、配置、来源及条款。

同一校园的五会话属于同一split，不能跨train/test泄漏；一个校园只能作为工程pilot，不宣称跨校园泛化。先小样本跑通S1/S2和重启恢复，确认后扩大；付费VLM评测单列预算，下载/运行测试不自动触发付费模型。

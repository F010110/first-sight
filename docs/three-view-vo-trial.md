# 三方向纯视觉运动原型

输入只有前/左/右时间序列图像。没有IMU，称VO而非VIO。使用已知的仿真90°方形针孔内参；真实设备需要实际标定。三方向同光心，不能作为普通立体相机估计米制深度。

每方向独立双向唯一SIFT匹配，检查分布；先检查标定单应矩阵是否符合旋转，再做本质矩阵RANSAC与recoverPose的正深度筛选。低旋转、广泛视差是移动候选。两方向支持才输出候选，任一旋转信号则跳过；其余未知。像素门槛用于拒绝几何退化，不再单独用像素幅度认定移动。

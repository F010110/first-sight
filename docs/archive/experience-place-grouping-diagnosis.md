# Experience Graph 上的地点分组实验与诊断

## 实施范围

`src/agent/experience-grouping.ts` 新增独立的派生地点层：15 个原视觉节点是不可拆的底层单元，10 个 pending observation 各自加入临时单元，共 25 个单元、40 次观测。地点组不修改底层身份、原图引用或访问顺序。重新计算分组即得到另一版可撤销解释，但尚无在线组版本/用户撤销 UI。

本轮是上一轮方案的**视觉重叠代理基线**，不是已实现全部“稳定对象关系 + 区域边界”方案：这些额外证据目前尚不存在，不能伪造。匹配数据来自重新计算的双向逐方向 SIFT；不使用旧 VLM 物体描述（门框曾被认成梯子），不使用坐标、房间、动作或运动描述做分组。

单元间分数：每个成员视角在另一个单元中找到最好的双向两方向对应，再取全体成员的覆盖下界。这样不要求两个朝向的所有笛卡尔配对都匹配，但每个视角需要某个对应。单元之间 complete-link 防止 A~B~C 无限制链式扩张。邻接次数仅作为诊断，不把时间连续当作同一区域。分数阈值为未标定的 0.25/0.15/0.1，仅作消融。

## 明确失败

W22/W23/W24 在同一端点仅换朝向，但细中档均分成三组；粗档也未合并，只把 W24 与 W25 合起来。端点坐标仅用于评价，不用于补组。

已直接查看 W21–W24 原始三视图：大片无纹理墙占据主视野，洗手盆/马桶分别只在侧边出现。W22/W23 最大匹配分数仅 0.1，另一些配对只有一方向强匹配。当前“至少两方向 + 全视角覆盖”对这种情况几乎没有依据，自然过分割。没有特征不能证明地点不同，但硬分区输出却把未知包装成独立组；因此所有组保持 provisional/scopeVerified:false，不能对用户断言不同地点。

浴室原观测 W14–W32 包含 19 次观测。即使粗档，其观测仍出现在 9 个候选组中；结合原地图像可见同一组设施反复出现，这是明显碎片化风险，尚不能用“同房间”规定全部应合为一个地点。几个非待定节点间匹配支持也严重不对称，例如 W18/W28 与 W19/W27 最高 0.55，但全视角覆盖仅 0.067。继续降低阈值会接受证据很弱的组合，不能确定活动区域粒度。

## 文档与论文复核后的判断

- 建议4：VPR/SeqSLAM 是回访识别证据，不直接定义活动区域。换 descriptor 有必要但不能替代分组关系。
- 建议5：可选聚合层仍正确，避免错误地点组破坏经历底座；它没有给出充分的分组判据。
- 建议6：强调自适应粒度/历史修订；本轮结果说明核心缺口确实是“同区域”证据，不是图存储。
- [RoboHop](https://oravus.github.io/RoboHop/) 方法页明确通过 segment 跨图像持续性和图内邻接建立连续 place sense。与本次失败最贴近：设施可在不同朝向的局部图像里接续，应该保留具体 segment/object track 和邻域，而非只用两张整图的覆盖分数。下一轮优先研究/实现 segment 持续性证据，但它本身仍不能证明区域边界。
- [e-TM](https://ink.library.smu.edu.sg/sis_research/6049) 作者机构摘要支持 episodic playback/consolidation 和 Fusion ART 模板泛化；全文不可用，不能声称已复现其算法或它保证合理活动区域粒度。ART 在相同缺信息输入下也无法自动恢复空间真值。
- [DGNav](https://arxiv.org/html/2601.21751v1) III-A/B 明确 RGB-D、欧氏距离合并和 waypoint 密度调整；不是我们的无可靠位移地点分组的直接解法，不照搬距离阈值。
- SMART 的 MDPI 全文入口本轮返回 403，未追加全文结论。

## 结论与下一项

**分组已运行，但效果未达到“合理地点颗粒度”。** 17 不是推荐地点数，只是粗档输出。零跨房间不能掩盖原地旋转拆组。

下一项应补可审计的跨视角对象/segment 轨迹和局部邻域关系，并把“有边界证据”“同区域支持”“未知”分开；首先针对原地旋转样本做验证，再对床侧/入口/设施区标注 must-link、cannot-link、unknown。不能仅按时间连续或相同物体名字合组，也不采用仿真坐标或房间 ID 做识别输入。

输出：`experience-grouping-eval.json`、`experience-grouping-inspection.html`，位于原录制目录。所有底层文件和生产记忆未覆盖。

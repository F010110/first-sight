# 历史快照：决定与不变边界（有效架构以active为准）

更新：2026-11-02。用户明确决定与实现事实分开；下述不构成付费或硬件操作的长期授权。

## 架构

- 面向视障用户的生活/经历记忆，不是机器人动作策略训练；不宣称现实安全导航。
- 短期空间Context与长期空间记忆独立；持续空间Agent维护实际状态，独立当前感知不受历史改写；独立用户问答只读空间并维护私有会话。完整契约见01。
- 用来源支撑空间判断、经历组织与历史关联；不以任意图数据库、向量库、固定地点数为目标。
- 一次访问、经历片段、物理区域、上层场所分开；同店内吧台/台球/卡座不是三家店，同一建筑不同区域不能全部合并。
- 不能以强制计数协议、题型正则、私有答案路由或逐题提示堆叠代替通用组织/检索。

## 评测

- 主评为灵活的标签驱动裁判：裁判比Agent多知道的真值是位置标注；硬聚合指标辅助；人工最终复核。标准外细节/连接/安全不能由裁判自创。
- Agent使用 `qwen3.8-flash`；裁判同版本 `qwen3.8-max-0902`。不擅自换GPT/Gemini或其他更强模型。
- 位置813帧由用户确认基本正确，不重复要求审核全部帧。细节是邻近人工关键帧时必须注明范围，不认证每帧所有物体。
- 不再继续813逐帧视觉细节造标准；废止的Max细节标注运行只保留历史。
- 标准、输入、题目与门槛先冻结；保留原15题37分支及90题原题。15/37及审计通过前不扩90题。
- 按正确时刻评估空间状态；空间评测完成后再决定用户问题测试。正常独立分支不能继承其他题答案。
- 网页三摄原图＋标注位置/细节 vs 模型最终位置/细节并排；不拿真值顶替模型位置，不伪造复杂图。实际结构存在时才展示。

## 安全/复现

- 保留原图/旧库/索引/旧服务、失败、被拒输出、未知用量预留；不同版本新目录，不能拼接有利前缀。
- 图像来源、方向、时钟、hash、实际可用时间、因果范围与引用通道必须可核验；主机时间和回放逻辑时间分开。
- 测试通过不等于模型语义正确；观察完成不等于空间建模完成；裁判有效子集均分不等于完整准确率。
- 不自动续跑/加预算/换API/重刷固件/扫描网段/推送/发布；429先记录再按用户授权调整。用户愿提供新API不等于已授权读取其他账号。
- 新用户决定如覆盖旧决定，必须在活跃文档记明覆盖范围；旧冻结实验规则原样保留，不反向修改。

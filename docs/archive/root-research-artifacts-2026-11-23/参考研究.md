
# 具身智能长期记忆：可作为 Baseline 的代表性研究

如果你们要做具身智能体长期记忆（Embodied Long-Term Memory），我建议首先关注 3D-Mem、RoboMemory、FindingDory、GraphEQA、Meta-Memory 和 HitMem。

它们分别代表了不同的记忆机制：三维空间记忆、多类型记忆、长期记忆评测、结构化场景图、语义空间检索和动态时序记忆。

这里需要先明确一个筛选标准：

真正值得作为长期记忆基线的方法，应该能够保存过去的观测或经验，并在后续决策或问答中重新使用，而不是仅仅把当前帧送给 VLM。

同时还要区分两件事：

- 长时序记忆（Long-Horizon Memory）：可以利用很长的历史轨迹，但可能在一个 episode 结束后重置。
- 持久长期记忆（Persistent Long-Term Memory）：在任务切换、环境重复访问甚至机器人重新启动后，记忆仍可使用。

目前有不少论文属于第一类，却不一定实现了第二类。

## 一、最值得优先比较的 10 项研究

| 研究               | 主要记忆表示           | 主要评价任务           | 长期记忆相关性         |
| ------------------ | ---------------------- | ---------------------- | ---------------------- |
| 3D-Mem (2025)      | 3D 场景记忆、空间观察  | 探索、空间问答         | 高：长历史空间信息     |
| RoboMemory (2025)  | 脑启发多类型记忆       | 交互式环境学习         | 很高：持续环境学习     |
| Meta-Memory (2025) | 语义与空间记忆检索     | 机器人空间推理         | 高：历史记忆检索与融合 |
| GraphEQA (2024)    | 3D 语义场景图          | 具身问答               | 中：累积空间知识       |
| FindingDory (2026) | 记忆基准及多种基线     | 长期具身记忆问答       | 很高：直接评价记忆     |
| HUMEMBR (2026)     | 人类活动习惯与情景记忆 | 预测性导航             | 很高：长期行为规律     |
| HitMem (2026)      | 分层时序 3D 记忆       | 动态环境中的检索与推理 | 很高：时空历史         |
| R4 (2026)          | 4D 时空检索记忆        | 具身问答、时序推理     | 很高：显式时间维度     |
| HERMES             | 习惯与情景记忆         | 具身检索与导航         | 很高：事件与习惯       |
| MemoryVLA (2026)   | 感知—认知记忆         | 长时机器人操作         | 高：操作历史记忆       |

其中 FindingDory 是评测基准，而不是应当与所有方法并列为同一种模型的单独算法基线。

这些工作也并非全都实现了跨天、跨任务持久化。下面按“能否拿来比较”进一步区分。

## 二、我建议优先复现的 6 个 Baseline

### 1. 3D-Mem — 三维空间记忆

首选空间记忆基线

CVPR 2025

论文： 3D-Mem: 3D Scene Memory for Embodied Exploration and Reasoning

这是与你们此前讨论的空间记忆、多视角观测、导航推理最直接相关的研究之一。

其主要特点是利用空间组织的三维场景记忆，帮助智能体在探索过程中保留过去看到的环境信息，并在之后进行推理。

它适合回答：

- 机器人经过一个房间后，还能否回答关于这个房间的问题？
- 长历史观测是否可以被压缩成可检索的空间记忆？
- 三维空间组织是否优于单纯保存历史图像？

适合作为： 3D 空间记忆基线。

但它不应被直接视为已经解决跨天动态记忆的系统。需要检查其评测中记忆是否跨 episode 保留。

论文信息可在 [CVPR 2025](https://openaccess.thecvf.com/CVPR2025?utm_source=chatgpt.com) 检索，另可参考 FindingDory 对该方法的基线评估。

### 2. RoboMemory — 多类型长期记忆

首选长期记忆基线

2025

论文： RoboMemory: A Brain-Inspired Multi-Memory Agentic Framework for Interactive Environmental Learning in Physical Embodied Systems

[论文原文](https://arxiv.org/abs/2508.01415?utm_source=chatgpt.com)

这篇尤其值得关注，因为它不是单纯将历史特征加入导航策略，而是明确研究具身系统通过多种记忆机制学习环境。

核心定位是：

- 多类型记忆管理；
- 从交互经验中学习；
- 在物理具身任务中重新使用环境知识。

适合作为： 综合长期记忆架构基线。

不过，如果你们只关注导航，需确认它提供的任务接口是否容易适配到统一的导航 benchmark。

### 3. Meta-Memory — 语义空间记忆检索

论文： Meta-Memory: Retrieving and Integrating Semantic-Spatial Memories for Robot Spatial Reasoning

[论文原文](https://arxiv.org/abs/2509.20754?utm_source=chatgpt.com)

这篇研究的价值在于，重点不仅是“存储”，而是如何检索和整合已经形成的语义空间记忆。

与仅使用 3D 地图的系统相比，它更接近具身智能体实际需要的记忆访问过程。

适合作为： Retrieval-Augmented Spatial Memory 基线。

建议特别关注它是否使用结构化对象表示、何时触发检索，以及最终向推理模块提供什么记忆内容。

### 4. GraphEQA — 基于 3D 场景图的记忆

论文： GraphEQA: Using 3D Semantic Scene Graphs for Real-Time Embodied Question Answering

GraphEQA 使用结构化三维场景图支持具身问答，具有明确的几何与语义记忆表示。

与 3D-Mem 相比，它更适合检验显式结构化空间知识对推理的贡献。

适合作为： Scene Graph Memory 基线。

它是重要的结构化空间记忆对照，但不能简单称为完整的长期情景记忆系统。

### 5. HitMem — 带时间信息的三维长期记忆

论文： HitMem: Hierarchical Temporal 3D Memory with Multi-modal Context-Aware Retrieval for Dynamic Environments

[论文页面](https://link.springer.com/chapter/10.1007/978-3-032-37435-6_3?utm_source=chatgpt.com)

这篇 ECCV 2026 工作特别值得放入对照集合。

原因是它明确将：

- 分层三维记忆；
- 时间维度；
- 多模态上下文检索；
- 动态环境；

放在同一研究框架内。

如果你们的记忆不仅需要回答“物体在哪里”，还需要回答“某个时间物体在哪里”，这类方法比静态 3D 场景图更直接相关。

适合作为： Temporal 3D Memory 基线。

### 6. HERMES — 情景与习惯记忆

论文： HERMES: Habit-and Episode-aware Retrieval Memory for Embodied Systems

[论文页面](https://openreview.net/forum?id=IkUhq9v0JX\&utm_source=chatgpt.com)

[代码仓库](https://github.com/jacobinsilico/HERMES?utm_source=chatgpt.com)

HERMES 是值得研究的另一个方向，因为它不只强调物体与空间，还考虑历史情景和习惯信息。

例如，机器人的记忆不一定只是“杯子在桌上”，也可能包括“这个人在什么时间通常出现在什么位置”。

适合作为： Episodic / Habit Memory 基线。

目前检索到公开代码地址，但仍需核对仓库中的模型权重、数据和复现实验脚本是否完整。

## 三、建议采用的评测基准

研究长期记忆时，选 benchmark 有时比选模型更重要。

FindingDory

重点评测具身智能体能否利用历史观察回答问题，明确面向记忆能力，而非只评测当前视觉理解。

适合比较历史图像、空间结构与情景检索方法。

[项目主页](https://findingdory-benchmark.github.io/?utm_source=chatgpt.com) · [ECCV 2026 论文](https://link.springer.com/chapter/10.1007/978-3-032-37086-0_13?utm_source=chatgpt.com)

OpenEQA

包含关于具身环境的问题，能够比较不同场景记忆表示的空间推理能力。

注意区分 Episodic Memory EQA 与 Active EQA 设置，不能混用评测协议。

HUMEMBR

HUMEMBR: Learning Human Routines for Predictive Embodied Navigation 关注历史行为规律如何影响后续导航。

对于研究多次观察、跨时间预测和个体化记忆更有价值。

[论文](https://arxiv.org/abs/2606.30404?utm_source=chatgpt.com)

## 四、从复现实验的角度，哪些值得真正动手？

我建议将核心方法和辅助对照分开。

| Baseline    | 对比的核心机制         | 我的建议               |
| ----------- | ---------------------- | ---------------------- |
| 3D-Mem      | 三维空间组织的观察记忆 | 必选                   |
| GraphEQA    | 显式语义场景图         | 必选                   |
| RoboMemory  | 多类型记忆架构         | 优先                   |
| Meta-Memory | 语义空间检索与融合     | 优先                   |
| HitMem      | 时间感知的动态三维记忆 | 若研究时间变化则必选   |
| HERMES      | 情景、习惯与检索记忆   | 若研究跨任务历史则优先 |
| R4          | 4D 时空检索和推理      | 推荐                   |
| MemoryVLA   | 操作策略的感知认知记忆 | 操作任务时选用         |

为了让结果更有说服力，还建议加入三个简单但非常重要的控制基线：无记忆（Current-frame Only）、历史关键帧检索（Image Retrieval） 和 固定预算的历史摘要（History Summarization）。

这些不一定是单独的代表论文，却有助于明确证明复杂记忆结构带来的收益，而不是仅仅由于输入了更多历史信息。

## 五、代码与可复现性需要单独核查

目前能明确找到的公开资源包括 HERMES 的 GitHub 仓库、FindingDory 的项目主页，以及多篇论文的正式页面或 arXiv 页面。

但我还不能确认这里所有方法都提供完整的开源训练代码、预训练模型、运行依赖和测试脚本。因此不能把“有论文”直接当作“可以立即运行”。

若要形成最终实验清单，建议以四个硬标准筛选：

1. 有可获取的代码、权重或完整推理实现；
2. 输入形式与你们的任务兼容（RGB、RGB-D、位姿、历史轨迹）；
3. 可以在同一个 benchmark 上评测；
4. 能单独统计记忆构建、存储、检索和更新时间。

特别是 3D-Mem、GraphEQA、Meta-Memory 和 HitMem，若共用统一的 RGB-D/位姿输入与 EQA 评测协议，将比直接比较不同论文的原始指标更有意义。

## 六、最重要的基线选择结论

如果你们现阶段的目标是建立一个覆盖具身智能长期记忆主流技术路线的基线集合，而不是只比较导航模型，我会先确定以下组合：

3D-Mem + GraphEQA + RoboMemory + Meta-Memory + HitMem + HERMES。

这六个方法分别覆盖三维空间记忆、结构化场景知识、多类型记忆、检索式记忆、时序记忆和情景记忆。

其中最关键的研究边界是：

它们并不全都证明了跨天、跨任务、持续在线更新的长期记忆能力。

因此，真正比较时，应把“单次探索后的记忆问答”“动态环境中的时间记忆”和“跨任务持续记忆”分为不同实验设置，而不是笼统使用 Long-Term Memory 一个名称。

这样建立的基线体系，才能真正回答你们的方法比已有具身记忆系统改进了什么。

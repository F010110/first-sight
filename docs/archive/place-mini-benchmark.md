# 简易地点评估集与分数 v1

## 目标：可复用的局部地点，不是一个房间一个节点

允许卧室分床侧和入口侧；不惩罚组数本身。要求同一个真实局部足迹旋转/返回时恢复相同身份、明确不同核心不能串组、历史观察能被定位。首批仅使用已审图的必要约束，不规定所有中间点唯一归属；边界不作强制负例。

## 冻结评估集

`docs/experiments/place-mini-benchmark-v1.json`，2户型共97观察。21对必要同地点检查（val5 19对、val4 2对），6对明确不同核心，10个历史足迹查找任务。不输入识别器。标注来自已有AI审图和实际轨迹，不是真人盲标；同端点坐标只用于评测。没有新增加API判断。

这只是开发smoke set。val4的同端点样本少，首批规模/覆盖不足以称可靠泛化评估集；必须另采“每个局部范围停留转向、原路精确返回、支路返回、过门前后停留”的新路线。至少每区3对稳定性、2对困难不同范围、2个查找任务再评留出集。困难负例应含门内外共见同物体、相似设施、开放功能区；标注人数与分歧保留。不能随机拆相邻帧制造独立测试。

## 三项0–100分

- S地点恢复：必要same对中恢复同组的比例。unknown=0，明确不同组=误拆分。
- D分离完成：明确different对中两端有归属且不同组的比例。unknown=0，同组=误合并。
- U历史查找代理：用query的组查找历史证据，必须包含指定target且不含列出的forbidden。unknown=0。这是分组查找能力，不是对象检索准确率；forbidden清单有限，不保证组内所有成员正确。与S有相关性，不当作独立信息。

每户型总分 `100 × 3 / (1/S + 1/D + 1/U)`；任何一项0则总分0，任一维度未标则不出总分。总成绩取各户型总分宏平均，防止旧户型样本多掩盖新户型失败。必须同时展示S/D/U、分母、误合并、误拆分和拒答，不能只报单值。不是“百分之多少全部地点准确”。

单例未被算法确认时保留unknown，不因为换了评分就假装完成不同区域分离。

## 本轮实际分数

| 条件/户型 | S | D | U代理 | 总分 |
| --- | ---: | ---: | ---: | ---: |
| 原算法 val5 | 15/19 | 1/2 | 8/8 | 70.3 |
| 原算法 val4 | 0/2 | 2/4 | 0/2 | 0 |
| 辅助VLM val5 | 13/19 | 1/2 | 7/8 | 65.2 |
| 辅助VLM val4 | 0/2 | 0/4 | 0/2 | 0 |

双户型宏平均原算法35.2分、辅助VLM32.6分。这里原算法是自动视觉身份/序列关联，不是人工3组区域pilot；与旧14/19不同。VLM否决后正确不同核心的端点也退回unknown，D降为0；不把零误合并当通过。

目前结论：基线不能作为可靠自动地点判断，辅助VLM没有净改善。但原观察记录/人工确认式检索可内部试用。

## 后续在线使用门槛（建议预先冻结，不是已通过）

新留出集每户型S≥90%、D≥95%、U代理≥85%，总分≥90，同时已标关键跨区域对零误合并。小样本门槛不代表安全保证；需列每项失败而不是只用阈值。边界合法性单列，不按卧室组数扣分。

还需在线前缀评测：每次只用过去帧，记录同一观测归属反复改动、错绑被撤销的延迟和检索响应时延。最终离线分组稳定不证明在线稳定。本轮评分器没有实现这些时间维度，也没有做真实对象问答检索。未实现项明确列缺失，不给100分；这两项完成前仅称离线候选质量分。

## 复现

```powershell
npm.cmd run build
node --test dist/agent/place-benchmark.test.js
node dist/sim/place-benchmark-score.js docs/experiments/place-mini-benchmark-v1.json <new-output.json> baseline
node dist/sim/place-benchmark-score.js docs/experiments/place-mini-benchmark-v1.json <another-output.json> verified
```

# 当前学校场景验收：不满足完整校园一日活动

## 结论

`public_education_4f_400_fp001#0`是教育综合楼候选，不是已验收校园。源布局4层共37房间/1576㎡，但37包含8个楼梯/电梯区域、8个卫生间以及走廊/储物区，不能理解为37个不同活动场所。平面约17×24米；可以用于楼内多次重访，不宜仅通过延长视频声称足够覆盖一天多样校园活动。

源功能：一层接待/多功能教室2间；二层办公室、备课、会议、茶水；三层教室3间；四层图书阅览、自习、讨论间。具备一定功能差异，但没有已确认食堂、操场、庭院、体育馆、多栋楼和真实室内外通路。对全部30个教育候选的room ID/type文本检查未发现outdoor/courtyard/playground/cafeteria/canteen/gym/sports/garden；这不证明几何绝无室外，却说明不能凭education目录名认定完整校园。

第一层有100种源asset ID未出现在运行metadata，主要是外部哈希资产和small_stair/toilet-suite等；metadata还有101个空assetId条目，因此不能简单通过总对象差算缺失数量，也不能排除命名/元数据行为。截图呈现基础墙地门，尚未验收教室家具。必须完成external asset加载及实例核对，不使用当前不完整版本制作正式benchmark。

## 一天活动主场景准入

优先找一个实际连续学校/校园：入口→教学→办公/图书→午餐→室外休息/运动→回教室→离校，至少包含教学、自习/图书、办公、餐饮、室外休息/运动等不同功能。这个清单是本项目提出的验收建议，不是当前场景已有能力。需要可实际执行的多路线、重复/相似位置和可验证编辑，不靠循环步行/静止等待凑8小时。

将物理空间多样性、路线覆盖、会话时钟与采样率分开报告；一天可以是有真实独立动作与状态变化的日程模拟，静止和无关时间允许稀疏采样，但禁止伪造连续轨迹或把两个独立引擎场景接成校园。每段跨层加载独立标记。无人物/课程/天气动态时明确说明只是个人空间活动模拟，不宣称完整学校生活仿真。

当前决定：保留已下载MansionWorld作为楼内辅助基线，不验收为校园主场景；下一阶段需调查真正室内外学校候选（包括已知TartanAir学校的可编辑工程/地面路线，而非仅下载预录空中视频），如现成资产达不到则明确提出替代/建设成本，不默默缩减用户目标。

# 当下／短期／跨段长期题库 v1

本文件取代“16题足以代表记忆能力”或“必须先逐帧细标全部房间”的理解。优先标注支撑每个问题的事实、来源、时间、必要证据与拒答依据；未用于任务的房间边界不作为前置工程。

## 原16题究竟测了什么

12道事实题的提问时刻都是证据帧时间+1毫秒；没有设置证据离开当前输入的条件，属于**当下理解题**，不能算短期或长期记忆题。另4道是未知信息/关机空档拒答控制，没有证据证明它们必须调用记忆。故旧题库中：12当下、4拒答控制，0道合格短期、0道合格长期题。

## 已实际构建的90题

| 组别 | 当下 | 短期 | 跨段长期 |
|---|---:|---:|---:|
| 有答案的事实题 | 26 | 22 | 22 |
| 有答案的两时刻对照题 | 0 | 4 | 4 |
| 信息不足拒答控制 | 4 | 4 | 4 |
| 合计 | **30** | **30** | **30** |

- 70道事实题使用70个互不重复的目标观察锚点，不是把原30道题改一下提问时间复制三遍。仍然只有一个学校样本、有限区域和题型，不把90题当90个独立环境或90种能力。
- **当下**：给当前三摄即可核对，作为视觉理解基线；不计为记忆能力。
- **短期**：所问证据在同一段20秒–5分钟前；实际这批范围20–140秒，当前场景标签与目标不同。
- **跨段长期**：跨episode、合成日程间隔至少20分钟，且中间至少50组观察。实际日程间隔21分40秒–3小时1分14.3秒；扣除合成关机空档后的视觉时间间隔100–1280.7秒。只称跨段长期，不称真实日级或全天移动记忆。
- 有答案的历史题共**52道**（短期26、长期26），均要求历史原图证据才能核验；当前26道事实与12道拒答控制不冒充这52道。

这里的“需要记忆”是**完成带引用核验的任务必须访问历史证据**，不是已经证明答案语义绝不可能猜中。该学校的场景/表面会重复，模型可能凭常识或当前相似画面猜中答案；实际消融尚未跑，不宣称已测得记忆增益。

### 题目示例

- 当下：当前画面是什么场所？处在室内还是室外？地面主要是什么材质？
- 短期：第N段某时刻那次记录中是什么场所／什么地面？之前那次记录与现在各在室内还是室外？第8段26秒和当前80秒是否同一物理层？
- 跨段长期：回忆更早段的指定观察，其场所、室内外、地面或典型设施是什么？较早段的那次记录与当前各在室内还是室外？
- 控制：镜头外房间里有几人、未拍到的抽屉中有什么、关机期间具体走哪条路、现实学校现在是否营业等，均不能从记录擅自断言。

当前题型仍偏粗粒度区域、室内外、地面与少量典型设施；自然找物、最后见到、完整路径规划、对象真实变化不在已完成范围。不能以题量替代这些未测能力。

## 题目所需标签，而非无止境细标

实际目录：`D:\Datasets\activity-benchmark-v1\school-memory-tasks-v2`。

- `model-questions.json`：仅匿名题ID、问题、提问时间、当前观察ID，不含答案/题型真值/位姿/目标证据位置。
- `evaluation-only/tasks.json`：记忆类别、时间间隔、合成/视觉双时钟、正确答案、必要证据集合、当前观察、任务特征、标注来源与标签索引。
- `evaluation-only/support-labels.json`：**163条支持标签**，包括所用观察的语义/源位姿记录、每道有答案题的目标属性值，以及12道拒答依据。按题ID和`supportLabelIds`即可追查。
- `evaluation-only/trajectory-map.svg`：直接用851组原生XY绘制10条路线及已审语义锚点。不同episode之间不画虚构通路；明确不是官方房间/楼层地图，XY重叠不说明同层。
- `evaluation-only/access-audit.json`：逐题检查三种输入条件下是否能取得全部参考证据，不是模型效果预测。
- `execution-protocol.json`：对照执行条件及检索/inspect权限要求。

### 能从非图像信息直接取得什么

| 来源 | 直接标注的内容 |
|---|---|
| 生成代码、episode记录 | 段号、采样规则、原始/合成时间、20分钟关机空档、记录先后；不虚构实际通勤 |
| 源metadata、原生逐帧位姿 | 相机高度、源索引、相机位置、同路线相对垂直差、路线投影 |
| 原始zip及hash | 题目证据是否确实来自该源帧，是否混图/改图 |
| 已审三摄语义与显式表面标注 | 场所类型、室内外、木地板/瓷砖、书架/课桌椅等可见事实 |

表面属性单独维护于`sim/school_activity_task_features_v1.json`，不是因为叫“体育馆”就自动推断木地板。不同路线相机高度不同，不直接跨路线用原始Z标楼层。

已核查本地源文件清单：有像素分割包条目，但当前下载材料没有官方可用的房间polygon、语义楼层图或对象状态地图；不能把自画轨迹投影当成官方GT，也不能从分割包文件名直接得到房间实例标签。现阶段利用位姿/配置得到结构与时序约束，图像只补必要的可见语义，绝不伪造源模型标签。

错误溯源按链路检查：**问题→目标属性标签→原观察/源帧与位姿→当时可访问的历史→检索/inspect日志→回答及引用**。必要标签齐全即可测该题，不要求把无关帧和所有门口边界精细标完。

## 记忆测试必须有的三组对照

1. **仅当前**：只能访问当前三摄，持久库/缓存也不能带入历史。
2. **最近5分钟**：只能访问当前与最近5分钟记录，用于区别短期与跨段历史需求。
3. **完整历史**：可检索本题截止时刻之前的已观察历史，不意味着把851组全塞入提示，也不能读取未来摘要。

三组使用完全相同的问题和答案/证据规则。历史题猜中但没有合法历史证据，不算完整任务成功。`select_inputs`及access审计已通过，实际执行器还必须把相同限制施加到retrieve、inspect和已有缓存，不能只限制提示图。

正式仍按“问题解决／长程与干扰／回答可信”三张卡展示；当下、短期、跨段长期必须分别下钻，不能用当下题的高分替代记忆分。此90题是新任务profile，不能未经适配直接塞入原六类配额评分器并假称全部能力通过。缺状态变化等能力仍明确未测；新profile的评分执行与实际三组预测尚未完成，当前不发布系统得分。

构建器`sim/build_school_memory_tasks.py`；测试覆盖每组题量、52道历史题的必要证据、70个事实目标不重复、题目支持标签齐全、长时间/干扰观察门槛、同源不同层约束、未来图拒绝、仅当前/近期条件不能取得长期参考证据。全部标签仍为源辅助AI初标，无独立人工审阅；未进行付费模型调用。

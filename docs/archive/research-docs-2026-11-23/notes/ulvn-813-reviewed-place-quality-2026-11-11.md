# 813地点级视觉复核（非标签一致率）

## 单位与证据

只读已有结果，没有重跑ULVN/VLM、调参数或修改参考。复核全部137个接受对的三摄联系图（12页），并查看5页均匀时间线及两个旧所谓漏检段的加密样本。证据和逐对归组：`run/ulvn-place-quality-audit-v1/`；可复现聚合脚本 `scripts/evaluation/score-ulvn-reviewed-places.py`。这是助手视觉审核，不是独立人工gold；时间线采用抽样，不宣称813每帧都经新人工认证。

同一实际地点多帧接受去重一次；同一错误地点关联也去重一次。一个查询既接受正确地点又接受错误地点，分别计，不因找到一个正确来源抹掉错误。站内连续移动、首次店内外移动、加油站外围连续绕行、同一电梯轿厢移动不算离开再返回。原图相同具体区域可跨视角/距离；不能只因看到共同店面合并对侧人行道与当前占据区域。

这是独立模块的地点关联质量，不是纯ULVN空库建图或完整Pi系统最终提交质量。原脚本并未输出明确“返回事件”分类，故连续/返回区分来自本次事后审核。

## 结果

本次确定的返回目标8个占据区域，找回7个：当铺门前、公园侧街段、餐馆外部、Union现金店街段、五金店门前、五金店内部、酒吧木廊。洗衣店门前返回未获同占据区域接受。**地点召回7/8=87.5%。**店内与门外是两个区域，不把两个不同商店或跨街人行道因同一地标合并；并非按标签名称计数。

地点级错误关联7组：

1. 加油站外围→当铺（575→194）。
2. 洗衣店外巷→另一砖店后室（633→303）。
3. 西侧公园街段→洗衣店外巷（679→640）。
4. 当铺侧人行道→公园/道路来源（196/198/199→149/150）。
5. 餐馆临街栏杆处→更远道路交叉口（235→129）。
6. 离开酒吧木廊后的街面→历史木廊（521/522→480/472）。
7. 石建筑侧/过街处→洗衣店门前来源（642–658→600/602/603）。

前三组明确异地/异空间；后四组是**边界敏感、共同背景但占据区域不同**的判定，逐组公开而非标签自动判错。按不认证跨占据区域原则，**地点关联精确率7/(7+7)=50.0%。**若另行忽略后四组，确认子集为7/(7+3)=70%，不能把这个子集数冒称全量成绩；更改地点边界需要独立复核，不能为了提高分数自动合并。主结果有视觉审核的粒度依赖，不声称唯一客观语义分数。

## 原因分析

1. **此前逐帧评分单位错误。** 同地点多帧未匹配会拉低逐观察召回，但不能说整个地点没找到。地点召回87.5%与旧38.52%并不矛盾，后者不是用户要的指标。
2. **双摄几何通过不足以认证占据地点。** 575→194有66/.524及60/.545的独立方向支持；633→303有88/.733和142/.643；679→640有70/.579和68/.482。三例均没有预算耗尽，故不能将其错误归因核验预算。重复砖墙/门面、共同背景、相邻但不同占据区域均可通过当前门禁；具体点分布尚未画出，不声称已确认每个错误的精确特征机制。
3. **局部域预算确实影响补证。** 返回洗衣店附近637–641没有接受；639–641均预算耗尽，640/641只检查607/608/609（偏店内来源），24次上限耗尽。641未查门前603–606；642以后才匹配到602/603，却已向其他占据区域移动，不能倒填641已识别。单方向代表探针、先查的局部域、每域前三组会限制发现；不能认为加预算就一定修复，亦未作新实验。
4. **小样本没有验证全量负例。** 已知公园、Union、五金店的成功保持；全量新增了其他场景的错误接受。旧“3个返回/7个指定负对”是开发控制，不是代表性精确率/召回率。统一旧历史目录与此前pilot目录不同，也是混杂因素，未经同目录对照不量化其影响。

结论：地点找回能力远好于旧逐帧数字所暗示的程度，但错误地点关联仍存在，不能声称整体识别可靠。此结果不能与旧VLM其他口径成绩直接比较。下一步优先独立复核4组边界敏感关联，以及相同口径VLM对照；不自动调参、付费或重跑。

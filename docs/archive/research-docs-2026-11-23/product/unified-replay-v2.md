# V2 统一回放入口

实时服务的 `/` 现在提供统一入口，真实记录与模拟样本均使用 `/recordings.html`，通过来源选项切换；历史校园样本保留在 `/campus.html`。所有页面和只读 API 共用实时服务端口（默认8884），不再要求打开8883。

模拟样本默认扫描 `run/replicacad-pilot/*/public/`，可用 `FIRST_SIGHT_SIMULATION_REPLAYS` 指定归档根目录。只投影公开观察、合成时间和独立图片；不提供 private 文件、位姿、答案或评分真值。图片读取校验 SHA-256。缺失或无效的公开包不列出，原文件保留。

当前实际样本为 `render-smoke-v3`：20组观察，每组前/左/右三张独立640×480渲染图，合成时钟0–9.5秒。使用 Mesa llvmpipe 软件渲染；并非GPU性能验证、硬件标定、10分钟生活事件或空间识别验收。v1 EGL失败、v2导航网格失败均保留；v3显式加载原数据集导航网格映射，没有重新生成导航网格。

验证：317项 TypeScript 测试通过。`scripts/testing/check-unified-replay.cjs` 使用临时端口和真实只读API，验证三视图、拖动、播放、来源切换和历史校园入口；1366×768、1280×720、1920×1080无页面溢出，无浏览器异常、POST请求、接收会话或模型调用。截图与报告位于 `run/hardware/unified-replay-ui/`。

已有8884进程未重启，以免影响当前相机预览。后端路由需在下一次正常重启服务后生效；不要把已在临时端口验证当作现有进程已更新。

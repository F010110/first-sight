## 本次原生问答修改

文件：`src/hardware/history-query.ts`、`src/hardware/realtime-question.ts`。

1. **工具契约**：可选字段省略/null统一处理。真实非空非法ID仍报错，不能静默扩大查询范围；返回错误码、有效placeIds及可执行恢复示例。模型实际提示中移除可复制的placeId伪占位符。
2. **行动闭环**：browse直接附上所选原图，而非只返回索引等模型再次inspect。重复查询保留原匹配hits，另提供明确标成探索候选的fallbackPreview，不冒称这些候选匹配关键词。重复参数错误后同样提供合法候选，避免全轮都耗在原样错误上。
3. **未建模帧可见**：按最近的已知空间判断生成只读时间邻近地点线索，让place浏览可找到附近未标注原图。此线索不写回空间分组，不证明地点持续、不合并现有groupId；图片内容仍须模型自己核查。
4. **事件邻近取证**：新增neighbors工具，围绕合法历史ID查看真实邻近采样，帮助比较人物动作/物品状态；同样受问题截止时刻和图片窗口限制。
5. **证据充分性审查**：历史肯定答案在接受前，由单独、无gold的VLM请求检查候选及实际引用原图，明确区分看过图、事件时间、人物身份、对话意图。审查不支持时把具体缺口交还Agent继续找证据或拒答；每题最多2次审查，不无限循环。

最后一项是可审计的模型审查，不是语义正确性的数学保证，也不是官方评分器。仍可能漏判/误判，必须保留理由与实际基准结果，不能宣称“审查通过即事实正确”。本轮不偷偷增加音频或人名映射，不改空间建忆。

不能将这些数字解释为检索取证设计已经可靠：

- 通过审查的第2/3题都答B，但标准答案分别C/D。审查者把当前/较晚桌面中的物品存在，误当成问题所问的此前位置；第2题还在没有身份映射时自行把黑衣人物认作Shure。说明**独立VLM审查也会重复同类幻觉，不是可信语义证明**。

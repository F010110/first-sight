# 手动轨迹记录器

2026-10-30。用户授权下次进入游戏自动记录自由移动，以获得地图坐标而不是依赖记忆系统自主导航。

已部署`first_sight_manual_route.lua`，并写入一次性`garrysmod/data/first_sight/manual_route_armed.json`。只在本地单人`rp_unioncity_day`的下一次InitPostEntity后启动；不启动游戏、不注入OS输入、不控制运动。进入时恢复鼠标操作并关闭自由光标覆盖。当前已过Lua语法检查，尚未实际游戏验证；不要提前自动启动游戏消耗一次性标志。

- 约10Hz记录人物脚底/眼睛Source XYZ、视线角度、速度、落地状态、移动类型和仿真时间。
- 按键位变化时记录按钮掩码、移动指令及视线目标实体；不证明交互成功，不保证记录每次运动指令变化，不能宣称精确输入回放。
- 启动时导出客户端可见实体的坐标、朝向、包围盒、类别、模型、会话实体编号及地图创建ID。该清单不包含完整静态几何，也不证明可达性；地图ID也不是自定义物品跨存档UUID。
- 上限20分钟、32MiB，`fs_route_stop`可提前停止；`fs_route_mark label`记录命名位置。输出`garrysmod/data/first_sight/manual_route_日期_时间_帧号/`，记录文件为`.jsonl.txt`；正常退出写summary，崩溃可能只有部分已追加记录。
- 此版本是坐标/轨迹记录，**不录制图像或三摄视频**，不上传、不调用模型、不触碰8884，不重复录制后续游戏会话。再次录制需重新布置标志。
- 32MiB为本轮追加数据上限（少量metadata/summary另计），没有游戏内可用磁盘查询，因此并非20GB自动储备监视器；部署时应确保磁盘足够。

下一步等用户自由走动后读取输出，生成俯视轨迹及实体散点图，并标出楼层和门；再建立局部可行走图。还未实现自动复走。离线BSP原始实体清单在`run/gmod-unioncity-route-feasibility-v1/`，2856个实体、297个门类实体；这些数量不是住宅或可用入口数量。

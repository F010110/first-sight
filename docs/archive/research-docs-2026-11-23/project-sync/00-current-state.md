## 当前主线【决定＋已实现最简版本】

**固定版视觉识别地点 → 程序将位姿通行经历存入拓扑 → 程序定位后检索正/反向路线 → 独立Agent写历史路线语言并缓存到边上。**

- 位姿不送地点识别模型；不要求VLM重算已经由位姿知道的几何。
- 默认可反向复用轨迹，显式单向例外；反向说明单独生成。
- 序列保存原始经历；图组织地点与通路，两者并存，不二选一。
- 面向视障人类，自然语言输出，不做机器人控制或动作策略训练。

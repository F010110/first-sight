# 产品目标与决定

## 核心目标【用户决定】

面向视障用户，记住“曾怎样从一个地点走到另一个地点”，并将可检索的经历解释为自然语言。产品输出不是精确坐标/完整轨迹，也不是机器人速度、waypoint或action chunk。

精确位姿可作为内部已知证据；当前实验先假设理想位姿可得。现实产品是否能获得足够可靠位姿仍未解决，不能把实验假设当硬件能力。

## 最新分工【用户认可】

|角色|负责|不负责|
|---|---|---|
|固定版地点识别|当前原图与历史原图的地点身份候选/不确定|不根据位姿代答，不计算轨迹|
|拓扑/几何程序|保存位姿变化、路线检索、反转、角差、连续性|不凭同名地点瞬移，不把直线距离当可走路线|
|路线说明Agent|把已计算运动事件＋原图变成语言，缓存边描述|不重新选路径/决定左右，不把语言流畅当事实正确|

同一地点有多个到访位置和朝向；边必须保留实际端点及地点内运动。路线可逆，但不是今天安全可通行的保证。相机朝向不等于人体朝向。

## 已覆盖的旧决定【历史，勿照旧执行】

1. 曾暂停数据集扩展及固定算法耗时重跑；后续用户明确重新授权完成Tartan题集、流水线和最简评测。这不是恢复无界扩样或原6轮批次。
2. 曾做“理想pose粗化给VLM”的独立序列原型；用户指出没有图、没有正确朝向输入，不作为当前主线。
3. 曾让VLM算角度、选图上路径；最新改为程序负责。
4. 曾把无显式反向边视为必须拒答；用户明确认为可反转，应在新版规则下允许，不修改旧冻结成绩。
5. 不再把“图不如序列”当确定结论；旧实验存在多种混杂因素。

## 持续约束

- 保留原片、失败请求、费用账本、冻结输入/答案和历史版本；不拼接成功前缀冒充全片。
- 标准答案先于推理冻结；不能预测后再说没标注，不能用预测制造真值。
- 独立`research/`不修改；不删除不熟悉的工作。
- 不自动提高调用额度、自动续跑或重新发布版本。
- 统一8884入口与一个模拟回放选择器；前大、左/右小且上下排列。
- 记录/模型默认关闭；普通预览RAM-only；凭据与固件私有备份不公开。
- 优先现有材料与现成环境，不重新造低细节程序校园。
- 人类记忆/具身智能是设计直觉，不宣称已证明认知机制或论文首创。

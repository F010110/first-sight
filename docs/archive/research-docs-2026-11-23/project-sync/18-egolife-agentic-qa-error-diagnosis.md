# EgoLife原生Agent问答第二轮：错误原因诊断

## 结论

第二轮3/10的主要问题不是已经证实的“VLM看到了正确证据但理解不了”，而是**工具参数兼容缺陷、时序/地点检索失焦、缺失音频及人物名字映射、证据不足仍作答**。这些问题叠加。

本次仅使用已保存调用、官方标注和本地图像做事后只读诊断。没有改生产算法、没有新的付费调用、没有改动原始评分。官方target_time仅用于本报告诊断，未交给推理系统。

## 1. 明确的软件bug：可选placeId为null，整个查询被拒绝

第2题（马克笔之前在哪）14次search都带`placeId:null`。当前代码将`null !== undefined`判为“提供了placeId”，进而要求它必须是合法字符串ID，抛出`Unknown placeId`。

**所以这14次不是词法检索无命中，而是根本没有执行成功。**模型一直收到同一参数错误，却没有去掉null；最后只看了11:35:00当前图片，回答“客厅桌上”。正确标注位置是“二楼桌上”，时间11:24:44.08。

第4题还曾把提示词示例的`placeId:"可选精确ID"`原样填入，额外消耗1轮。说明目前用自然语言示例描述可选字段，既有nullable兼容缺口，也有示例占位符被照抄的问题。

需要纠正17号报告中的粗分类：第2题的14次search不能简单归因于重复空检索。应优先修复工具契约兼容，并给出能实际恢复的结构化错误。

## 3. 证据已经归档，但检索没有可靠地找到它

对照所有10题，归档中距官方标注时刻最近的采样图都在1秒以内。**这证实标注时段附近有原图，不证实单帧必然包含完整事件或对话。**2秒采样仍可能错过短动作，标注时间本身也未必精确到决定性画面。

7道错误题中，除了第3题曾看过距标注时刻约7.9秒的楼梯图，其余6题实际看过的图片都距标注时刻超过30秒。具体最近距离：

|题ID|实际看图距标注时刻的最小距离|
|---|---:|
|2|10分15.9秒|
|3|7.9秒（楼梯图，不是目标桌面）|
|4|8分9秒|
|6|50.2秒（仍缺语音）|
|8|23分52.9秒|
|9|26分49.2秒|
|10|14分34.1秒|

问题不只是“关键词是否搜得到”：

- Agent有时改用了browse，却仍inspect当前图，而不是浏览返回的候选图。工具可用不等于模型正确使用。
- 地点browse只检索被空间模型实际标注的稀疏帧，不自动涵盖该地点附近所有未建模原图；模型需要主动转为时间范围浏览，但本轮没有稳定完成这一步。
- 同一会议空间出现多个scope/groupId，且有名称范围差异。按旧组ID搜索晚些时间可能得到空结果；本轮可观察到这种现象，但没有独立地点标注，不能把这些组直接判为错误拆分。
- “之前放哪里”“谁帮谁”“最先写会议记录”需要事件和时序证据。地点概览提供的是导航线索，不是事件索引，也不能代替物品状态/人物动作关联。

## 4. 输入缺口：音频与人物名字

错误题6、8需要音频；正确题5同样标注需要音频。本次输入没有音频或转录，不能用“多看几张图”补回谈话内容。第5题选项匹配也不能作为对话理解能力通过的证明。

实际查看发布版原图：画面顶部有`A1_JAKE`等佩戴者/时间标记，人脸有模糊处理；**不能把这些标记理解为已给Agent所有参与者名字**。本轮没有额外人物名字到视觉对象的映射。人物参与类问题因此还有独立身份识别输入缺口，不能简单归因于模型看错脸。

## 5. 最后的证据门仍太弱

目前自动验证的是：引用ID存在、早于问题、原图确实交付过。它**没有验证图中是否真的有该事件、能否证明时间先后、能否建立人名关联**。

因此松开形式上的“先search命中”门后，旧版10次拒答变成10次有效选项，并不意味着10题都有充分证据。第9题用11:10图支持11:36整理花的人物组合，第10题用12:17静态画面证明11:26谁最先书写，都是明显的证据错位风险。

这轮结果更准确的说法是“3个选项匹配，回答流程已打通”，不是“3题已有验证充分的事实证据”。不另造一个人工调整后的分数。

## 6. 建议修复顺序（本报告未执行）

1. **P0：工具契约**。null/省略一致处理；去掉可复制的伪ID占位符；结构化schema及真实可用ID约束；参数错误后避免继续原样调用。补实际失败样例测试。
2. **P0：检索行动闭环**。记录待验证假设与已查时间范围；空搜后切换地点/时间策略；browse结果要转成实际候选查看，不再反复inspect同一当前图。不是靠继续放大轮数解决。
3. **P1：事件时间定位**。地点候选 → 对应时间段的全部归档帧 → 粗到细邻近帧/短序列取证；“之前/最先”必须比较状态或动作，而不是看见对象就回答。
4. **P1：证据充分性与拒答**。区分“这张图看过”与“这张图支持该答案”；缺动作、名字映射或对话就承认不足。优先减少无依据肯定回答，而非追求零拒答。
5. **输入轨单独处理**。若要测完整多模态EgoLife，需显式接入音频/人物身份信息并另立输入版本；不能暗中加转录或用gold附近证据抬高现有RGB轨成绩。

没有证据支持此时先更换大模型、下载更大模型或移除取证约束。应先消除确定的软件缺陷，再做受控定位实验。

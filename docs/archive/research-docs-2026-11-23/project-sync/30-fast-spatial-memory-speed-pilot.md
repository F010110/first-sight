# 快速空间记忆：联合更新和小样本速度对照

2026-10-31，用户批准提速方案后实施第一阶段，未替换8884服务、未改现有实时入口默认行为。

## 改动

- `spatial-json-vlm.ts`增加每请求`timing.json`，记录准备、每次HTTP响应头等待、响应体读取、总耗时及成功状态。非流式HTTP响应头等待包含服务端可能已完成的生成，**不是TTFT，不能区分排队/prefill/decode**。未更改模型、提示词或生成参数。
- `fast-spatial-memory.ts`提供独立实验类：一次请求联合输出当前可见事实和地点候选；最多最近1＋视觉2候选，每个仅1代表观察，三摄最多12图。所有原始输入由外部存档。代表视图匹配不冒充全成员检查，不把候选直接追加为已确认成员；未决核查按地点去重，上限8，溢出计数。
- 新的有界worker：普通更新仅保留最新1项，重要证据队列最多4项；合并后按输入顺序执行，记录替换/溢出，失败不偷偷重试。采集方必须先存原片。当前更新不可取消时停止会等当前请求返回。
- 图像描述子触发器：变化阈值/10秒心跳/显式重要证据；它不是房间边界或物品事件识别器。小物体事件仍可能漏检，尚未实现自动重要事件检测。
- 固定入口增加`--front-only-diagnostic`，仅用于对照，将模型图像和检索特征都投影为真实前摄，绝不复制单摄成三摄。`SpatialCandidateRecall`增加显式1/3视图参数，默认3保持原行为。
- `run-fast-spatial-pilot.ts`是最多8观察/8调用/USD0.15的候选生成试跑；不运行深度核查，不是完整助手。

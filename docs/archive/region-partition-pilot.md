# 建议7证据图分割首轮试验

后续原图/实际逐步轨迹核验见 `docs/archive/region-partition-actual-review.md`。重要纠正：撤除W24后分成马桶/洗手盆两组不是更合理的功能划分，它错误拆开同位置转向的W22/W23；11次未知也并非全在门槛。原输出同位置覆盖14/19，床侧粗范围合理，其他范围和覆盖仍有缺陷。

## 实际完成与未完成

新增 `src/agent/region-partition.ts`：带正/负/未知关系和帧来源的证据图，用 greedy additive edge contraction 近似优化 multicut 的关系违约成本。不是精确求解器，不是 RoboHop/Prior-SG 完整复现。未知边零成本；无支持的单观测保留 unresolved，不成为已确认新地点。重新运行即可修订派生归属；不修改原观测、视觉身份和路径，不授权导航。

本轮**仅是人工证据注入的机制试验**。直接查看 W1–W40 原始三视图缩略汇总，根据设施及开口的具体布局提出软关系，来源明确为 `assistant-manual-image-layout-review`。没有自动 SAM mask、对象轨迹、几何估计、旋转检测、边界穿越检测。区域结果由这些人工假设驱动，不能称自动分组成功，不能将同一批假设作为独立评测真值。没有使用模拟器坐标、房间 ID、动作标签、图片分数或旧视觉节点分组。

## 消融和问题

- 移除所有 W24 证据：4 个候选、12 次未知。设施区拆为 W16/W17/W19/W23/W25–W30 和 W18/W20/W21/W22，W24 未知。说明两侧聚合依赖单个桥接观测；没有足够的证据冗余。
- 只保留 unknown：0 候选、40 次未知。没有用时间连续、图不连通或检索失败凭空创建地点。
- 基础试验 objectiveCost=0 仅表示满足手工关系，不是精度100%。缺少负证据时，一个正关系链可能全部合并。图分割器无法凭空生成细区域边界。
- 当前粗设施区可能掩盖洗手盆/马桶两种活动区域；任务聚合和局部范围核验尚未实施。

## 下一步门槛

### 继续验证：求解器与证据鲁棒性

`src/sim/region-partition-stress.ts`，固定种子7109，输出 `region-partition-stress.json`：

| 检查 | 结果 | 解释 |
| --- | --- | --- |
| 100次节点/证据输入重排 | 原始证据下0次变化 | 仅当前图稳定；不能推广到冲突图 |
| 单条正证据逐项撤除 | 27次中16次分区变化 | 证据冗余不足；变化不一定是误分，但不支持稳健性宣称 |
| 台面—床侧假桥，权重0.25/1 | 未合并，记录冲突 | 低权重假桥被现有证据压制 |
| 台面—床侧假桥，权重3 | 错误跨范围合并，并切断W3/W4支持 | 强错误证据可重排归属，不是单纯把两个整组拼一起 |
| 200张6节点合成有符号图，穷举精确分区对照 | 19张贪心非最优，最大成本差3 | 近似求解器存在局部最优；不是区域识别错误率9.5% |

因此上一轮3个粗候选没有得到更强的有效性证明。完整流水线仍不可称可用。下一轮应优先自动证据与独立标注，同时给出小图精确参考、修复/拆分能力和多解歧义诊断。不能通过把所有边界升级硬约束来掩盖问题：边界检测本身也会错。

复现：`node dist/sim/region-partition-stress.js run/sim/multiview-val5-clean-20261007`。原试验结果未覆盖。

当前试验没有完成用户要求的自动算法链。下一项应获得真实连续视图，产出带 mask/帧引用的 tracklets、可信运动类型与边界候选，再把这些自动证据接入同一求解器。现有端点可用于分割器机制试验，不能当作已验证跟踪数据。需要独立人工标注检验结果，而不能用本轮证据生成的分区当真值。

验收必须检查纯旋转、小移动、门口停留/穿越、同房间不同活动区、相似不同区域。还应比较 greedy 解与小图精确解、输入顺序敏感性、桥接错误注入和证据撤销。

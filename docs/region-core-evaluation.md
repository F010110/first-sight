# 核心区域优先评测（宽容边界）

用户本轮确认：边界点归到相邻内部可接受；优先防止不同区域核心被合并和同一区域核心被拆开。该标准替代此前局部范围审查的严格验收口径，但不改写历史评分。

## 先标区域，再看算法

评测员看原图、实际路径和中间帧，为所经过的范围标区域核心、边界带、无法判断。区域编号不由room ID或算法组号生成。房间内若没有明确功能/结构分离，不强迫拆成多个区域；朝向不定义区域。

每个区域应有至少两个不紧贴边界的核心观察，尽量含反向重访或旋转。边界带列出允许邻接的区域，如入口允许A/B；无法确定时记unknown，不硬设边界宽度或距离阈值。只有一个核心观察的候选区域不能评内部碎裂，须补采。算法不能读取这些评测标签。

## 三项主检查

1. 串组：同一预测组含两个不同人工区域的核心。逐个列出冲突核心帧，不让大量正确邻近对稀释错误。
2. 碎裂：同一人工区域核心落到多个已支持预测组。核心未归属另外记漏覆盖，不算明确碎裂。
3. 覆盖：已归属核心数/全部可确定核心数，以及有核心未恢复的区域数量。全unknown可不串组但不能通过。

边界观察归到允许邻接区域不扣错；归到不相邻区域仍错误。边界成为单独连接候选可保留，但不得使任一区域核心碎裂。不得先看输出再缩减核心集合。

报告区域清单、每区核心数、覆盖率、串组/碎裂见证、边界合法率；不把选定关系对的88%当环境准确率。需要总体单值时，可在完整核心标签上补充B-cubed precision/recall，并同时报告覆盖；当前尚未实现该区域级评分器。

## 覆盖率试验

现有人工证据partitionRegions没有识别置信阈值：unknown边权为零，没有候选关系。降低边权不会把未知变成支持关系。下一轮只能针对有可审查证据的候选同区域关系试宽松档，记录来源和置信依据；严禁把时间相邻或未检测到门当same。

固定严格/中等/宽松三档，在开发集选档，在新户型不调参。每档比较串组、碎裂和覆盖；宽松档仅在未增加核心串组且覆盖改善时推荐。人工补关系必须标人工证据对照，不能算自动算法效果；评测员判断不得回填识别器。

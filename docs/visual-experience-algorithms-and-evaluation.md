# 视觉经历算法与多维评测 v1

## 后续功能不回退修复

此前v1表中的“新链路0覆盖”仅为独立新增层的拒答结果，不应替代原系统有效输出。现由 `visual-experience-memory.ts` 组合旧关联与新时序解释；新层未知不清空旧地点、对象历史检索、轨迹、拒绝历史或修订。整个关联bundle和解释历史一起保存，显式修订保留原始观察。

最新 `visual-pipeline-v3` 主输出保留val4 22/57、val5 30/40个已有视觉身份（38.6%/75.0%已关联观察；不是确认物理区域准确率）。原小基准20.0/71.6及全部分维数值未变，原错绑也仍存在。回归验证逐项比较完整旧bundle；见 `docs/experiments/visual-memory-regression-v2.json`。

新增自动弱变化批次切分器检查持续视觉低对应与VO稳定移动，允许形成候选批次但不声称穿越。当前两录制仍0新提案。可靠物理边界跟踪器仍未完成。因此兼容修复完成，不等于所有算法不足解决；下面v1成绩作为失败历史保留。

## 接入范围

完成独立实验回放链路：三方向RGB → 三方向VO缓存 → 严格时间窗口聚合 → 连续性/穿越状态机 → 候选片段 → 多锚点历史匹配 → 可修订存储。未替换生产Place/Space、Experience Graph或RequestAgent。

**这不是完整自动地点识别已经完成。** 自动门/开放区域边界跟踪器仍缺失。状态机可消费独立轨迹证据（合成集成测试覆盖），实际回放没有这种证据，不能把VO移动伪装成穿越。因此当前全链路产生0边界、历史身份全部未知。

## 已实现算法整理

|模块|方法|状态|
|---|---|---|
|三方向VO|双向唯一SIFT、单应旋转检查、本质矩阵RANSAC/正深度、两方向低旋转视差支持|已接实验回放；非VIO、无可信尺度|
|方向补偿|设备—相机标定轴系，预测射线旋转，广泛静态轨迹残差|独立可选实验；纯图像VO主条件不使用传感器|
|连续性|时间排序，VO连续候选聚合；unknown/旋转不当静止|已接；整个窗口至少两个相邻步骤全支持移动才给窗口运动支持|
|跨越状态机|同一边界轨迹接近→移动支持穿越→后续至少两观察确认；退回/超时/断档重置|已接机制；自动边界证据生产器未实现|
|经历片段|可修订切点、原图不变、时间边不授予导航|已接|
|历史匹配|多锚点匹配、结构支持、历史根竞争、矛盾拒绝|已接；无边界时不能把整段当已知物理区域|
|持久化|原观察与解释修订一起存储，原子保存，撤回保留历史|已接|
|原视觉基线|图像对应与邻近序列支持；正几何补充另作派生提案|保留对照，未被新流程覆盖|

VLM自动否决与严格几何替换此前失败，不采用。新链路也不声称视觉几何总可靠。

## 评测集整理

当前端到端集：val4 171实际帧/57观察窗口，val5 121实际帧/40窗口，每帧前/左/右图，共876图片。算法只读图片、顺序及缓存视觉证据；GT动作仅评测使用。AI审图边界分别6/5事件，语义标签非真人盲标。冻结图片hash在 `docs/experiments/visual-pipeline-dataset-v1.json`。

扩采集：3户型6相关录制2526帧，72个候选切换窗口经AI审图；稀疏前视图Oracle回访成绩仅单独作诊断，不和当前三视图流程混为同一评测。核心/子区域完整标签仍未冻完。val3保留为场景留出，不调参。

## 重跑

1. `python sim/three_view_vo.py <录制目录> <新VO输出文件>`（当前回放读目录下固定 `three-view-vo-v1.json`）。
2. `npm.cmd run sim:visual:pipeline -- <录制目录> <新输出目录>`。
3. `npm.cmd run sim:visual:scorecard -- <新报告文件>`（v1固定读取两套 `visual-pipeline-v1` 输出）。
4. `npm.cmd run test:visual-pipeline`；`python sim/test_three_view_vo.py`。

报告数值/算法hash：`docs/experiments/visual-pipeline-scorecard-v1.json`。各维度分母独立，不合成一个掩盖缺模块的总分。下一步首先补自动边界证据，不先调VO阈值。

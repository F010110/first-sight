# 区域分组：换方法还是训练？

2026-10-10，结合建议3–7、已核查论文与实际图/轨迹诊断。

## 判断

**还不能把当前缺陷归结为成熟算法上限。** 当前主分割试验的输入是人工软布局关系，自动对象轨迹、边界和局部结构尚未实现；greedy multicut只是求解近似。缺少“附近还是远处”的证据时，换更好求解器或训练都会面临输入不足。

推荐：先实现预训练感知 + 结构证据，再对照概率语义分区方法，最后根据独立验证失败类型决定是否训练小模块。暂不从零训练大模型或端到端整图Place ID分类器。

## 哪些研究更充分、更直接？

### 1. Prior-SG（2026预印本）：最直接的功能区域联合推断

[原文](https://arxiv.org/html/2608.06170v1)，本轮复查V-A、VI、VII、结论。不是仅凭摘要。

- 物理实例图与语义先验图分离；视觉、几何、具体对象、环境先验作为置信度加权专家，MRF联合推断。缺失某一模态时其权重可归零。
- VI-B使用alpha-beta swap进行图割标签优化，不是当前只能做正收益合并的求解器。VI-C按同标签诱导子图的连通分量生成不同区域实例；相同“走廊”标签不必是同一个区域。
- VII对HM3D、TartanGround、CODa、内部车站集报告几何/语义P/R/F1/mIoU，并做对象、几何、拓扑专家消融。相比我们单录制/人工关系，对区域研究与评测更完整；论文自报结果不是我们的纯RGB性能保证。
- 局限：RGB-D、Hydra自由空间图、3D对象关联与空间距离是基础。每步全图优化的固定预算在线部署仍被作者列为后续工作。LLM先验可能错，不能把“厨房通常邻接餐厅”写成观察事实或可走路径。
- 训练：使用现成基础模型与推断规则，不要求我们先训练自己的区域网络。采用其融合/优化思想仍需重做纯RGB证据映射，不等于完整复现。

### 2. Clio（2024）：颗粒度目标和在线聚合最明确

[原文](https://arxiv.org/html/2404.13696v1)，本轮复查IV、V、VI-C、VII。AIB按任务信息损失合并相邻空间单元，提供增量版本。不同任务列表可改变空间抽象粒度，不靠图片匹配阈值定义地点。

对多个真实环境进行区域评测，并明确报告公寓过分割、语义相似相连区域欠分割；使用平均多视角特征也不是万能。继承CLIP的提示敏感性，两个实体任务相关性相似时仍可能过聚合。系统依赖RGB-D/位姿与Hydra，无法直接给我们的无定位视频提供邻接图。

训练：作者称zero-shot，先复用已有编码器即可；任务压缩不能删原始经历，也不能让任务改变底层历史身份。

### 3. OSG Navigator（2025扩展版）：输入约束最接近我们

[原文](https://arxiv.org/html/2508.04678v1)，本轮复查3、4、5系统和表示部分。仅要求RGB，不用ground-truth定位；Objects、Places、Connectors与可选Region分别表示。图像解析、状态估计、更新分模块，利用对象及邻域描述作为关联上下文，提供概率映射扩展。

有模拟和Fetch/Spot真实机器人ObjectNav研究，系统不只是一个聚类函数。但成功率主要评价找物导航，不直接证明我们的床侧/入口Place分组正确；schema的家庭例子多为房间级，需适配局部活动范围。LLM状态估计仍会错误，不能把其输出自动升为身份事实。图连接不能从语义常识或时间边直接获得导航授权。

训练：复用预训练VQA/检测/LLM/GNM，没有必要先端到端训练新的地图网络。对我们优先借鉴Objects/Connectors显式建模，而不是重走“让VLM单独决定same/new”的旧路。

### 4. RoboHop（ICRA2024）：低层结构证据首选参考

[原文](https://arxiv.org/html/2405.05792v1)，既有核查见 `place-grouping-literature-review.md`。segment对应、邻域图和上下文聚合适合替代无结构的整图关联；但它不是Place区域分割论文，纯旋转结果主要是定性实验。强制补边和重复对象错配风险不能照搬。

可以配合[预训练SAM2](https://arxiv.org/abs/2408.00714)生成视频mask轨迹（SAM2为补充低层工具，不是地点算法），加上局部运动与开口事件再向上推断。mask持续性不保证物理实例回访、观察者位置或可通行性，需验证。

### 其他方法

- **Hydra/Bao2025**：几何空间/房间分割基础更充分，但依赖局部地图、深度/定位，且门边界不能处理所有开放功能区域。不符合直接无全局几何移植。
- **COVISMAP**：多观测共视地点模型和不确定性处理有用，主要是回访识别而不是活动区域语义。
- **From Entities to Areas（2026）**：[摘要](https://ltu.diva-portal.org/smash/record.jsf?pid=diva2:2054125)明确3D实体图的label propagation区域聚合。本轮出版商全文403，不能声称其超参数、消融或可修订能力已核实，暂不据此优先替换。
- **e-TM/Fusion ART**：经历回放/泛化值得研究，但现有核查仅摘要，不能因为带神经网络就推断需要大规模训练或能修复我们的旋转分割。

## 下一轮方法对照，尚未执行

固定同一自动证据底座后比较：

1. 多视角对象轨迹/开口/局部结构 + 改进multicut，支持拆分、局部重分配和小图精确对照。
2. 同底座 + Prior-SG式置信度融合与语义MRF，用可拒绝软先验、unknown及实例分离。不要未经检查就照搬图割条件或声称全局最优。
3. 另外加Clio式功能任务抽象，独立于物理区域实例与原始路径。

比较的不是节点数最少，而是原地转向一致、小移动一致、过门定位、通道覆盖、不同相似区域误合并、区域修复时延和对象检索准确率。必须看原图/轨迹，不能只报告objectiveCost与稳定性。

## 什么时候训练？训练什么？

先按房屋/场景/录制划分训练、验证、测试，不能随机拆邻近帧。当前一个40观测折返录制不够，也不能用我们自己的人工证据生成分区作为监督真值。位置标签仅做几何事实/纯旋转评价；活动区域same/different/unknown及过门事件要独立标注，并保留细中粗/重叠解释。

| 在留出集确认的失败 | 优先动作 |
| --- | --- |
| masks或对象轨迹经常失效 | 先试现成视频分割/跟踪，再考虑针对性微调；不要训练整个区域链补偿错误输入 |
| 对象/结构证据正确，同区域/跨边界权重仍误判 | 训练小型时序关系/边界模型或校准器，输入轨迹与布局，输出同区域支持、边界事件及unknown；不是图片余弦分类 |
| 边权正确但分区成本/结果不好 | 改求解与纠错，不训练感知模型 |
| 哪个对象被看到决定Place | 改观察者范围建模与旋转约束；W22/23/24、W18/28就是反例 |
| 遮挡或断档根本不可观测 | 拒答、补观察；训练不能凭空恢复事实 |

没有统一“多少条数据就够”的承诺：用跨场景学习曲线、概率校准和拒答覆盖曲线决定。重点收集原地转向、短移动、过门/门口停留、开放活动区、相似设施/房间、遮挡与动态对象的困难负例。视频模型训练若用连续模拟过门标签，仍须做真实手机视频域外验证。

**推荐决策：先补齐并换成结构化自动证据链，优先对照Prior-SG式推断；训练作为有明确误差归因后的工具，不把当前原型失败当作必须训练的证明。** 这份文档是研究建议，本次没有安装/训练/部署新模型。

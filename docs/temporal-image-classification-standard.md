# 时间图像识别归类正式标准 v1

本文件取代之前“三能力”“必须同组事件”等口径作为当前正式标准。仅使用一个人工区域标签，不再引入额外层级。人工标签只进评分器，不进入算法。

## 最终分组

- **错合并率**：人工标签不同的已审核图像对中，被放到同一组的比例；同时列混合组数/原图ID及未确定对数，不可只看低百分比。
- **同区域聚合率**：人工标签相同的已审核图像对中，被放进同一组的比例。
- **每区域组数**：同一区域可分成多组；分散是允许出现的错误，记录聚合率和组数，不单独否决算法，不强制唯一组。
- **未归类率**：已审核图像中组为null的比例。全unknown不能因错合并率为0而通过。

## 新图到达时

必须保存每张图到达后的实际前缀，评分时不能用最后状态替代首次决定。根据到达前的历史分组区分：

- **旧组识别率**：已有同人工标签的历史组时，归到正确旧组的次数/该类图像数。
- **新组建立率**：尚无同人工标签的历史组时，建立干净新组的次数/该类图像数。
- **错归旧组**：选中包含其他人工区域的旧组，严重错误；按到达前旧组内容评判，不能同时移走旧图隐藏错误。
- **重复建组**：已有正确旧组却另建组；是允许出现的分散错误，计入未正确识别，不作为零容忍安全否决。
- **不确定率**与**未审目标组**单列；均不能算正确归类。

旧/新场景在自生成历史中由前缀决定，算法改变历史后场景分母也可能变化，所以必须报告分子/分母，不能直接只比百分比。正确历史组条件下的归类测试应另行固定相同历史组；目前尚未跑通此条件对照，不能拿Oracle重访替代。

稳定性仅辅助：错误改绑/纠错次数。到达时归错即使最后纠正，首次错误仍保留。

## 判定

已有明确跨区域混组或错误旧组归类，直接**不符合**，不因样本不全抹去已发现错误。没有此类已知错误但仍有未知、未审标签或场景缺失，**证据不足**，不允许宣布通过。当前标准定义指标及安全错误，不擅自替用户批准80%等数值门槛；同区域多组不单独否决。

`符合当前标注样本`只表示该样本内完成归类且无严重错误，不等于独立留出集可靠性认证；正式流水线缺独立留出审查仍降为证据不足。

## 执行

`sim/run_grouping_acceptance.py`支持正式包`protocol=temporal-image-benchmark-v1`：observations包含原图hash/时刻，labels为每图人工标签（null仅明确未审核/排除），review声明独立性及留出性质。算法输入只有observations，无labels。两个adapter输出每一步snapshots，正式评分器为`sim/temporal_classification_standard.py`。

已有实际前缀诊断：

```powershell
npm.cmd run build
node dist/sim/formal-association-replay.js run/sim/region-val4-multiview run/sim/NEW-prefix.json multi-bearing
python sim/formal_grouping_report.py run/sim/NEW-prefix.json docs/experiments/region-val4-core-labels-v1.json docs/experiments/NEW-formal-score.json
python sim/test_temporal_classification_standard.py
```

此回放是相同缓存视觉证据逐端点到达的受控实验，不冒充重新从原图提取的端到端性能测试；没有读取模拟坐标/动作或区域答案。

## 检查与修正结果

固定同一实现、同一证据预算，只比较legacy与multi-bearing策略：

|val4已有44图标注|原策略|修正策略|
|---|---:|---:|
|混合组数|1|0|
|错合并图像对|2/703|0/703|
|未归类率|61.4%|68.2%|
|同区域聚合率|2.9%|2.1%|
|即时旧组正确识别|0/22|0/16|
|即时新组正确建立|2/22|2/28|

修正明确错误：序列邻居不能让单方向共享表面的中心图直接成为身份确认。新记忆默认要求中心锚点双向多方向匹配；原策略保留便于对照，旧包加载保持原策略/证据，原观察、检索、拒绝和修订不删改。

报告：`formal-classification-val4-legacy-controlled-v2.json`与`formal-classification-val4-repaired-v2.json`。13图缺唯一审核标签，现有审核是AI开发审查；不能宣称真实算法通过。val5严格策略必要同位置恢复12/19（原15/19），关联24/40（原30/40）；缺同规格完整标签，不能发布正式全量分数。

**本轮已修一个实际错合并原因，但整体未达到可用标准：未知增加、即时旧组归类仍失败。** 记录退化，不以“零误合并”包装成功；需要后续非单表面证据补足召回，以及正确历史组条件下的归类评测。旧已有错误组不会因为加载被偷偷删除，重新评测须从空记忆按新策略跑。

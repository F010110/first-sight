# 仅分组：固定/弱固定/动态同输入对照

用户要求暂不调用VLM，检验家庭与HSSD局部连续分组。新增`sim/run_grouping_only_ablation.py`只调用原图匹配及TS在线memory，不调用API、标注或组聚合。沿用既有标签作事后诊断，家庭固定core子集与HSSD AI暂定core分开标识。

## 四种native算法

1. legacy-first-pair：固定段首两张，旧/新两对均需≥0.4。
2. recover-weak-anchors：段首弱则找当前prefix最早的强相邻对，找到后维持固定基准。
3. unconditional-first-pair：实验性固定段首两张，取消旧对必须强的条件；新对仍须强，四次跨比较必须已知且≤0.1。它容易把弱开头/无纹理低分误作离开，不进入生产默认策略。
4. updating-context-v2：现动态双观察窗口，矛盾证据冻结、两个新端点均须支持才迁移。

共享同一原生证据cache；THOR1fps、HSSD2fps。每种native候选配合同一个legacy稀疏控制器及同一历史关联路径，不让其他算法差异混进native策略比较。另独立跑稀疏legacy/weak/v2，说明旧观察点层的贡献。不是用两种检测频率混比推导优劣。

输入原图/原始时间/查询点数不变，不使用位姿、collector区域，不修改VLM提示。每例仍有真实中途保存/加载验证。第六HSSD原采集失败保留，不从计划6分母抹掉。

## 怎么判断改善

同时报告组数、core混组数量/成员、core多数纯度、不同区域pair分离率、同一区域pair保留率。纯度可被逐帧切分刷高；同区保留率也包括正常回访/不同朝向经历切分，不能单独视为正确率。输出全组成员，便于看跨房间有没有留在长组、同一连续空间有没有过切。boundary/unknown不强当独立房间，排除数显式报告。

建议方向不是立刻恢复固定首两张默认：固定参考能防漂移，但无条件固定低纹理起点会把未知当离开，弱固定遇到全程无强pair仍可能卡住。先同一数据对照再决定；不按家庭/HSSD分别调规则、阈值，不靠组数选赢家。

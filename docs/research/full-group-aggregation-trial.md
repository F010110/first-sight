# 全组迭代聚合试验（2026-10-12）

按要求让全部18个组参加离线全局聚合，不因上一轮保守条件提前排除单图组。每轮对所有当前簇重算：双方每个观察到对方的最大双向多方向视觉支持，各自求均值，取较小均值作为组亲和度；合并最强簇对。缺匹配记0表示缺支持，不宣告不同区域。

始终运行到1组，保存每轮原组成员、观察、亲和度、逐查询结果及聚合/错合并率。另按预先固定0.4阈值选停止点，停止规则不读取标签、不预设四个区域。全部组都参加不等于必须把所有组变成同一区域；到1组的后半段仅用于展示强行聚合后果。

脚本：`sim/full_group_aggregation_trial.py`。输入为可选修复v2最终18组和已有同方向视觉缓存，没有新跨相机匹配、几何或边界证据。原观察、默认算法和原报告不变。标签只在全部聚合及自动停止选择完成后读入评分。

8组是看标签后可观察到的本轮峰值，**不是算法无标签选出的结果，也不作为推荐停止点**。自动阈值实际选2组：一组包含43个已审观察（浴室15/卧室12/厨房7/客厅9），另一组只有1个已审浴室观察。严重错误，不能启用。

8组时，厨房6张聚到一起，卧室12张聚到一起；客厅9张与原污染厨房1张混在一起；浴室仍分为4个组，另有一组没有核心审核标签。合到4组也不是恢复四个正确区域：厨房/客厅/卧室全部进入同一簇，浴室仍占其他三个簇。

结论：已有视觉证据能合并相当一部分重复组，但**不能自行可靠决定何时停止、也不能识别区域身份界限**。现阈值在完整聚合时失效，强匹配仍跨区域。不能挑70.5%峰值掩盖实际自动结果，更不能把高聚合率等同正确区域恢复。

# 长期模拟第一轮：先验证时间跨度，不宣称生活任务完成

用户优先级：长期，而非精细画面。

本轮尝试24小时合成时间线：五个几何位置锚点，12段导航路径，反复离开与重访。移动阶段按约1m/s脚本生成路径位置，每约2秒采样；停留阶段每5分钟采样，带小幅观察方向变化。所有观察均重新从场景渲染独立三视图，不循环短视频，不复制前图到侧面。

这只是**静态环境下的长期空间重访**，不是已经模拟了一整天生活：没有人物、饮食、睡眠、物体操作、光照昼夜变化；几何锚点也不是已核验的不同房间。停留只意味着相机位于同一锚点，不代表人在做某件事。转角朝向由路径分段计算，尚非自然头部运动。采样之间的空白明确保留，不作为连续观察。

运行目标：`run/replicacad-pilot/revisit-24h-v1`。生成期间不发布manifest；全部完成才写公开manifest，网页才列入模拟回放。失败保留，不拼接成功前缀。位姿、行程脚本及几何锚点仅放private，模型输入和网页记录不带这些真值。

命令（WSL仓库根目录）：

```sh
LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless run/environments/habitat-v033/bin/python -m sim replicacad_smoke --dataset datasets/realism-source-survey-20261024-v2/ReplicaCAD_dataset --output run/replicacad-pilot/revisit-24h-v1 --scene apt_1 --egl-default-device --long-horizon-hours 24
```

验收：检查完成凭据、实际图像数量与哈希、时间单调且覆盖24小时、位置在原导航网上、网页可拖到后半段重访；时长只能称合成时间跨度。没有模型调用，不产生空间准确率分数。

后续应优先增加跨日事件持续性（物体放置后隔日仍在那里、再次移动留下前后证据），而不是把静态相机停留无限延长。必须先绑定并核查实际场景物体、支持面及碰撞，才能声明生活事件已实现。

## 回放与移动帧率更新

原 `revisit-24h-v1` 已完成349组观察、1047张图片，0至86400000ms；逐文件SHA-256、时间顺序和导航位置检查通过。它仍是稀疏静态重访，非连续24小时录像。

新生成任务 `revisit-24h-15fps-v2` 使用 `--travel-fps 15`；旧包不覆盖。渲染器对移动路径实际增加中间位置并独立渲染，而非前端插帧。停留仍每300秒采样。CLI允许0.5至30fps，默认15fps（只作用于长期模式），并在私有计划及公开manifest记录采样设置。

模拟回放新增“跳过停顿”，只在下一采样间隔至少30秒时可用：跳到下一段密集采样起点或记录末尾，并明确显示跳过的样本时间。这是依据公开时间间隔的浏览功能，不是活动识别；不能据此断言人没有活动。真实回放没有此按钮。两种来源都采用画面底部播放/暂停图标、时间、进度、倍速和全屏控制，支持播放器聚焦时按空格；三视图为前方大图、左右小图，问答侧栏280px。

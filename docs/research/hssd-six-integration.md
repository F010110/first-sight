## 实际测试队列

```powershell
npm.cmd run build
python sim/audit_hssd_assets.py
python sim/run_hssd_six.py
```

默认输出`run/hssd-six-v1/`；每例独立状态/日志，失败attempt不覆盖，重试新attempt。原分母6，不把失败或未知从分母剔除。可`--scene ID`做单例调试，`--offline-only`仅采集/图像回放/冻结代表，不冒称完成VLM。

1. 实际Habitat小步动作采集：移动2.5cm、转动3°，24fps每帧原位实际渲染；每12帧保存一次三视图，每48帧取观察点（约2秒一个），最多1920帧。不是交叉淡化、复用帧插值或复制旧轨迹。
2. 采集限定室内polygon，排除已知室外/阳台/露台/屋顶。navmesh含静态家具，选有最多室内目标的连通岛，实际最短路径巡视并计划回访起点。仅允许距室内polygon≤0.35m的**未标注门口间隙**，任何已知室外重叠仍拒绝；这些帧collector标签保留null，不借此赋予物理房间身份。失败首试因从孤立目标/严格polygon间隙无法路线连通，保留。
3. 原图hash、三方向配对、样本时间映射、视频24fps全解码和逐样本画面对齐校验。暗图/几何空洞等仍需视觉复核；数值检查不是场景画质验收。
4. 图像VO、双向多bearing匹配、旋转表面证据，`VisualExperienceMemory.observe()`真实online prefixes，途中保存→新memory load→严格快照一致→继续后续观察。HSSD在线adapter使用原始模拟拍摄timestampMs；旧通用诊断回放的1000ms/tick仅留作旧诊断，不用于HSSD在线结论。
5. 固定test.5的主体＋附注prompt/模型/验证/最多2次反馈修复，新增`--unscored`只取消无真值评分，不改prompt。完整回答/错误/反馈/未知保存。
6. 独立请求图像级AI审核预标签，不传算法预测、姿态或数据集区域标签。这仍是AI辅助建议而非人工真值；不能以“教室”功能标签证明学校建筑，也不能以相同功能名称作为同一具体空间身份。
7. 真实视频/留缝三视图接入原审核网站，独立显示原AI标签与预测、通过/不通过及理由、导出、数据集按钮切换，保留HSSD归属/许可。

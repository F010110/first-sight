# 同区域不同组聚合：方法核查（2026-10-12）

目标是判断局部组是否属于同一个具体区域，不是同类房间分类、同一表面匹配或固定距离回环。先研究判据，不修改默认算法、不启动训练。

## 已核查原文方法

1. [Predicting Topological Maps for Visual Navigation in Unexplored Environments](https://ar5iv.labs.arxiv.org/html/2211.12649)，§4.2、§5.1、补充§9：直接用同房间/不同房间全景对训练二分类MLP，输入图像特征及相机位置编码。无位置消融准确率76.37%，含位置编码78.15%；这是该论文全景对分类，不是本项目查询成绩。论文系统假设已知3D位置，不能整体套用。最相关启示：同区域关系需要专门建模，房间类型相同不等于房间身份相同。
2. [Hierarchical Unsupervised Topological SLAM](https://arxiv.org/html/2310.04802)，§III–IV：ResNet101+GeM单图特征聚类，再按时间拆序列，用SeqVLAD比较变长序列，最后组内图像核验。聚类过程无人工簇标签，不代表全部免训练；序列模型在Matterport/Habitat序列上训练。结果主要为回环检出及SLAM优化，不证明用户定义的区域划分正确。可借鉴组级候选检索，不能拿相似度阈值直接认证同区域。
3. [TF-VPR](https://arxiv.org/html/2208.09315)，§III–IV：时间邻居伪标签初始化，特征邻居扩张，RGB用RANSAC验证，迭代学习；全景水平滚动增强方向鲁棒性。目标是空间邻域检索，不是区域实例识别；自动标注模式明确为同数据自监督拟合，需与跨场景泛化区分。论文已明确指出时间远仍可能重访，不能把时间远无条件设为不同区域。可借鉴提案后验证，训练暂缓。

搜索另发现360ST-Mapping（全向共视+语义，但依赖视觉SLAM）、PRISM-TopoMap（局部匹配，但使用点云/里程计）；不作为当前RGB三摄条件下已验证的直接方案。本轮未复现任何论文实验。

## 推荐的无新训练试验

先把现有失败固定为组关系测试：浴室内碎片/卧室重访等同区域正例；隔门共享表面、开放厨房客厅、同类不同房间为负例。按独立录制划分开发/留出，不能把同一段的相邻帧随机拆成独立样本。标签不进入算法，不能按照预设四区域强制聚四类。

在已有segment-association上诊断/增加证据，而不是仅新增区域ID层冒充改进：

- 每组保留多张、多方向代表，跨相机比较同一场景方向；不能只front对front。指南针可信时辅助选方向，没有时搜索方向关系，不作硬门槛。
- 记录组间匹配矩阵和支持覆盖：多个独立结构锚点、多个时刻的一致性，单表面强匹配只提候选。
- 相邻碎片使用经过视觉验证的连续轨迹/转动解释作桥，不能只因时间邻近就合并；断录重置，跨边界或混组桥不能传播身份。
- 全局关系保留同区域/不同区域/未知，缺匹配不是不同区域。合并候选须检查整个区域的已知冲突及独立支持，不能用单链连通分量无条件合并。全组任意两图必须相似的complete-link同样会排斥同区域相反视角。
- 证据不足保留未定区域关系；后续跨视角桥出现可回溯确认或撤回。只有实体相机/不同独立结构算支持，重采样虚拟视图不能重复计票。

这是一条待验证的工程路线，不是新保证。若在同区域相反视角上始终无共享结构/可信连续桥，仅用当前证据不可识别，应留未知，考虑补采集或独立同区域学习；不能靠调低阈值制造身份。

## 评测约束

组关系先报告同区域召回、不同区域误聚合和拒答，再回到固定44查询的即时/延迟/最终区域身份评分。保留局部组，另输出有证据的区域关联，评分器按该真实区域输出评分；不根据标签映射组来美化结果。既有61.4%仍是局部组复用口径，新区域层必须明确另立协议版本，保留旧对照。

结论：最值得先试的是**跨方向的组级多锚点核验＋有证据的连续桥＋矛盾约束的可修订聚合**。图存储/聚类求解器不是主要缺口，可靠的同区域判据才是。新训练需另行批准并准备独立区域关系数据。

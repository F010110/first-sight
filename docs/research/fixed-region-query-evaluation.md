# 固定查询点的可修正区域识别（开发评测 v1）

查询清单：`docs/experiments/fixed-region-queries-val4-v1.json`，固定44个已审核心观察的ID、时刻、标签及查询前历史ID。它固定的是现有录制的观察时刻，不是随机空间采样，不含模拟坐标，也不代表任选位置成功概率。

评分器`sim/fixed_region_queries.py`仅在评分侧读取标签，算法不接收答案。新/旧按查询前是否已出现同标签观察确定，分母固定4新/40旧，不依赖算法此前是否成功建组。分别读取到达时、随后至多10模拟秒、整段结束的真实前缀；10秒窗口只取不超过截止时间的前缀，记录末尾不足10秒的实际可用延迟。

## 正确判断的定义

旧区域必须与至少一个查询前的已审历史观察归入同组，而且该组所有已审成员标签相同且等于查询标签；新区域必须没有同组的查询前已审成员，且已审组内容干净。不以多数标签给混合组贴正确标签，不允许查询自己作为旧组锚点，不确定保留在分母中。新旧情形及历史候选清单固定，历史成员归属允许修订。

这是**自生成历史下的可修正识别诊断**，不是向算法预先提供正确历史分组的条件识别实验。算法可有多个同区域组，但重访后完全另建没有正确历史成员的组算重复建组。所有已审混合组成员都不算确定正确，不意味着这些成员每一个都是被错移的图。

|配置|即时|延迟至多10模拟秒|最终可修正|

|默认时间分组|18/44，40.9%|18/44，40.9%|22/44，50.0%|
|可选回溯修复v2|18/44，40.9%|20/44，45.5%|27/44，61.4%|

最终可选修复：旧区域24/40、新区域3/4；失败17次中，6次目标组已审成员跨区域混合、11次重复建组。默认最终：旧19/40、新3/4。

从默认最终22到修复最终27，不是声称修了5张错图：实际提案迁移53/54两图，也使原先被污染组中的其他查询满足干净目标条件，因而评分变化5次。即时评分不受未来修复改写。

报告：`docs/experiments/fixed-region-query-report-val4-v1.json`，含每个查询的结果、实际可用延迟、输入hash与冻结清单hash。

## 标签和聚合率如何理解

已有标签是AI查看原始left/front/right三视图后的开发审查（`blind=false`，`reviewer=assistant-image-review`），不是独立真人盲审。四类为kitchen-dining、living-sofa、bedroom、bathroom。厨房/客厅开放布局的功能区域划分是产品粒度约定，不是由一条墙或米数自动定义。图片应标**观察者所在区域**，不是画面里能看到的物体所在区域；跨门看到床不自动意味着站在卧室。原图及连续记录用于判断，有争议的边界和未审图不强行单标签。

原包57个观察中44个core纳入，13个边界/未审观察排除。排除图仍可在算法组里，本诊断仅认证已审成员的相容性，逐查询列出未审成员；61.4%不是完整录制或设备可靠性成绩，完整标签缺失仍是阻塞。需要独立审查固定区域定义、逐图标签和边界，不能依据算法输出反改标签。

聚合率=同标签图片对中同组的比例。10张同区域图共45对，若分成两个各5张的组，仅20对同组，聚合率44.4%。每图一组为0%；全部一组可能100%聚合却严重跨区域混合。必须和错合并、重复新组及查询正确率一起读。

现协议没有独立“子区域”标签，因此不能给每图创造新子区域来解释碎片。算法子组是暂时组织结果，不是ground truth。同一区域多个组不单独安全否决，但缺历史链接会损害重访识别并降低得分。将来若确实需要子区域，须先独立定义并重标一个新版本，不能事后靠细分标签提高成绩。

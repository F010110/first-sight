# 多代表＋近期窗口＋候选：仅分组试验

用户批准尝试，未替换生产memory策略，不调用VLM，不重新标注、不改旧预测。`python sim/run_grouping_only_ablation.py --multi-context`已后台启动；输出独立`run/multi-context-only-<timestamp>/`。先家庭val4/val5，再5个既有有效HSSD采集；第六输入失败保留。

实现于`sim/multi_context_evidence.py`，消费原native三视图证据THOR1fps/HSSD2fps。共享同一legacy稀疏控制器/历史关联，与上一轮native对照保持一致。

## 状态与规则

- 稳定cohort档案保留所有已接受的双观察代表，另有近期窗口。优先取首、中、末代表及近期窗口，不只看开头两张。
- 弱启动从首个可信相邻cohort获得上下文。支持阈值仍0.4，低关联阈值0.1，不按数据集修改。
- 新cohort与某代表双端点一致，且其他选中代表没有整对离开证据，才允许延续/更新；一条孤立高匹配不授权更新。
- 歧义时检查全部**已接受cohort档案及近期窗口**，不是号称已经比较全部原始图片。原图保存不删；未接受的暗图/未知帧不充当稳定证据。
- 对全部已接受cohort均有四次明确低匹配且新cohort内部可信，进入待定候选，冻结旧上下文。
- 再到一帧，要求连续两对支持且第一候选帧与第三帧也支持；再次核对全部已接受cohort后才确认，回溯候选起点。缺比较不切分，正匹配恢复撤销候选；弱证据打断连续确认，不跨弱帧累积。
- 断档重置，不读未来、位姿、模拟标签。候选仅视觉上下文，非物理房间。历史匹配弱、门口共享视野、同房间大转向仍可能导致漏切或过切，不承诺一举解决。

## 验证

Python87/87通过，新增三帧因果确认、缺比较不切分、单匹配桥接不更新、断档重置测试。原有构建已通过，本轮仅原图检测层实验，TS生产策略未变。

用相同事后标签评组内纯度、混组成员、异区pair分离、同区pair保留，报告候选诊断次数（不是未知观察比例）；保存中途memory roundtrip。HSSD标签仍是同模型AI暂定标签，开放区域划分有争议。家庭13/12个边界或未标注观察排除数仍显示，不能把已标核心纯度100%说成全部观察正确。

本轮新保存原图匹配pairEvidenceCache，便于后续仅调整状态机时重用；原有对照未存此cache，当前仍需重算部分图像证据。扩大档案比较可能增加CPU成本，因此不得承诺模拟器内实时延迟或仅凭视频fps推断计算速度。

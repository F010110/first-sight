# 新视觉记忆应有功能与验收清单

本清单区分软件实现和可靠性验收；原图/轨迹不变、无GT进入算法、无可靠米制定位前提、不替换生产记忆。旋转同时移动暂不判断，旋转/断档不是静止。新增判断不得静默清空旧版结果。

最新状态：F04/F05实验实现仍保留，但因实际0/11失败已退出默认链路，勾选不代表可用。重访新增平移兼容的多方向双向分布几何验证，Oracle val4恢复2/3、val5保持2/2；自动端到端仍未恢复边界。当前总多维报告：`docs/experiments/visual-repair-scorecard-v1.json`。

## 本轮软件工作

- [x] F01 原地点、历史对象检索、拒绝/修订/轨迹与持久化兼容（已有回归验证）。
- [x] F02 输入校验及可配置内参/输出路径：`three_view_vo.py`、`build-visual-memory-inputs.ts`；三方向库存、分辨率、顺序校验。内参为针孔/已矫正图像前提，不等于真实手机标定已完成。
- [x] F03 VO诊断原因和统计：无描述子、唯一匹配不足、分布不足、位姿支持不足、低视差及旋转。实际两户型移动发现率未提升，不将诊断输出当优化。
- [x] F04 **候选级初版**自动开口轨迹：`automatic_boundary_tracks.py` 几何线框、重叠匹配、扩张/消失、退回和后续观察；原生帧顺序接入状态机。停止移动也可提供后续观察，但未知/转动不能冒充穿越。真实穿越可靠性未通过V01。
- [x] F05 **弱证据初版**开放区变化：空间边缘布局+灰度分布持续变化与VO移动共同支持；不把此模型当功能区域语义真值。未通过V02。
- [x] F06 `VisualExperienceMemory.observe` 在线追加、失败原子回退、仅接收已到达端点证据及已确认时间的边界。断档分开时间上下文，不证明物理地点改变。
- [x] F07 共享边界锚点不改唯一主归属；`segment-association.ts` 仅用共享锚点提候选，不能单独确认身份。切点、确认时刻、延迟分别保留，原生帧事件不因合并窗口丢失顺序。
- [x] F08 `region-interpretation.ts` 将临时时间区域与历史假设分开；`revisable-region-hierarchy.ts` 支持区域/子区域独立组织与修订。自动语义层级正确性仍未验证。
- [x] F09 显式reviewBinding/createReviewedRegion/retractLastReview；不自动覆盖拒绝和旧基线，审核有原因及原绑定记录。新增自动历史假设不冒充已审核区域。
- [x] F10 原子保存原关联包、在线解释输入、审核与层级修订；旧包导入、损坏加载不改变记忆。持久化/撤回/层级测试通过。
- [x] F11 `visual-complete-evaluation.ts` 原基线另列；无边界控制/Oracle/自动条件采用相同视觉链接、边界缓冲与历史匹配器，不向推断输入真值。
- [x] F12 多维框架包括动作计数、边界F1/确认延迟、原视觉身份覆盖/物理覆盖区别、原核心审查、严重错绑、前缀改绑、历史对象查询及提取/缓存更新时间。无对象标注、真实延迟/修复真值则填null，不伪造实测。
- [x] F13 `run_visual_memory_pipeline.py` 一键原图→VO→自动轨迹→记忆；无旧包时从图像生成原基线及几何证据。13帧三视图/4观察冷启动已跑通，输入没有GT、旧缓存或旧地点包。

这里的勾选只表示**软件初版及接入存在**，不是“全部不足已解决”。F04/F05在两旧户型仍未确认任何切换，自动边界F1=0；V项必须保留未通过。

验证：`test:visual-pipeline`35项、`test:memory`73项（部分重叠）；Python VO4项、自动边界6项、冷启动产物1项。两户型原baseline bundle逐项保持不变。当前说明及重跑方法：`docs/research/visual-functional-implementation.md`。

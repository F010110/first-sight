# HSSD v1逐观察误差归因（暂定标签，非人工真值）

只读生成`run/hssd-region-labels-v1/error-attribution.json`，完整每图编号、标签/理由、预测类别/身份、最优映射、组内分布与原模型理由。没有重调用模型或修改预测。

## 评分规则及修正

core按全场景具体身份最大一对一映射；core预测boundary/unknown均失败。boundary只评类别，不评邻接身份。附注不改主体。166 core：66一致、45错误身份、26被标边界、29真正未知。15 boundary：4命中、6被标core、5真正未知。

此前`predictionUnknown`把finalAssignments=null全部算未知，但主体boundary也用null，因此有误导：64空区域赋值实际为34真正未知＋30边界，不是64次模型弃权。分数未受此字段影响，脚本已修正统计，历史scores.json原样保留；详细归因表给真实分类。

## 可确认与不能确认

可确认：组把长段不同视觉上下文混在一起、干净走廊被整组标交界、首中末压缩不覆盖过程、模型明确指出异区域仍整组绑定。

不能确认：仅凭这一轮AI标签判所有分房粒度正确；“模型没弃权”不是正确；同模型另一次标注不是独立真值。标签描述不一致及对开口/墙体的解释需要人工审查，不能从暂定39.8%直接推出真实准确率。具体错图都已逐项列在归因JSON，但它们首先是标签不一致项而非全部已证实错误。

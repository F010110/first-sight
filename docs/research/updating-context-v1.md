# 小范围动态上下文更新试验

本版替代固定首对/弱首对恢复，不做生产代理大重构。新鲜在线memory使用`updating-context`，旧持久化解释继续继承原策略。

当前代表仍是一个小的可信双观察窗口，不是已经实现的完整多代表库。窗口只在新观察有正支持时更新；共享一帧不足以授权更新，新端点还必须与旧端点有正支持。缺少证据时不移动窗口。候选连续两帧内部一致且与保留上下文四次明确比较均低时，提出可撤回经历切分；下一帧恢复原上下文正支持时更新代表而不切分。0.4/0.1阈值未改，缺失比较不能当冲突，低匹配仍只是上下文候选而非物理房间真值。

这实现了用户要求的随观察更新的轻量版本，不宣称实现任意长度候选状态机、多代表异质性检测或物理门口确认。

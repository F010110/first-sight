## 分区

|目录|用途|
|---|---|
|`application/`|手机试用、产品与应用记忆设计；本轮不接入三视图研究|
|`research/`|当前视觉记忆架构、功能清单与评测协议|
|`archive/`|早期设计、方法对照和失败诊断，仅作历史参考|
|`experiments/`|数值报告与标签，原路径保留便于复现|
|`references/`|参考资料与评审|
|`notes/`|讨论、建议和草稿，不作为验收结论|

2026-10-24用户确认当前版本作为V2。**这是接受已知限制的单摄实时原型版本，不是稳定移动通信／安全导航产品。** 本次仓库整理不新增通信协议、模型策略或硬件架构。

- 后续网络持久诊断、Android／iPhone热点与中继实验已撤回；历史原图、日志、APK及Git提交保留，不冒充当前功能。

## 当前入口

```powershell
$env:CAMERA_TRANSPORT = 'push'
$env:CAMERA_RECEIVER_HOST = '电脑当前校园IPv4' # 替换；需与设备目的地址一致
npm.cmd run realtime
```

实时http://127.0.0.1:8884/realtime.html，真实回放http://127.0.0.1:8884/recordings.html。8885是摄像头图像接收，8884是仅本机控制。旧8880视频助手、8765手机HTTPS及其他回放实验不是此实时链路。

## 已知限制（保留，不视为发布后已修复）

1. 校园网移动断联、多次超时／不完整上传仍存在；网络策略、覆盖、AP切换及实现因素不能一概归因；用户也报告手机校园联网不稳定。
2. 单摄仅前视图，左右真实缺失；三摄并发、同步、标定及光学没有验收。
3. 没有断网图片缓存补传；默认预览不隐式保存；接收端没收到的画面不能从回放补造。
4. IP变化需人工同步；启动需显式选择push和接收地址；无进程守护、自启或可靠的全局重启恢复。
5. HTTP局域网鉴权并非传输加密；设备NVS凭据未加密。当前不开放控制服务到公网。
6. 成员完整原图比较超过12图cap会产生unknown；空间误合并／误拆分、跨环境真实准确性无独立充分验收。
7. 问答可能误认或编造细节；断流／过期画面不能保证当前状态，不能作为安全通行依据。
8. 会话预算为空间0.50／问答0.25美元每小时估算，重启不是严格全局账户限额；长期磁盘／内存增长尚未验收。

v1.2.0的851观察／90题及96.67等成绩保持[v1发布身份](v1.2.0.md)，不能迁移为V2移动硬件或当前模型链路的验收分数。空间对比实验也仍是各自冻结样本的工程指标。

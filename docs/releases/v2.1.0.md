# First Sight v2.1.0 — 三摄线下闭环初步完成

日期：2026-10-25。正式工程版本；继承v2.0.0算法基线，不是算法升级或新评测成绩发布。用户确认当前版本可以固定，线下闭环初步完成，评测样本仍在构建。

## 本版固定内容

- 三台ESP32-S3/OV2640逐台烧录与独立配对，使用eFuse派生cameraId及显式front/left/right方向；状态、拉取图片及主动上传均携带身份信息。前/左/右使用独立密钥，不按IP或连接顺序推断方向。
- 三台同时供电的短测：每路收到3张640×480原图，身份、方向、会话、哈希、解码通过。左右配对隔离经错误密钥返回401验证。
- 8884统一首页、真实/模拟回放及实时页；实时布局与模拟三摄一致，前图大、侧图右侧上下排列、问答栏收窄。模拟显示样本在同一选择器选择，不把几何原型作为合格校园场景。
- 三路网页预览；前摄沿用现有记录/模型路径，左右仅独立RAM预览，未接入method2、不录制。默认记录和模型均关闭。模型算法和历史分数不变，不宣布三摄空间推理已完成。
- 真实长视频支持播放、定位及原片绑定；UTE浏览器兼容副本明确标识，原片保留。源数据不随代码发布，本机可用不等于获得公开再分发许可。

## 启动

```powershell
cd D:\Projects\Projects2026\VLM
npm.cmd run realtime:three
```

打开 `http://127.0.0.1:8884/realtime.html`。保持终端运行，电脑不休眠。该命令不启用付费模型，不能将网页三摄预览等同于三摄Agent验收。现有`npm.cmd run realtime`保留为原单摄交互入口，需要原有显式开关和凭据。

# First Sight v1.2.0

正式发布，经用户确认；保留已知限制。版本沿用1.x：仓库已有v1.0.0手机基线及v1.1.0-test.5研究版，不覆盖旧标签。

## 发布内容

- 窗口级连续空间推断，独立、短寿命Context与SQLite长期拓扑。
- 原始输出／检索／答案可追溯；历史答案需要真实inspect原图。
- 修复候选已找到却反复search：根据取证阶段引导inspect、完成后回答。
- 每事件16轮推理、16次搜索；保留图片权限、因果截止和显式付费确认。
- 按功能重组Python工具与TypeScript模拟入口，测试、文档历史分离；构建只写`dist/current/`。

## 已知问题（发布后仍存在）

1. 已正确取回原图也可能误认场所、编造可见细节。
2. 相似地砖墙裙不足以证明同一楼层，仍有错误同层断言。
3. 对关机／未记录时间段可能无依据断言持续位置。不得据此作人员位置、安全或路线保证。
4. 手机及部分旧服务入口尚未全面迁移到新循环，不能将此分数迁移给所有应用入口。
5. 58/63个预测地点不代表正确物理区域数量，仍需[轨迹人工审核](../application/spatial-graph-human-audit.md)。

此前发布检查曾因第3项保留候选身份；本次用户明确接受当前版本作为正式版，状态由此更新。不是这些问题已经修复。

## 开发入口与复现

```powershell
npm ci
npm run build
npm test
python -m unittest discover -s tests/python -t .
python -m sim --list
```

新评测入口（仅显式授权后运行；下列路径为本机开发数据，不分发私有标签）：

```powershell
node --use-env-proxy dist/current/sim/evaluation/interleaved-memory-evaluation.js ORIGINAL-GROUP CALENDAR-DIR NEW-RUN full --confirm-paid
node --use-env-proxy dist/current/sim/evaluation/memory-evaluation-grade.js NEW-RUN TASK-BANK full --confirm-paid
```

需要`QWEN_API_KEY`、`QWEN_BASE_URL`。完成后仍需检查完整性和语义，不自动挑选最优答案。当前监督入口：`scripts/evaluation/run_release.ps1 -OutputDirectory NEW-RUN`；冻结候选复现仍可用`run_inspect_candidate_full.ps1`默认参数。见[仓库规则](../maintenance/repository-layout.md)。

历史实测编译依赖在`dist/inspect-probe-grading-v1`保持原样，`run/inspect-repair-full90-v1/code-freeze.json`为当次哈希。目录重组只更新源路径／导入，不重写旧回执或把新构建冒称当次受测二进制。受测算法代码来源为`inspect-repair-candidate-v1`及其修复提交；正式发布标签`v1.2.0`包含仓库整理。

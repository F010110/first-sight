# 固定地点识别＋位姿拓扑＋独立路线说明Agent

## 本次“回退”的含义

恢复职责分工，而不是删除旧工作或Git reset：

1. **固定版负责视觉地点识别**。不修改`FixedGroupSpatialAgent`，不添加位姿/图关系输入，不再让它计算轨迹。
2. **程序负责几何与路线**。原始位姿进入独立拓扑，存储每次到访与完整轨迹；正反向检索、角差与运动摘要由程序完成。
3. **独立Agent负责语言**。读取已经计算好的运动事件和少量历史原图，给边生成说明并持久缓存。它不决定路径或转向。

历史的理想位姿原型、24题开发集及17/24成绩保留，但不再作为本架构的基线。尤其“没有记录反向边必须拒答”是旧评测假设，不能用其0/3否定本次默认允许反向复用的需求。

## 实现入口

- `src/agent/pose-route-topology.ts`：节点、到访、地点间边、地点内轨迹、原始pose、反向复用、连续路线检索、运动事件、JSON快照恢复与说明缓存。
- `src/agent/fixed-pose-route-assistant.ts`：组合现有`FixedGroupSpatialAgent`与新图、新Agent。`observe`只把`{id,atMs}`交给固定识别器；图像仍由原识别模型适配器交付。`answer`按已定位的到访锚点检索路线并调用说明Agent。
- `src/agent/route-description-agent.ts`：独立Agent输入/校验/缓存/渲染。不向Agent提供原始坐标数组，仅提供程序运动事件及原图。左右/转身字段不允许模型改写，明显文字方向矛盾会拒绝，不静默修正。
- `scripts/datasets/prepare-fixed-pose-routes.py`：复用已存在固定版输出，并与它原先冻结的输入hash绑定，不重新运行识别。
- `src/evaluation/fixed-pose-routes.ts`：实际图构建、快照恢复、独立预生成几何答案检查、路线连续性回归，以及可选的小预算真实语言调用。

这是独立组合入口，未接入8884网页、硬件实时服务或改动其默认行为。

## 图如何存储

节点是固定版返回的地点候选ID，保留名称及全部到访记录；不是重新用pose聚类，也不把模型地点候选提升成人工真值。

每两个相邻已知地点观测之间，只在**完整pose连续**时生成轨迹资产：

- `between-place`：不同地点ID之间的边；
- `within-place`：同一地点内的两次到访位置之间的运动。

后者不能省掉：同一地点ID可能覆盖十几米，若只存节点中心，跨次到访会发生“瞬移”。每个轨迹资产绑定起终到访ID，保存全部原始pose（位置、相机yaw、时间、frame、recording、来源），长度和可逆策略。未知地点观测不创造节点，但有完整连续pose时，它不妨碍连接前后已知端点。

默认允许反转，显式one-way例外。反向使用时倒排原始pose样本，并重新计算运动方向/转向；**不能把相机记录yaw直接加180°**。正反向说明分别缓存，不能倒排中文。

位姿断档超过150ms、坐标系/录制/来源切换均断开通路，只有时间相邻不能造边。路线搜索约束实际端点衔接，最多0.25m误差；同名节点的远处到访不能直接跳接。按记录路径长度搜索；到达目标地点候选不表示到达某扇具体门。

沿路线连接多条边时，下一条边的初始方向由上一段实际行进方向传递，不能重置为当年摄像头朝向。说明缓存键包含边内容、正反向和初始方向；策略更改使缓存失效。快照保存原始pose、到访、单向约束及带版本指纹的语言记录，边可确定性重建。

当前只支持同一全局时间轴下的单录制回放；跨会话坐标对齐、地点merge/split后的图修订不在本次最简版本中。

## 运动摘要与语言边界

NED正yaw表示右转。程序用0.5m误差阈值简化XY折线，去掉小抖动；保留的路段产生方向、转向及取整距离。此摘要不是精确的每个脚步指令，不能证明地标可见性或安全性。

说明Agent每个事件返回index、原样turn、text、sourceIds，并输出不确定性。约束检查不等于完整语言/地标正确性验证；尤其不应把历史机器人图像中的左右直接当用户身体左右。最终文本固定标识为历史路线回顾，人体朝向及当前通行未确认。

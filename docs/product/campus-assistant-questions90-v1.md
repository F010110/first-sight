# 新90题：空间记忆复用后的用户问题运行

## 与原90题分开

用户要求将三问试跑扩充为与旧实验相似的分层90题。本次单独创建`assistant-questions90-v1`：当前／短时／长时各30题，覆盖校园全部10段。旧90题、旧评分、旧输出及空间建模包均不改写。

这是**基础环境信息与时间回忆题集**，不是已完成的10–12条复杂互动故事，也不代表找物、取消、监测、活动识别或安全功能全部验收。问题由公开观察时间与模板生成；未导入旧答案、旧任务真值、GT坐标或未来图像。没有独立人工语义验收，不产生冒充正确率的数字。

## 题目范围

- 当前30题：环境概况、左侧物体／边界、右侧物体／边界各10题。看不清可以拒答，不推断图外物体。
- 短时30题：同一段中约20秒前的环境、室内外、地面描述。
- 长时30题：前一段的环境、室内外、地面描述，合成样本时间间隔至少20分钟。
- 不把记录间隔期间的活动补造出来；不问未记录路线、可通行性或安全承诺。

长时只指显式合成活动时钟上的跨度，不宣称真实用户走了20分钟或真实生理记忆性能。原始轨迹在episode间有缺口。

## 冻结与隔离

`python -m sim.school.build_assistant_questions90`生成新目录（已有目录则拒绝覆盖）：

- `run/campus-assistant-questions90-v1/tasks.json`：只有用户问题、时间、分层、当前观察索引与显式能力选择；不带答案或历史证据ID。
- `evaluation-only/evidence.json`：源时间／证据ID／图像hash／接受边界，供执行后核对，**不交给Agent**。它是源绑定及审查线索，不是独立标注真值。
- `frozen.json`：90题计数、分层、数据hash与构造说明。

当前问题点按episode时间分散，全部90个观察索引唯一并按源时间前进。第1段没有可成立的跨段长时题，因此长时题分布于第2–10段，而非伪造第1段的过去。

## 独立重跑

```powershell
npm.cmd run assistant:questions -- --full90 --confirm-paid
```

仍加载同一完整空间包，只运行问答Agent，空间调用0。每次运行新目录，保留原始请求、输出、失败、用量、冻结问题脚本、前后数据库hash。模型固定`qwen3.8-flash`、thinking关闭。

90题模式最多720请求、公开价估算USD2；三问模式与网页默认预算不变。每题最多8轮。不因单题失败拼接其他运行的答案；后续题继续尝试，失败通知原样进入回放。预算不足也不静默扩额。

时间定向检索支持`afterMs`／`beforeMs`，由模型根据问题中公开的HH:MM:SS计算，不从私有证据表注入目标ID。检索仍受提问时刻硬截断，历史主张必须inspect实际原图。

本轮采用**加速因果阻塞运行**：每题等待模型后才发下一题，不是实时输入压测。网页将每题实际返回耗时映射到源样本时间；若返回晚于下一题，旧答案不跨题显示，审计保留原答案。不得据播放效果宣称实时时延达标。

## 统计与观看

完成后用`python -m sim.school.audit_assistant_questions90 <本次运行目录>`生成补充`validation.json`，从追加式事件核对90个独立任务、分层计数、实际状态、交付、原图引用及空间库hash不变。运行时UI状态只保留最近50任务，因此不能把快照长度误当全量执行数；审计从完整`task-settled`日志重建，不覆写原报告。

网页`http://127.0.0.1:8882`刷新后自动选择最新完整问答运行的时间轴。展示的是本次实际交付内容；任务completed是执行状态，不是语义正确。视频、问题、回答与空间短地点名称维持原有同步规则。

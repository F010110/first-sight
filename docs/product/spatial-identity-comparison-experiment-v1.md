# 空间身份原图对照实验 v1

状态：2026-10-21首轮因新增历史图传输问题失败，已修复并启动新的完整双臂实验。不是生产策略切换，不重建前端当前使用的空间包。

## 最小改动

- `SpatialContextLoop`增加显式启用的历史原图预取入口，默认关闭。历史必须早于整个当前窗口，最多4个来源／12张图；缺少原图、重复来源或未来来源直接失败，不以文字假装已看图。
- `spatial-context-identity-review.ts`选择最近观察和该身份仍在短期Context中的较早锚点，实验runner再隔离录像来源。只从当前运行的Context选择，不读取旧运行身份或人工标签。
- 模型额外输出自身所在区域及逐来源的same/different/uncertain、具体布局依据；不仅看物体清单。每个当前观察必须比较历史原图与窗口内紧邻上一观察，并引用对应原图。
- 确认same却新建身份、沿用身份却报告different/uncertain、未比较原图却沿用旧身份、uncertain却新建，均拒绝。至多三次决策，失败明确记为unknown；原始响应与拒绝原因全部保留。
- 核验器只能验证证据流程与自洽性，不能判断模型编造的布局依据是否符合图像，更不是独立视觉真值。
- 本轮不实现自动全局合并、追溯修订、完整经历片段层或几何导航，也不修改已有SQLite归属。

## 冻结实验

```powershell
npm.cmd run build
node --use-env-proxy dist/current/desktop/experiment-spatial-identity.js --confirm-paid
```

两臂都从空记忆读取相同100个原始三视图观察：第1段0—134秒、第4段88—150秒；相同最多4观察窗口，同模型`qwen3.8-flash`、`enable_thinking:false`、temperature=0、输出上限2400tokens。control保持既有判断流程；review增加原图对照与核验。不同臂不共享身份或输出。

每臂最多96次实际请求、估算USD0.30，两臂合计USD0.60；包含有限修复及网络重试，不无限补跑。运行前冻结观察ID、源码hash、私有检查hash及旧库hash；每臂保留失败／中断／usage／原始响应／Context。运行后再次校验旧库hash。

第4段是截取片段，不假称包含本段完整历史。两臂的起点、窗口、预算与信息范围相同，但review因自动取图增加图像token；成本差异需如实报告。单次开发实验不能分离提示、取图、核验三者各自贡献，更不能建立总体鲁棒性。

## 证据与验收范围

模型输入不含人工标签、地图、XYZ或预期地点数。付费执行前冻结的少量私有配对仅供开发诊断：球场48秒与树侧80秒应区分、树侧80秒与球场112秒应区分、球场48秒与112秒应恢复同地。三个配对不独立，没有全量区域标签，不能折算校园准确率。

补看三视图确认80秒左图隔围栏看球场，前图为树侧地面，右图为建筑外墙；48秒三视图显示球场地面与围栏。样本依据已人工查看，但仍不是独立盲审。

**修正先前审计过强的措辞**：第4段112／120／128秒属于有转角和门口的室内通行区域，旧版同ID、新版多ID可以确认，但仅凭共享瓷砖／墙面不能证明必属同一细粒度地点。这三组配对冻结为`review-required`，不计correct/wrong；重点查看新建是否比较最近身份、是否给出真实边界依据，而非强迫所有走廊同组。新旧结果都需进一步原图和轨迹审核。

同时报告全部100观察的空身份数、候选数、被拒比较、执行失败与成本。不把“更少地点／更少unknown”当成更正确；相反也不能通过全部unknown消除错误来宣称修复。

## 首轮失败，完整保留

`run/spatial-identity-experiment/2026-10-21T07-09-56-421Z-6b4bed59/`：control完成100观察，25请求、估算USD0.037841346；冻结的两个球场／树侧不同区域配对均混组，球场同区域配对恢复。review仅完成4观察，第2请求HTTP400，不能作成功对比。review估算USD0.0199083504包含一个未知计费预留，不能擅自清零。

原因是新增预取代码把`reference.images`附带进入Context元数据，导致第二请求input.json约5.98MB；图像既出现在图片内容，又被Base64序列化为文字。API报`Range of input length should be [1, 991808]`。修复为原图只进入`evidenceImages`、Context只保留来源元数据，并增加测试断言Context retrieved没有images字段。修后16项相关测试通过。

首轮两个臂原样保留，不续跑review、不借用其control作为新实验基线。新实验重新运行两臂，同样冻结输入／预算／源码。此失败是实验实现的输入膨胀，不是空间效果的拒答或正确率结果。

## v2协议减负，新的完整对照已启动

保持同一100观察、窗口、私有开发检查、模型和两臂预算，重新从空记忆运行两臂，不拼接之前结果。

- 窗口首观察必须比较所有已交付历史代表；后续观察必须比较紧邻前观察，可以额外比较已交付的其他历史／窗口内更早原图。窗口长度仍至多4观察，不把任意长视觉链当成同区域证据。
- 给模型逐观察的`requiredReferenceIds`表。错误反馈指明具体观察的missing／unavailable来源；有效额外比较不再当成格式失败。
- 仍拒绝未交付／未来来源、same却新建、different／uncertain却沿用、uncertain却新建；不通过放宽这些约束造改善。
- 再次说明候选身份不要求知道建筑名／用途，没有旧UUID但有新区域正面证据时可以建候选。并非自动把所有null改为新地点。
- 新增多观察单测覆盖首帧锚点比较、后续帧原图比较、可选已交付参考、同地重复建点仍被拒。17项相关测试通过。

v2结果出来后先审核原始输出，不自动扩大到全校园或替换前端包。当前策略只主动比较短期最近身份及其锚点，不能据此声称已解决较长间隔后的全局重访；这一能力仍需单独验证历史候选检索与原图确认。

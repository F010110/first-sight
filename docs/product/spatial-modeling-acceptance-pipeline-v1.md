# 空间建模迭代与接近可用验收 v1

状态：2026-10-21实现通用离线评分＋从空记忆在线固定范围分组实验；正在执行6观察开发冒烟，不是已达到可用。

## 目标与冻结门槛

允许门口／转角边界不精确，但核心区域不能长期混组、碎裂或大量未知。地点是具体可占据空间，名称与定义固定，不能把同建筑／相似物体当同区。层级粒度由评测协议先定，不能看模型输出后改真值。

暂定开发验收条件（必须全部满足）：

- 至少3个未参与调试的完整场景、60个审核核心观察；每个场景至少10同区对和10异区对。
- 场景宏平均平衡准确率≥90%，每场景≥85%。同区恢复率和异区恢复率等权；未知、缺失、失败不从分母消失。
- 核心已判身份覆盖率≥95%；异区对误合并率≤3%。同时报告错误拆分数量和比率。
- 至少6个事先审核的真正重访对，恢复率≥90%。远时间间隔不自动称重访；旋转／同次连续行走不能冒充独立重访事件。
- 全部计划观察执行完成，不能以中断前成功片段通过。

门槛是工程开发代理，不是盲人用户验收、硬件验证或安全导航承诺。当前没有足够独立人工审核的校园／家庭留出真值，因此即使某个开发小例全对也不能宣称接近可用。

## 复用而不是重造真值

已有`region-core-evaluation.ts`支持core/boundary/unknown与边界邻区检查，`region-evaluation.ts`支持人工同／异对；HSSD有图像审核与标注脚本。本轮增加统一输入和验收汇总，既可导入家庭／HSSD也可导入校园，不把旧局部地点、房间、整建筑三个粒度混成一个分数。

先建立公开原图清单和独立私有标注，再从冻结清单运行；标注者直接看原图而非先看模型分组。模型产生的描述不能做自身真值。人工不足时明确标为assistant-reviewed development，不能自封独立人工留出。开发集看过错误后永久留在开发集；按场景分割，不用同段邻帧冒充留出。

标注JSON：`{"labels":[{"id":"a","scene":"home-1","split":"development","kind":"core","region":"kitchen","reviewer":"实际审核者","reason":"原图依据"}],"revisits":[]}`。

boundary或unknown的region必须null，不进入核心成对准确率；二者比例、未知数和原始观察总数仍报告。不能把难例事后全部标成边界。边界精细邻区检查可额外使用原core评价器；本轮通用门槛不强求边界帧准确落组。

预测JSON：`{"runId":"完整独立运行ID","predictions":[{"id":"a","placeId":"程序ID或null","status":"completed"}]}`。失败／尚未执行分别failed／pending，身份必须null；缺失也扣覆盖和完成率。不把不同运行的成功答案拼接。评分写新文件且绑定两输入SHA256，不覆盖冻结分数。

```powershell
npm.cmd run build
node dist/current/desktop/score-spatial-acceptance.js labels.private.json predictions.json NEW-report.json
```

`spatial-acceptance.ts`按场景内所有core对统计，避免不同场景使用同样ID导致跨场景虚假合并；按场景宏平均，避免长场景压过短场景。all-merged、all-singletons、all-unknown、缺失结果、场景泄漏均有单测。

## 在线固定范围策略，不再手工喂种子

`spatial-fixed-group-agent.ts`：每场景从空组开始。首次原图可建立一个明确命名的候选范围；之后逐一检查所有已建候选组，按每页最多3成员原图覆盖全部成员。名称／定义／排除边界固定；任一成员冲突不能入组。唯一belongs且所有其他组different才加入；全部different才允许根据当前原图建立候选。候选冲突、模糊竞争保留unknown，不由时间邻近自动继承身份。

首次建组来自单观察，可能起错名，这是尚待验证风险；不能靠名称锁定就认为正确。没有自动撤回旧归属、跨重启恢复或范围纠错；这些必须作为后续显式版本机制。组比较直接看当前原图并先检查区域范围，本轮没有把前一次ground-first感知作为强制中间输入，因此不能把效果归因于感知提示改进。

公共输入只允许schema和observations，每行只有id、scene、atMs、views，每视图direction/path/sha256。不允许标签、region、预期结果。接口按scene独立记忆，禁止未来／跨场景原图，使用已有adapter验证PNG及hash。每个请求保留原始响应和计费。候选组全量扫描是正确性参考实现：成员数增多时调用量近似二次增长，不冒称已达到实时性能；预算不足停止并计pending，不能偷偷截短历史来节省开销。

```powershell
node --use-env-proxy dist/current/desktop/run-spatial-fixed-evaluation.js PUBLIC-input.json --confirm-paid
```

每轮最多128实际请求、估算USD0.50。冻结公开清单及源码hash后才付费，模型qwen3.8-flash、enable_thinking=false；不读私有标注。所有失败原样保留，不自动续接或无限重跑。应先小批次通过开发，再增加新场景和规模，不在未解决错误上直接烧完全量。

# 实时画面记录模式

默认关闭记录：网络接收器校验JPEG后，通过进程stdout传入服务器内存；服务器只保留最新一帧，下一帧覆盖，不生成JPEG／PNG、不写图像收据或空间观察。浏览器no-store，画面不会主动存浏览器持久缓存。系统状态、失败类型等非图像元数据仍可落盘，因此这不是“零文件／隐私擦除”模式。

页面“记录画面”独立控制手动记录；开启后图片保存在`run/realtime-system/<session>/capture/frames`，收据为`capture/observations.jsonl`，供模型使用的像素等价PNG为`model-originals`，结构化观察写本会话SQLite。单纯记录不会调用VLM。

“系统启动”自动包含记录，期间记录开关显示开启且不可关闭；关闭系统后恢复手动记录选项。默认手动选项关闭，因此通常关闭系统就恢复仅预览。已记录文件不会因此删除；历史证据、在途模型结果和使用记录仍保留。

模式切换以接收器收到控制消息为界：只有请求开始与完成时均开启记录、期间未切换模式的帧才写入。开启前的内存预览不追溯归档，关闭时在途网络帧不保存；已经开始的本地归档／模型准备可完成。预览不必等待模型PNG准备。

失败正文在仅预览时不落盘；记录开启时保留错误正文以便诊断。内存预览短暂保留最新一帧供多次HTTP读取，不承诺某个浏览器显示完成就立刻销毁，也不宣称操作系统不会交换内存到磁盘。

Python回归覆盖默认预览收到有效JPEG而frames目录为空、收据为空；随后控制开启记录可生成JPEG。历史数据不迁移、不删除。

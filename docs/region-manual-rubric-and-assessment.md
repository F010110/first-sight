# 人工可执行标准及本次审图判定 v1

## 评审性质和固定对象

2026-10-10。对象为 `region-partition-refined-eval.json` 的 `review-evidence` 分组，与旧基线相同。先明确规则，再按规则审查原图与真实轨迹并标注39对。本次评测员是AI助手，不是两名真人；已见过算法结果，**非盲、同开发录制、部分关系与算法输入重叠**。不能作独立精度证据或推广到未见环境。

本标准作为下一次真人盲评的固定规则。历史22标签不覆盖本次标准标签；二者结果不得混用。本次不修改算法输入或分组以迎合标注。

## 一、固定中等局部颗粒度

判定对象是观察者占据的活动范围，而不是当前面向的物体。我们选择：台面操作侧与入口通行侧应区分；设施近侧与穿过空地到达的远端墙角应区分；床前一小段同侧范围可以保持一个Place；门槛可为待定/连接区域。

这是产品评测约定，不是自然界唯一真值。若希望整间卫生间都叫一个Place，需要另设粗空间评测，不可事后切换定义以提高成绩。也不强迫马桶和洗手盆各自一个Place：同一个观察位置旋转看到两者必须兼容同一身份。

## 二、按顺序执行的判定规则

| 规则 | 标注 | 如何判 |
| --- | --- | --- |
| S1 同位置/纯旋转 | same | 实际轨迹与真实中间帧确认没有平移；姿态、画面、可见设施变化不影响地点 |
| S2 同局部足迹 | same | 观察者仍在同一稳定设施/床/台面侧或同一短通道范围；原图布局与路径支持局部重定位，没有换到边界另一侧。不能仅以“没看见门”证明 |
| D1 边界两侧 | different | 真实过门或从通道进入另一空间，且原图显示观察者侧改变；透过门看见同一物体不抵消边界 |
| D2 局部范围改变 | different | 原图与路径共同显示离开设施近侧/操作侧，到入口通行侧或空地另一端。需要观察者与结构的关系变化，不能单凭朝向、物体名称或米数 |
| U1 过渡/缺证据 | unknown | 无法确定局部边界、缺中间观察或细粗解释冲突；不勉强套same/different |

优先级：S1优先于当前可见设施标签；若证据自相矛盾，复核而不是同时保留same/different。S2不能无限传递成“A到B很近、B到C很近，所以整段都是一个Place”；要回查组首尾是否满足D2。每条标签注明帧和理由。

不使用“相距超过X米必分开”，不使用“同room必同组”，不以一张图的左/右替代观察者实际所在侧。先做判定，再看算法是否符合；本轮无法做到真正盲评，明确记录这一限制。

## 三、评分与通过标准

same被分为两个已支持组=误拆分；different被合组=误合并；任一端unresolved=拒答/未恢复，不当作判对也不当作明确误拆。unknown不计对错，另列待审。

每组都要满足：①内部无D1/D2成员对冲突；②没有S1/S2关联被无理由丢弃；③组首尾仍是一处局部范围而非仅有链式兼容。组级结果为通过/不通过/待审，不给任意加权总分。

本轮门槛：所有明确S1保持同组；明确D1/D2不能被合并；明显同范围回访/小移动不能一直拒答。颗粒度unknown可以保留，但必须指明具体观测。缺少相似不同区域等类别，整套验收记未完成，不因已测类别通过就上线。

## 五、按标准的判定

### 组1：W1–W4——不通过局部范围标准

W1贴台面操作侧，W4已走到门框/连接通道的接近位置；所有视图和实际移动说明观察者离开原台面边缘，而不是仅转头。按D2，W1/W4应分不同局部Place，但当前同组。**计1对误合并**。W1/W3是中间过渡，记unknown，不伪造精确切分点。

### 组2：W8–W12、W34–W38——基本合理，但整组待审

W8/W9/W10沿床前同侧小移动可保持同组；返回端点对应也一致。W12靠卫生间开口，W8/W12是否都算床前范围不够确定，记unknown。所以明确同侧部分通过，但不能宣称整组已获充分验证。

### 组3：W16–W30——不通过局部范围标准

W16/W17/W18处于马桶近侧的相邻足迹，换朝向看见洗手盆不需要另建Place。W22到达穿过空地后的终端墙角，近侧设施变成跨空地的远处上下文。按所选D2标准，W16/W22和W18/W22应分开，当前均同组，**计2对误合并**（同一过宽组的两个见证，不是两个独立错误事件）。

但W22/W23/W24都在同一个墙角位置，只转向，必须同组；本轮3对均通过。不能再按“马桶视图/洗手盆视图”把这些观察切开。墙角与近设施的具体过渡切点未知；本轮只断言两端应分，未规定中间所有点的唯一归属。

### 未知覆盖——不通过

原5对同位置漏关联仍在；新增S2的W6/W7通道内部、W15/W16设施接近范围、W30/W31返回范围，也都被拒答。W7/W8明确跨门、W10/W14明确不同空间，因某一端未知无法给出完整关系。unknown机制是诚实的，但缺少应有覆盖，不能算正确分组。

## 六、39对标签的结果

标签文件：`docs/experiments/region-judgments-local-scope-v1.json`。19对同位置检查之外，增加9对同局部移动、5对不同范围/边界、4对待定；包含原有2对不同空间检查。

| 人工标签 | 总数 | 算法正确 | 算法错误 | 拒答 |
| --- | ---: | ---: | ---: | ---: |
| same | 28 | 20 | 0误拆分 | 8 |
| different | 7 | 2 | 3误合并 | 2 |
| unknown | 4 | 不计 | 不计 | 2对有分组建议，2对拒答 |

35对确定标签：22对正确、3对误合并、10对拒答；判定覆盖25/35=71.4%。有输出对的正确率22/25=88%，**不是总体分组准确率**。同区域恢复20/28=71.4%，不同区域恢复2/7=28.6%。原同位置子集仍14/19，没有因为新增标签变成另一个数字。

这些对不是独立随机样本；一个错误组贡献多个错误对，重复路线也相关。不报告置信区间或把该比例推广到全部场景。similar-distinct类别仍缺失，两名真人一致性尚未评测。

## 七、结论

**按固定中等局部标准，当前不通过：2个组过宽，1个床侧组基本合理但入口范围待审，同时存在明显漏覆盖。** 原地旋转具体样本正确，不足以挽救整体可用性。

这比14/19更有判别力，因为同时包含该合与不该合的见证、整组首尾和unknown覆盖。台面/入口、近设施/远墙角之分依赖已声明的颗粒度约定；下一轮请真人评测员用同一规则复核，分歧保留unknown，不能把本轮AI意见包装成最终真值。

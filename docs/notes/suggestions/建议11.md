
查到了。确实有不少已经开放的数据集，而且有几个非常适合 First-Sight。

比起继续自己生成完全虚构的室内生活轨迹，我认为现在应该优先利用已有研究的数据。尤其是具有真实第一视角视频、跨时间重访、相机轨迹和空间标注的数据集。

不过，要注意三个不同概念：

- 开源模拟环境： 提供三维场景，可以自己控制摄像头生成任意轨迹。
- 开放真实数据： 提供真人佩戴设备采集的视频，但不能自由改变轨迹。
- 现成记忆 Benchmark： 已经设计了问题和答案，可以直接评估长期记忆算法。

对你们而言，理想情况是三者结合，而不是只选其中一种。

## 三、我建议 First-Sight 采用的路线

不建议立即把所有数据集整合进来。你们当前首先要解决的，是让模拟样本更真实，同时保证有可以信任的标准答案。

### 分阶段数据路线

[RoboTHOR Challenge 2020](https://images.openai.com/static-rsc-4/cXeLK9ClaDgtTbN6EOVXLTs3WOB54-8xobevppB0pGksDdNQ0JOjz9BjZcrMzFd8r5XVhjPq8ih98zQ-iTGkF1CRLJWypD0HVrE7a1WOv2InWG7-zOBlREsFbgSiO7n5YP4mG6FaWaxt3nIiK3XfUm-e3FA1pfbWgrp615yVdf4?purpose=inline)

第一阶段：ReplicaCAD / HM3D

利用现成 3D 场景生成三摄轨迹。先完成一个人反复进出房间、返回旧地点的 30–60 分钟样本，自动记录位姿和地点真值。

[Meta Introduces Aria Everyday Activities (AEA) Dataset: A Game-Changer for Egocentric Multimodal Data | Multiplatform.AI](https://images.openai.com/static-rsc-4/5QZdHN83hNHMfYde_xhYfiRgN0LEjgMbmw70QilQKoEAxoXYzHkOh73ywo4brYZj25z9PsGh5SjIuZj-rrTFXN6xHLe8y4hBqbARKyBsBV226FcRk-9wY_XrS_oF7T_GvGJTuzPhYAGEg1Z3_mBEGbC4wbwYsTX3w9LoIf8JYl8?purpose=inline)

第二阶段：Aria Everyday Activities

接入真实视频与定位轨迹，验证模拟实验中的结论是否可以迁移到真实采集数据。

[Egocentric computer vision - a giant leap](https://images.openai.com/static-rsc-4/6Gw6_M7HMSvfxyPNgXdnrPSF9LpSFIJ134b47johzLIc2wojEPxNg7y_XUUZS3ZbHUw2t2EO9KPtpMeVl1JrMYii5oVMJmVghl_g7njB6-Vzvx5g1d0RBlfNs0lWkMWDnBg4v-HB8wmmkVve3UYoyTph9VcGdoxCAEV0sYanDqY?purpose=inline)

第三阶段：EgoLife

扩展到多小时、多天的记忆任务，包括物体位置更新、活动回忆和用户习惯。

我还发现了一个重要的问题：你之前的模拟器虽然已经能生成路径和问答，却不一定能生成具有真实时间演化的生活事件。

例如，用户上午把钥匙放在桌子上，下午拿走，晚上又放进抽屉。

这样的题需要系统追踪状态变化，而不是只判断当前位于哪间房。

这恰好是 EgoMemory 强调的核心能力之一。

### 近期最合适的具体任务

我建议你们先不下载几百 GB 的数据，选择两个小型样本：

1. ReplicaCAD： 官方约 140 MB 的交互式公寓场景，用来验证三摄轨迹生成和自动标注。

   [image](https://www.google.com/s2/favicons?domain=https://github.com\&sz=32)

   GitHub
2. Aria Everyday Activities： 官方示例序列，用来测试真实数据接入。

验收标准也很简单：两种数据最终都能转换成你们现有的时间戳、三路图像、相机位姿（真实数据允许缺失）和问答标注格式。

先不要重写现有算法。 只替换数据输入，观察算法在更真实场景下的表现。

我认为这是你现在最值得推进的 First-Sight 工作：不需要硬件、不需要新增预算，而且能够直接提高现有评测的可信度。


我专门查了一下 2025–2026 年的相关论文，也重新看了你们 First-Sight 的 GitHub。

现在我倾向于一个比较明确的判断：

可以先把 First-Sight 做通，再决定具体研究什么。我甚至认为这比现在强行寻找一个新算法更合理。

但是有一个前提：你们要做通的是一个能够反复实验的长期视觉记忆系统，而不是急着把所有产品功能实现。

我查到一个非常关键的事实：你们想研究的「长期第一视角空间记忆」，在 2026 年已经有相当直接的研究工作，甚至包括顶会论文。 这既证明了方向有价值，也意味着你们需要认真考虑已有工作的覆盖范围。

## 一、目前有哪些明确的科研方向？

我把相关研究整理成六个方向，并按照它们与 First-Sight 的关系作一个主观评价。

| 方向                     | 已有研究进展                           | 对你们的价值       |
| ------------------------ | -------------------------------------- | ------------------ |
| 场所识别与重访定位       | SLAM、视觉地点识别等研究较成熟         | 中，适合做基础能力 |
| 长期空间记忆构建         | 已有结构化空间记忆和增量更新方法       | 高，但竞争明显     |
| 长期第一视角记忆问答     | 2025–2026 年出现多个大规模 benchmark  | 很高               |
| 记忆存储、检索与压缩     | 图像、文字、场景图等已有系统性比较     | 很高               |
| 动态环境中的记忆更新     | 已有方法，但仍存在长期一致性问题       | 很高               |
| 从模拟器到真实可穿戴设备 | 涉及低质量观测、传感器噪声和系统可靠性 | 高，但工程成本较大 |

这里有一个重要区别：

前两个方向更多是在回答「我在哪里、是否来过」；后面几个方向则是在回答「我长期经历过什么，如何正确地保存和使用这些经历」。

First-Sight 如果想走 Agent Memory 科研，我认为应该逐渐从前者转向后者。

而且，前者其实可以直接使用现有算法作为基础设施，没有必要坚持原创。

## 二、最值得了解的五项研究

### 1. UCS-Bench / DirectMe：与你们最接近的研究

[Keep It in Mind: User-Centric Continual Spatial Intelligence Reasoning in Egocentric Video Streams](https://proceedings.mlr.press/v306/wang26je.html?utm_source=chatgpt.com)

ICML 2026

170 多小时第一视角视频、8100 多个带时间戳的问题，提出 DirectMe，通过增量构建结构化空间记忆，追踪物体相对于用户的位置，并回答动态空间问题。

[image](https://www.google.com/s2/favicons?domain=https://proceedings.mlr.press\&sz=32)

Proceedings of Machine Learning Research

[代码](https://github.com/cocowy1/UCS-Bench?utm_source=chatgpt.com) · [数据集](https://huggingface.co/datasets/cocowy1/UCS-Bench?utm_source=chatgpt.com)

这篇对你们的意义非常大，因为它几乎直接研究了：第一视角视频输入、长期空间信息、实时位置与历史记忆的关系。

而且它不是只有论文，已经公开了包含深度估计、物体检测、分割、场景图构建和评测脚本的实现。

[image](https://www.google.com/s2/favicons?domain=https://github.com\&sz=32)

GitHub

+1

这意味着你们之前设想的「根据视觉观测增量维护物体与空间记忆」，已经有相当完整的先例。

我建议把它作为第一篇重点阅读、尝试运行的论文，而不是马上重新设计自己的空间记忆算法。

### 2. EgoMonth：长期生活记忆能否真正跨天保持？

[EgoMonth: A Month-Level Egocentric Video Benchmark for Long-Term Spatiotemporal Memory](https://arxiv.org/abs/2608.13113?utm_source=chatgpt.com)（2026 年 8 月）

这篇已经覆盖超过 300 小时、20 名参与者、跨 20–120 天的日常生活录制。

它将任务分为记忆模式整合、具体事件索引和多步推理等类别。最强受测模型 Gemini 2.5 Pro 的宏平均准确率为 71.8%，而经过修正的人类基线是 94.2%。跨视角空间推理、路线推理与方向判断尤其困难。

[image](https://www.google.com/s2/favicons?domain=https://arxiv.org\&sz=32)

arXiv

它说明的不是 VLM 完全不会记忆，而是长时间的视觉历史中，某些信息依赖关系仍然难以维持。

你们正在构造「一天校园生活」，本质上也在尝试这一方向。不过，EgoMonth 已经将尺度扩展到了数十天，因此单靠视频时长很难形成差异。

### 3. MeMoREval：到底应该让 Agent 记住什么？

[What Should Embodied Agents Remember?](https://arxiv.org/abs/2610.12561?utm_source=chatgpt.com)（2026 年 10 月 8 日）

这是一篇新预印本，我觉得在研究问题设计上很值得借鉴。

作者在四个模拟室内环境、53 项任务上，比较保存原始图像、文字描述、场景图等记忆方式，并同时测量记忆写入和查询的推理成本。

尤其值得注意的是：作者尝试有选择地保存图像，但在报告的实验设置下，压缩存储量通常会降低任务成功率。

[image](https://www.google.com/s2/favicons?domain=https://arxiv.org\&sz=32)

arXiv

+1

这里有一个很明确的研究问题：

> 当 Agent 还不知道未来用户会问什么的时候，它应该选择记住哪些视觉信息？

这比「怎么把房间分得更准确」具有更普遍的研究价值，而且不一定需要庞大硬件工程。

### 4. EgoLife：真实生活中的超长时序记忆

[EgoLife](https://egolife-ai.github.io/?utm_source=chatgpt.com)

记录六名参与者一周的共同生活，每人约 50 小时，包含第一视角视频、注视信息、IMU、多视角摄像头及环境三维扫描，还提出了 EgoLifeQA 和 EgoRAG。

[image](https://www.google.com/s2/favicons?domain=https://egolife-ai.github.io\&sz=32)

egolife-ai.github.io

它的意义在于：长期记忆评测不仅可以评价系统记住了哪些信息，还能评价它如何从大量历史记录中定位证据。

这也说明，你们未必需要先自己采集大量数据，完全可以从已有数据集上寻找问题。

### 5. LMEE-Bench：记忆能不能让 Agent 越来越熟悉环境？

[Explore with Long-term Memory](https://openaccess.thecvf.com/content/CVPR2026/html/Wang_Explore_with_Long-term_Memory_A_Benchmark_and_Multimodal_LLM-based_Reinforcement_CVPR_2026_paper.html?utm_source=chatgpt.com)

CVPR 2026

这篇将长期探索、记忆问答和多目标导航连接起来，提出 LMEE-Bench 与相关强化学习方法。

其重点不再是单纯回答历史问题，而是让 Agent 过去的经验真正改善后续行动。

[image](https://www.google.com/s2/favicons?domain=https://openaccess.thecvf.com\&sz=32)

开放获取计算机视觉基金会

这条路线更接近传统具身智能，科研价值明确，但需要更复杂的交互模拟器及导航评测体系，暂时不建议你们优先投入。

## 三、那么 First-Sight 还有什么可以具体研究？

我认为比较现实的是下面三个课题。它们都不是我能保证新颖的原创 idea，而是目前有明确实验切入点的候选研究问题。

A. 长期记忆的错误修正与一致性

最契合现有积累

你们已经遭遇过区域错误合并、边界判断失败和错误身份传播。

一个具体问题是：过去把两个教室错误地认成同一个地点，后续证据证明它们不同，系统如何修正已有记忆，包括此前关联的物体、事件和历史查询结果？

可以比较只追加记忆、事后纠错、带来源证据与版本的可修订记忆，衡量错误传播范围、纠错后问答正确率及计算成本。

B. 有限预算下的视觉空间记忆

实验成本较低

面对一天的连续观测，Agent 不可能无限次调用 VLM，也不应该将全部图片永远放在上下文中。

一个具体问题是：在固定视觉 token、存储量和 API 成本下，应该按时间均匀采样，按视觉变化保留关键帧，还是优先保存重访地点和物体状态变化？

这里可以直接与 MeMoREval 等工作的设置对照，避免重复已有结论。

C. 不可靠定位下的长期空间记忆

硬件特色明显

在只有前、左、右三个摄像头以及不稳定方向信息的情况下，系统能否跨时间保持地点身份稳定，而不依赖准确里程计？

可以比较单摄与三摄、是否使用方向信息、采样频率和误差水平，研究这些因素对重访识别和记忆问答的影响。

不过，视觉地点识别和无定位建图本身已有大量工作；必须证明这里存在不同于传统定位任务的长期记忆需求。

其中，我最关注 A。

不仅因为你们已经有实际失败案例，而且因为「错误的空间结构如何污染整个长期记忆，以及后续能否撤回」是一个可以把工程中的真实困难转化成研究假设的问题。

不过，A 的前提是先研究已有的可修订记忆和动态图方法，不能把给数据库添加版本号直接当成科研创新。

## 四、我建议先把项目做通，但要重新定义「做通」

我重新看了你们仓库的 [TODO.md](https://github.com/F010110/first-sight/blob/main/TODO.md?utm_source=chatgpt.com)。截至目前公开的 10 月 12 日研究快照，已经有离线空间分组、人工审核和一系列失败实验，但长期历史身份匹配、真实头盔采集、长期记忆调用仍未形成完整验证闭环。

其中 val4 的 44 个粗粒度核心查询达到 44/44，但边界只有 4/13 被检出，val5 也没有完成独立人工审核。

[image](https://www.google.com/s2/favicons?domain=https://github.com\&sz=32)

F010110/first-sight · GitHub

+1

这意味着，现在继续追求更复杂、更准确的区域划分，可能会让你们长时间停留在一个局部问题上。

我建议将下一阶段的验收目标缩小为：

输入一段长时间第一视角记录，系统可以持续记录经历，在重访场景时利用历史信息，并回答具有明确证据来源的记忆问题。

为此，只需要一个最小闭环：

第一视角视频

模拟器或真实头盔

关键帧与观测记录

时间戳、原图、可选位置假设

可持续更新的长期记忆

历史存储、索引、证据关联

检索 + VLM 问答

答案、证据来源、不确定性

这里甚至允许暂时不实现可靠的场所分组。把空间结构当成可选信息，而不是整个系统的硬性依赖。

下一轮测试也不必一开始就做完整的一天校园生活。先用一段短而有重复访问的轨迹，专门加入相似地点、跨时间重访、物体状态改变等情形。验证闭环后再扩展为一天。

我建议采用下面的顺序：

1. 先跑通最简单的长期记忆系统。 原图、时间戳、持久化存储和检索必须可靠，能够跨程序重启保留信息。
2. 建立小规模人工标注评测。 例如 50–100 个问题，要求答案能指向具体历史观察，并记录错误和合理拒答。
3. 让朴素方案先跑。 比较均匀关键帧检索、文字摘要检索与结构化空间记忆，在相同证据预算下的效果。
4. 再接入硬件。 将真实三摄图像导入同一测试流程，检查模拟器与真实世界的差距，而不是立刻大规模采集。

前两步完成，你们就有了开展科研实验的基本条件。第三步的结果会告诉你们，哪些复杂设计实际上有价值。

## 五、你们目前最应该避免的事情

我觉得有两种极端都不适合你们。

一种是现在就为论文强行发明算法。你们已经在区域分组问题上付出过不少成本，继续这样做很可能重复之前的过程。

另一种是说「先把整个产品做好，然后科研自然会出现」。这同样危险。一个完善的产品可能涉及几十个工程问题，而不一定产生值得发表的研究问题。

我的建议是：先暂停追求算法创新，但不要暂停科研式的实验与评估。

你们其实已经拥有一项重要积累——大量失败试验，以及比较严格的实验记录意识。比起继续加入新功能，我更希望你们把这部分积累转移到长期记忆问答上。

至于方老师，我认为现在就可以沟通，不必等到有论文 idea。可以重点讨论这件事究竟适合作为两个人的课程项目、实验室的研究原型，还是有条件建设一个长期第一视角数据平台。后两种情况对资源和人员的要求完全不同。

## 最后，我对你们下一阶段的建议

接下来两三周，我会优先选择：

70% 精力完成长期记忆最小闭环，30% 精力阅读 UCS-Bench、EgoMonth 和 MeMoREval，并在已有基准上尝试实验。

不是因为我认为工程比科研重要，而是因为你现在很缺一个稳定的实验对象。First-Sight 的代码已经积累得不少了，但还有一些最有研究价值的核心能力没有得到验证。

有一个问题也值得你重新考虑：First-Sight 不一定必须拥有原创的空间记忆算法。 完全可以把成熟的视觉定位、场景图、VLM 检索方法组合成系统，然后在长期记忆更新、选择性保留或者跨时间一致性上寻找新的问题。

这样也不意味着此前的算法探索白费了。

如果做通最小系统之后，朴素 VLM + 检索仍然能解决你们所有的任务，那么也许应该承认 First-Sight 更适合作为工程项目，科研可以转到已经具有成熟 benchmark 的其他问题上。

我的核心判断是：现在不需要决定 First-Sight 最后能不能发论文。先让它成为一个可靠的实验平台，再用实验结果决定是否值得继续投入科研资源。

你已经花了不少精力寻找 idea，现阶段与其继续在脑海里判断方向有没有希望，不如让一个真正可运行的长期记忆系统提供证据。

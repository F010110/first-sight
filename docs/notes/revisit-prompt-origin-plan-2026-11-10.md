# 用户重新授权：从错误源头检验提示词

这是用户在两轮停止后明确要求的有限新诊断，不是自动续跑旧调参。目标是给出当前模型/预算下提示词是否足够的工程结论，不声称一份有限实验能决定所有VLM、所有提示词的理论能力。

**已完成并收束：三组均未达到完整要求，提示词修改不足，不采用、不继续调参。** 具体原始证据与结论见[结果报告](revisit-prompt-origin-results-2026-11-10.md)。

## 固定实验

- 起点：原813请求0048、版本57错误提交以前；不加载后来的错误提交或压缩摘要。
- 修复图片交付条件：当前641/660和历史580三摄同轮可见；各提示词组图片完全相同。先修交付，再比较提示词，不把交付改善冒充提示词效果。
- 三组：原有规则基线、明确锚点/布局对应、反例/证据不足核查。共同输出可审查associationChecks与完整segments，不输出隐式思维链。
- 每组重复2次；原错误批641–660→使用该分支结论解释下一批661–680；另加380/65真同地点正对照，防止全部拒绝就得高分。
- 同模型qwen3.8-flash、thinkingBudget128、3000输出；总模型请求最多24，估计费用上限$1.20，最多一次inspect续轮，原始输入/失败保留。
- 原图/hash、事实、旧模型身份记录可交付，地图/坐标/人工参考答案不交付模型。事后只读地图审核，不另起付费裁判。
- 诊断分支使用显式临时别名，不伪造数据库真实ID/commit receipt。不是完整持久Pi/SQLite端到端认证。

## 结果前冻结判定

只有某提示词组两次均：不虚认660/580、680/100、680/440为同一具体占据区域，正确接受380/65真实同地，且完整分组无明确空间矛盾/无根据转场、没有以全部new或全部insufficient回避任务，才算该提示词在本组已知错误上有效。两次同组结果不稳定则不算解决。范围/ID差异不作错误。处理时间另报；若语义改善却不满足预算，结论明确区分。

如果基线也稳定通过，只能归于干净起点＋同轮证据足以改善，不能把功劳独归新提示词。若更强提示词不能稳定通过正负对照，工程结论是“当前路线不能靠此次提示词修改解决”，停止推广，不再把实验数量增长当进展。除本计划请求外，不自动扩题、换模型或继续无限试提示词。

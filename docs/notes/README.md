# 建议与笔记索引

本目录保存**外部建议与研究笔记**，是线索来源，不是当前架构或状态：架构看 [docs/active/README.md](../../active/README.md)，状态与待办看 [TODO.md](../../../TODO.md)。

## 结构

| 路径 | 内容 |
|---|---|
| [suggestions/](./suggestions/) | 按编号归档的建议与调研；编号越大越新，历史结论可能被后续建议推翻 |
| [spatial-memory-design-and-references.md](./spatial-memory-design-and-references.md) | 当前空间记忆完整设计（分层表）＋ StreamMind / DirectMe / EventMemAgent 对照与可借鉴项 |
| [discussion.md](./discussion.md) | 讨论记录 |
| [draft.md](./draft.md) | 草稿 |
| [review-notes-1.md](./review-notes-1.md) / [review-notes-2.md](./review-notes-2.md) | 审阅笔记 |

## 使用约定

- 建议里的判断不能直接当成设计决定；采纳前先走 `docs/active` 的变更流程，并在 TODO 记录批准范围与验证结果。
- 编号建议按日期理解，旧条目不会被静默改写；若与最新用户决定冲突，以用户最新明确要求为准。
- `suggestions/README.md` 维护逐条主题索引。

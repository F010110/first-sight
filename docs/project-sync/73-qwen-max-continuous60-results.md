## 已知失分与核查

Max标出21条负面记录，涉及12帧，其中4条来自前两轮一致、17条经第三轮确认。同一事实可能同时出现在摘要和观察列表，所以21不等于21个独立错误。以下关键例子另经本助手直接查看原图复核（不是独立人工金标准）：

| 帧/方向 | 实际输出问题 | 原图核查 |
|---|---|---|
| 65/front | 把门前地面说成浅色瓷砖 | 门前为混凝土，瓷砖在门内；边界外推错误 |
| 84/left | 把暗处门说成敞开门洞 | 可见关闭门扇及底部通风口；开闭状态错误 |
| 106/right | 把右上彩旗说成信号灯杆和红灯罩 | 可见三角彩旗与细线，不是灯具 |
| 111/front | 黄色双实线/中央黄线分车道 | 图中黄色线在路缘，中央为白色虚线；标线数量及功能错误 |
| 115/right | 三个蓝色遮阳篷 | 可见两个，中央入口没有第三个 |

其他自动负面候选包括招牌/路牌/横幅误读、货架结构和建筑层数。OCR方面裁判对“正确替代文字”也有幻读：106横幅实际可读为100 years festival，而Max提出过106 Segues Festival等错误替代文本；63路牌的替代读法不同轮也不一致。因此不能因为它们一致指责Flash就把裁判给出的正确答案当金标准。保留为需精确复核的OCR候选，不将自动21条全当人工确认。

此前被怀疑的桌腿和球形灯罩不在此次确认失分清单，说明原Flash裁判确有误报。

## 分数解释与剩余盲区

当前机制足以比旧单次Flash评分更有依据地定位开发问题；**仍不能声称基本正确率得到统计证明**，尤其同一个Max多轮可能重复同样错误，仲裁也可能被已有意见影响。下一步需小批原图人工校准和代表性控制集，而不是因94.6就批准完整系统。

未测：远距离重访；长干扰后召回；相似但不同地点的身份区分；完整813时刻的压缩/恢复稳定；地图与路径连通、定位和导航安全；真实问题agent及15/37门槛；独立人工标签下评分器的误报率/漏报率。

未来可用两个较长连续片段（如60—119与350—409，包含71/385对应场景）。若省略中间经历，只测试跨时间稀疏保持；要测试长期干扰必须保留完整中间前缀状态。当前未启动新记忆生成。

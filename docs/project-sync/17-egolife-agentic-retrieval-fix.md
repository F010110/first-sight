# First-Sight自主检索与取证协议修复：同一记忆重答

## 用户要求与定位

用户指出，搜索“马克笔”无命中时，VLM应该能推测可能的历史地点，再主动浏览该地点或时段，而不是机械重复关键词；取证也不应强制通过关键词命中这个形式步骤。要求修复并重跑。

旧实现不是完全没有Agent：模型可以发search/inspect/answer动作，但搜索只有摘要字符串包含匹配、无历史地点总览与时间浏览，且每次只给最后一个工具结果。历史肯定回答还强制要求关键词search命中再inspect，连已经交付的当前历史原图也可能被拒绝。16号报告的0/10正是在这条旧路径上产生，保留不变。

## 修复内容（生产原生问答组件）

修改`src/hardware/realtime-question.ts`，没有另起临时RAG或修改官方题目：

- 初始上下文提供历史地点、区域、已标注帧数量和时间范围，附真实代表原图ID、全时段均匀时间轴。
- 新增`overview`动作，以及按`placeId/afterMs/beforeMs`限定的`browse`，支持均匀抽样、顺逆时间顺序和游标。
- 保留字面`search`，同时纳入原空间判断的layoutEvidence/retrievalQueries等可用提示；不把它伪装成语义向量搜索。
- 模型自己决定检索假设、地点、时间范围、查看对象及是否继续缩小范围。提示明确：物品可能出现的地点只是搜索假设，不能直接作为答案事实。
- 保留最近8步动作、工具结果和notes，反馈重复查询次数；空命中时明确提示换地点或时间浏览，而非机械重试。
- `inspect`允许查看因果快照中任意真实可用原图，不再强制先关键词命中。时间轴、recent、地点概览中的ID均可直接查看。
- 已交付当前图片也是实际看过的历史证据。最终引用仍只能来自实际交付过的原图；未查看的ID、未来原图、未可用判断不能进入证据。
- 图片使用最多12张的滚动窗口，不再把累计看过12张当终身上限；实际查看过的ID保留，允许重新inspect比较。
- 每题最多16轮，最后一轮要求回答或拒答，不再继续发起无后续查看机会的搜索。

这仍然是“模型自主规划＋确定性工具执行”。没有让工具自由编造语义匹配，也没有移除原图证据要求。地点推断不是连续停留或物品存在证明，提示明确其限制。

## 回归验证

构建通过，23项相关TypeScript测试通过。新增测试覆盖：

1. 物品英文关键词无命中后，Agent可改查中文地点、浏览并查看原图；
2. 不经关键词搜索的直接inspect合法，但未看图引用仍被拒绝；
3. 初始实际交付的当前历史图片可合法引用；
4. 未来图片与晚于截止时刻的判断不进入概览和取证；
5. 图片滚动窗口不超过12张，同时不丢失真实已查看记录；
6. 重复空查询保留历史与换策略反馈；
7. 只读SQL复用基线记忆，因果快照和不可写限制均生效。

测试只验证工程协议，不算benchmark正确题。

# 怎样得到真正准确率

## 最新讨论结论【建议，尚未实施的新测试集】

用户要求知道当前方法准确率。助手建议分层测试，以**端到端任务准确率**为主，不再用几何74/74或连续性190/190代替。

### 第一层：无位姿视觉定位

- 仅给当前原图与历史图像记忆，不给当前pose/yaw/真实地点ID。
- 包含不同时间/朝向同地、外观相似异地、真正离开再回来的重访、未在记忆中的未知地点。
- 地点正确率＝正确地点题数/全部定位题；另报误定位率、拒答率，不能只报已回答部分。
- 已有0.5秒邻帧题只能冒烟，不是主要准确率证据。

### 第二层：已知位置的路线与说明

隔离定位影响。程序路线必须合法连接起终点，按产品策略允许可逆边反向；角差与程序标准一致。语言必须不左右颠倒、不把转身写成倒退、不造门/台阶/通路，对人体朝向及当前通行未知作正确限定。

语言需提前定义允许事实、必要步骤、禁止事实及评分规则；可自由表述，不逐字匹配模板。程序检查结构，人工盲审地标与语言；若用另一VLM只能作为辅助，不是唯一真值。

### 第三层：端到端主任务

输入历史记忆、新当前图像、用户目标。系统自行执行视觉定位→程序选路→Agent说明。

整题正确需：起点正确、目标正确、路线有效、关键方向/步骤/地标正确，缺必要信息时请求确认。

**端到端准确率＝全部条件正确题数/全部题数。** 同时报严重误导率（误定位、错向、编通路、倒退等），不能让平均分遮掩。离线任务准确率也不等于现实出行安全率。

# 生活地图需求与首轮候选

2026-10-29。用户已确认GMod三摄移动视频可用，要求先明确换什么地图、能实现什么。本轮只核查公开元数据，**未订阅/下载地图、未启动游戏**。

## 1. 要的是可生活的完整街区，而不是最大空城市

硬条件：

- 原版现成地图中有正常居住空间，不用自建粗糙几何替代；至少一套带家具的住宅，卧室/客厅/厨房或可辨识生活区域、实际楼梯与上下层。
- 同一地图能正常走过住宅门口→街道→可进入商店/公共建筑→返回；不能用传送/换地图伪装连续。
- 正常步行尺度，足够形成不同路线、停留、掉头、重访。优先紧凑多用途街区，不为“城市大”牺牲室内丰富程度。
- 日常桌面/柜台/地面可放置少量真实可见物品；家具可以是静态布景，但必须清楚哪些可以交互。不要求所有物件可拿起。
- 白天光照可辨物，住宅不是空壳；缺失纹理、ERROR模型、严重LOD消失或持续过暗均不通过。
- 本地单人Sandbox可用，不依赖公共RP服务器、职业经济/武器/任务系统；继续沿用无HUD、无枪及安全无键鼠采集。
- 地图/依赖/资产许可分别核查；Workshop可订阅不自动意味着科研数据可再分发。

暂不要求一次具备完整学校、办公园区、全城NPC、真实做饭洗漱动画。第一包要服务First-Sight在线生活助手，而非只扩展空间导航题。

## 3. 能实现什么：按证据分层

### 已实测、预计换地图可复用但仍需回归

- 无枪/HUD的三方向图像导出、位姿/时间记录；约一分钟正常步行与转向，程序指令而非OS键鼠。
- 同回调三路渲染、约4.6Hz实际采样、原时间间隔的视频及原网页回放。复杂地图可能降低频率，需重新测，不承诺同帧率。

### 地图验收后可直接开展

- 室内外连续经历、房间/楼层/商店辨识、出门返家、不同路线重访。
- 原本在哪里看过物品/标志、某时段到过哪里等视觉记忆输入生成。

这仅指能够生成输入，不等于First-Sight已能正确回答，正式题目与gold需独立冻结。

### 需要我们补一个小型生活状态层

- 选少量杯/书/包等合法可用的3D物件，给独立持久ID；普通交互键拿起/放下或脚本移动，无需枪、机器人抓取或完整人体动画。
- 记录可见拿放、物件前后姿态、遮挡、观察者视角及时间；放下→离家→返回仍在原位。
- 独立保存对象ID、模型、位姿、属性和事件；保存/重启后按真实场景恢复。不能把EntIndex当跨会话身份，也不能只保存背包菜单数据。
- 支持重复外观物品、相似房间、重访期间物品被移动，产生真正需要长期记忆的对照问题。

地图中的静态家具/贴图未必是物理实体，不能承诺任意家具可拿。可以保留原装内装，只增加少量生活小物和事件，不另造整个城市。

### 仍未保证

全城市居民作息、任意商店交易、自由做饭洗漱、任意家具物理、跨地图无缝、天气/昼夜动态控制、严格运动对象三摄同步，以及公开数据发布许可。固定day/night地图不是已实现动态昼夜。长时间运行必须有实际路线和新事件，不能拉长短片时间或重复片段冒充一天。

## 4. 首轮验收路线与止损

先验收一张地图上的**卧室/楼上→楼梯→客厅桌面→出门→街道→商店→返回同一住宅**，三摄原图和视频继续放原网页。先看真正室内家具和连通，不先做全城漫游或NPC。

再用一个物品完成**桌面放下→离开→重访找回→换到另一位置→保存/重载验证**。物件与事件真值只给生成/评分侧，不泄漏到在线Agent输入。通过后再扩展多物品、多次外出和更长时间。

拟定下一轮有界范围：只装一张地图，不订阅合集；优先UnionCity Day，地图及必要依赖计划总量不超过2GB、安装新增预留8GB，至少保留20GB空闲。**这是执行建议，不是已获得新下载授权或实际占用保证**。发现额外付费依赖/超过预算/严重空屋即停并报告。本轮没有下载游戏资产。

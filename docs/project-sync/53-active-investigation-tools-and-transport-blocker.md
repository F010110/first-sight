# 主动调查能力扩展与真实小样本阻断

用户要求继续按“Agent主动调查、工具只提供线索”思路迭代，时间效率可放宽；确认无问题后才做大规模测评。本轮没有放宽来源/因果/费用边界，也没有降低原15题准入门槛。

## 发现并修正的类似问题

上一版虽然移除了直接locate，但仍有主动性瓶颈：只准一次调查、报告不完整后不能补查；只能翻页，难以主动跳转线索；较早事实退出上下文后不易重读；没有显式展示未读范围。

现在`memory-investigation-question.ts`支持：

- `find`：最多6个字面词、any/all匹配、按时序分页返回原描述预览；只是线索，不理解第二家、身份或进入次数。空查明确建议改词/翻时间线，不代表系统无记录。
- `around`：从已返回引用展开前后原记录，检查接近/进入/离开和局部属性。显示源时钟间断，不把时序相邻当同地点。
- `coverage`：显示指定范围已读/未读记录、未读区间和源时钟间断；返回的未读区间起点可继续around或read，不自动认证事件覆盖。
- `recall`：完整重读已返回线索/已读事实，找回滑窗之外的证据。
- 保留timeline、read、inspect；判断目标、候选进入、反例与身份比较由调查Agent完成，不交给机械函数。
- 最多三次可续查委托，成功调查后沿用已读记录、预览、图片和工作笔记；答题Agent可因缺少比较另一方、属性或反例而继续调查。发生提供者失败则不反复启动同一个失败请求。
- 每次调查32轮（原20），答题最多6轮，总计最多102个模型请求，仍共用原调用/费用账本。放宽时间不是无限调用或新增预算。

## 本地验证

新增脚本响应回归覆盖：空字面查询→换词→around补读→coverage检查→recall重读→不完整报告→第二次续查并复用证据→比较报告。它证明工具链可走通，不证明真实模型已具备所需推理能力。

最终完整`npm test` **477/477通过**，还包括真实别名/HTTP适配器的双会话端到端测试（HTTP与模型响应由本地mock提供），验证格式、来源别名和计费账本，而不是云端识别准确率。

- 此前三轮USD0.3243112176；本轮封顶答题USD0.05、评分USD0.025，最坏合计USD0.3993112176，仍在原USD0.40帽内。
- 结果`run/unioncity-investigator-smoke-v1-run1/`：前两题HTTP 400，第三题被预算保守预留拒绝，0个有效答复。**不是模型语义准确率0%，也不能据此判断调查推理有效或无效。**

## 修复及为何没有立刻重试

- `spatial-json-vlm.ts`现在在JSON-object传输模式统一追加固定JSON输出要求，不再依赖每个业务prompt恰好含有JSON。text模式不加，保持原文本描述协议。
- 增加提供方契约回归，以及真实`aliasedSpatialRequest`→`spatialJsonVlm`→HTTP(mock)下答题→调查读取→调查报告→答题的四调用集成测试，验证usage结算且未知预留0。
- 修复发生在真实试验之后，旧请求/HTTP错误/失败分支全部保留，没有覆盖或偷偷重跑。
- 前两次HTTP 400没有用量信息，保留**2笔未知调用预留USD0.0356304**，没有擅自认定免费或清零。
- 原三轮已结算估算USD0.3243112176，本轮新增保守未知预留USD0.0356304，账本合计**USD0.3599416176（含未知预留，不是实际账单）**。原总帽仍USD0.40。历史累计账本含预留USD0.9511506744/1408次调用尝试，未知2。
- 后续评分脚本只保存3个执行失败结果，未调用裁判；输入审计检查2份实际请求的来源/时间等所查项无错。没有Agent语义结果可评分。
- 未知费用未核清前停止新增付费调用，不借“可放宽时间”推断可绕过费用边界。当前没有后台付费任务，未进行大规模测评。

## 当前准入判断

仍是**不放行**：主动搜索路径及传输修复有本地验证，但真实调查轨迹尚未验证，原15题质量/来源/保留控制门槛更未通过。后续须在用量明确后先跑真实小样本，检查主动换线索、连续读区间、反例与图片核查是否实际发生，再讨论完整15题和90题。不能将477个本地测试或三题机械执行失败解释为大测就绪。

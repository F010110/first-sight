# 经历组织与评分拆分：第一版实现和零调用验证

承接用户“开始做”。本轮主线仅记忆组织、检索与评分；不扩展其他专项，不修改旧样本、旧运行或旧评分，不启动付费模型。

## 已实现的记忆底座

`src/assistant/organized-experience-memory.ts`新增独立SQLite组织库，复用`segmentExperience`的可修订时序解释契约：

- 原始描述、提取结果JSON、原图路径/哈希、发生时间、源时钟、实际可用时间、来源版本独立保存，不被组织摘要覆盖。重复导入幂等，内容变更拒绝覆盖；允许提取结果晚到，查询按事件时间与知识可用时间双重过滤。
- 组织修订独立追加，保留边界及事件/实体/关系断言。历史查询只使用当时可用且证据截止未越界的修订，不把后来确认的边界泄漏到较早提问。
- 片段与物理地点身份分离；相似外观不会自动合并两次经历。允许合并/拆分、未知身份及候选边界，旧片段引用在修订后明确失效而非偷偷重绑定。
- 事件索引返回“有支持记录中的顺序”和覆盖不完整标志，绝不把片段序号当第几次进店；原始模型描述未证明进入事件时不自动创建已确认事件。
- 索引只读模式固定SQLite读事务，问答不写组织库；未来组织器仍可用同一修订API写入，但持续生产同步尚未接入。

## 检索与显式运行时接入

- `locate`先按经历候选检索，支持relevance/earliest/latest和时间范围；earliest排序使用真正匹配事实的时刻，不用整段起点伪造最早证据。结果返回来源、匹配区间、候选提示和未满足的证明条件。
- `retrieveFacts`再在已定位候选内取属性事实，避免直接从全库挑一条最像的描述。类别/别称线索只是候选特征，不是实体身份断言。
- `events`按有来源事件查时间顺序，不无条件宣称完整事件覆盖。
- 问答适配增加`memory.locate`、`memory.facts`、`memory.events`；每次返回的事实必须与本题不可变快照中的原始事实逐项一致。未定位不能猜经历ID，未交付不能引用；原图回看继续沿用来源门禁。
- 工厂显式新增`questionPolicy:'organized-context-v1'`及`organizationPath`，只读打开组织库并在问答后关闭。旧策略与默认行为不变。

该实现不等于已经完成可靠语义记忆：第一版语义候选仍用可审查的通用类别词汇和词项匹配，没有验证过的向量/语义召回组件；也没有把旧视觉关联框架所需的匹配证据凭空补上。

## 评分拆分已实现

`src/sim/evaluation/split-question-review.ts`把裁判输出拆为独立语义审查与记忆通道审查，分别保存原始错误：

- 语义审查有效、通道判断错误时，保留语义分，但机制结论标未评分；不把oracle图偷偷“修成”memory证据。
- 主张摘录不是实际回答子串时语义审查仍失败；不能替模型补比较或正确细节。
- 已完成回答的无效审查返回`utility:null`，不是0；执行失败仍明确为0。
- 汇总保留全部计划题分母。有未评分项时不报单一精确分数，仅报告覆盖及缺项导致的区间，并明确区间不涵盖裁判自身判断错误。
- 对已知可回答问题的拒答不能因诚实而直接获满分；错误目标、重复题干、错误附加主张和明确通行许可按固定规则处理。真正歧义题可独立标注，避免唯一私有参考强判。

`src/sim/evaluation/review-saved-pilot-grades.ts`对之前37个保存的裁判原始响应做零调用重解析，新增结果：`run/unioncity-repair-pilot-v2-split-review1/`。

- 有效语义审查由原来26项恢复为34项；8项原本仅因记忆通道错误而被整题丢弃，现在语义与通道分别保留。
- 仍有3项语义摘录等问题未通过；不伪造分数、不把未评分当错误答案。
- 恢复的是评分流程中的信息，**不是让模型回答变正确，更不是把裁判校准成34/37准确率**。全部是同一批原始裁判判断，旧答案、旧自动分和旧响应均不覆盖。

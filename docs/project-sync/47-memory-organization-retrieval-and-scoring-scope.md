# 主线收敛：记忆组织、检索结构与评分修复

用户最新决定：组织和检索都有明确不足，需要合适的组织结构；评分缺陷必须修复。其他问题暂不做专项扩展，只维持鲁棒性底线。本节覆盖报告46的分散改进候选，不继续以零散提示修补代替记忆设计。

## 已核查的实现差距

- `ThreeAgentStore`可靠保存观察、事实、来源、版本和待核查关系，但当前`finalizeObservationFacts`主要原样提交独立提取结果，跨观察关系只记待核查。
- `causal-memory-index.ts`的固定20秒块只是搜索分页；不能表达一次经历、进出事件或重复访问。
- 仓库已有`experience-segments.ts`、`segment-interpretation-store.ts`、`experience-graph.ts`、`visual-experience-memory.ts`的可修订片段、身份关联和证据保留框架，可复用契约和测试。
- 上述旧框架依赖边界、匹配等输入；当前fact-first问答分支未具备这些完整输入，不能仅import旧类就宣称已自动组织好访问记忆。需要明确、因果、带来源的组织层适配。

## 组织结构选择

不是“按42个参考场所建目录”，也不是把全部文字换成向量库。采用**按时间组织经历、按事件/实体交叉索引、始终可下钻原始证据**的结构：

### 1. 原始证据与事实底座

观察/原图不可改，事实保留原文、来源、发生时间、实际可用时间、提取版本。组织摘要不得覆盖原始事实，也不能因为压缩抹掉矛盾。该层继续复用现有SQLite及哈希档案。

### 2. 可修订的经历片段

片段描述连续经历，维护起止区间、代表证据、变化/物品/区域线索、摘要及开放/不确定状态。由已发生的证据组织，可合并/拆分、保留修订历史；缺边界证据时保留候选或不确定，不强制命中某个物理房间。

**经历片段不是永久地点身份**：同一地点的两次到访必须保留为两次经历，不能合并掉先后顺序；一段经历也允许含区域过渡。

### 3. 事件、场所候选与物品交叉索引

- 事件线：进入/离开区域、观察到门态变化等有证据的事件，连接前后片段，保留时间区间与确认程度。
- 场所/物品线：使用暂名、属性、别称和来源索引；跨经历“可能同一”“已支持同一”“有矛盾”分开记录，不按同装修直接合并。
- “第几家店”应查询**符合店铺进入条件且有支持的事件顺序**，不是数第几个片段或第几个时间块。事件漏检或指代不确定时不能编造序数。

短期context仍是有界近期工作视图，长期结构在持久层。不能把长期概览常驻context，再宣称长期题不查库也证明了memory能力。

## 检索方式

从“全文搜几个词”改为两阶段：

1. **定位经历/目标**：解析公开问题中的时间、次序、场所/物品及关系约束，结合时间索引、语义候选和事件线召回。比如“最开始等车”不能只按“长椅”找最相似描述。
2. **提取属性/比较证据**：在候选经历中检索对应对象与属性，必要时回看原图；跨访问比较保留两次独立来源。

检索返回应包括命中理由、目标时间范围、实际证据、尚未满足的约束。语义相似度用于候选发现，不用于证明同地点/同物品。候选多样化按经历与来源做，而不只按固定秒数去重。

语义索引可以替换和比较实现，不把“引入向量库/图数据库”本身作为目标；先验证组织契约、查询行为与旧证据兼容，再决定必要的语义召回组件。

## 评分修复

拆开三类职责，避免一个自由JSON结果同时决定所有结论：

1. **程序审计**：因果范围、实际交付、检索/引用通道、context/memory/诊断原图区别、失败和缺项。
2. **语义核查**：问题目标、实际答句中的事实、证据是否支持；必须逐字引用候选答句，允许多个受支持答案，不给私有参考多写的条件额外权重。
3. **程序汇总**：按冻结规则计算；裁判未完成或结构无效标“未评分”，不能当答题0分或从分母移除后报高准确率。答题执行失败仍记0。

具体修复要求：

- 语义评分有效、记忆通道判断无效时分别保存，不能因把oracle图误作memory就丢掉整个语义审查；也不能自动把错误通道修成合规。
- “当前没看到、memory禁用所以不知道”不因诚实便对本可回答的历史问题给满分。诚实程度与任务完成程度分开。
- 不把“已含信息”当“用过信息”，不把“调用工具”当“正确使用”；机制结论依赖请求/返回/交付/引用与支持证据。
- 对“刚到上面”“那件设备”“最显眼台面”等多解题，修订指代或接受合理替代，不泄露答案属性。题干更改先给用户审核，旧题和旧分保留。
- 建立评分回归例：正确但无免责声明、不问数量却要求两项、额外错误身份、只重复题干、裁判虚构比较、诊断图误标memory、可回答问题的拒答被判满分。

## 鲁棒性底线与暂缓事项

保留现有失败可追溯、来源/版本校验、有限重试/轮数、预算、停止与因果隔离、安全门禁。不给这些门禁新增一个独立大项目；也不把“其他暂缓”理解为允许无依据结论交付。

暂不专项投入：换大模型、提并发、扩地图、扩大题量、重新调整所有措辞、完整导航/语音/UI功能、为个别失败逐题堆提示。时序与对象约束属于组织/检索主线，不另扩成一个万能推理系统。

1. 明确证据、片段、事件、候选实体的可修订契约及适配点，用合成在线前缀测试验证因果、重访不丢先后、分段不唯一和重启恢复。

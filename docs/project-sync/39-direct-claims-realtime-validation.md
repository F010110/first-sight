# 实时优化：直接事实协议、完整源时钟与持续压力测试

2026-10-31。用户要求持续优化至实时达标或遇到明确并发限制。本报告记录固定输入节奏下的事实处理能力，不把关系未决转为已确认，不将有限测试说成无限稳定性。

## 消除的必经开销

旧提取协议要求模型对每个观察重复生成facts、summary、顶层sourceIds和空memoryRefs，真实运行出现结构漂移。新`direct-claims-v1`只让模型输出`claims:[{text,sourceIds}]`，每条仍必须自己明确引用一个实际交付的观察，覆盖所有观察。程序校验后按引用分组，摘要仅连接原始claim文本；没有从缺失引用中猜测来源，也不接收字符串事实或未知ID。缺失观察仍失败，不自动付费修复。

成窗改为可配置1/2/4观察，提取工厂初始默认2，形成等待最多2秒；单观察实验无成窗等待。A按需、关系核查按需保持不变。提取输出预算700tokens，保留每观察1至2条、最多80字的事实能力，三摄原始PNG及哈希校验没有降低分辨率或跳图。

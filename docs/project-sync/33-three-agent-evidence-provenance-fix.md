## 修正内容

1. 原图直接引用仍用`sourceIds`，历史解释用`memoryRefs`（如`memory-v2`）。fact可以只引用原图、只引用历史解释、或同时引用两者；顶层必须覆盖各fact引用。版本引用必须已存在且源时间严格早于本次观察，禁止未来/自我引用。
2. 新增`three-agent-evidence.ts`：给模型的历史上下文仅含记忆版本、源时间、摘要、未验证标记和时间范围说明；不再把摘要内全部嵌套原图出处一股脑交付，避免抄作本次直接视觉证据。数据库仍保留原始引用链，不删除来源、不补写模型引用。
3. 工厂分别校验本请求实际交付的原图与记忆版本白名单，包括每条fact；数据库存在某图不等于本请求看过该图。
4. 复用既有`aliasedSpatialRequest`，模型只引用请求内S0/S1；白名单和原图回退ID也同步映射，未知别名拒绝，不猜测少零/近似ID。历史记忆版本不作为原图别名改写。
5. 输出协议不再让模型填写`basis`，程序按引用命名空间确定类别：多张原图仍是直接视觉，不是“混合记忆”。旧结果显式填写了不一致basis仍拒绝，不会悄悄覆盖它。每次提交必须至少有一条引用当前原图的直接检查，无法判断可以记录未知，不能只复述旧记忆。
6. 提示历史摘要只描述其过去时刻，不是新时刻位置预测；新场景不同不能自动推翻旧记忆。历史上下文精简到摘要，减少事实逐条复述。

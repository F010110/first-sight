## 错因分层

1. **工具契约**：episodeRef与memoryRef混淆，L07最终执行失败。系统拒绝伪引用是正确门禁，但反馈未能帮助模型及时恢复。
2. **召回与上下文组织**：完整时序问题词面与原描述不一致；候选可能只给出店外招牌，原事实却按描述变化被分到后续片段。不能由一次局部检索未命中宣布历史未记录。
3. **对象/事件解释**：模型先猜店铺类型再搜；或把相似地砖、多帧连续出现当不同访问及同一身份。时序、类别、访问事件、物理身份不是同一个概念。
4. **目标替换**：历史问题被当前图中的相似平台替代。图像真实、引用有效仍可能答错对象。
5. **评测局限**：自动裁判同家族，部分指代歧义，部分通道审查仍错误；分数不能替代实际检索轨迹检查。

## 本轮改动

- 新增`OrganizedExperienceMemory.sequence`及`memory.sequence`工具，只允许从实际已返回的经历引用展开。交付前一/当前/后一候选的代表与边缘原始事实，后续可facts/inspect。与问答不可变快照逐项核对。
- 跨录制及源时间间断的邻居不交付；按原有发生/可用双时钟过滤。
- 明确标注chronological-neighbors-only、confirmedEntry=false、confirmedSamePlace=false。没有新建已确认进入或同地点关系，没有用私有地图/题号/答案/时间切段。
- locate结果明确引用契约及后续检索动作；prompt和错误反馈区分experience经历引用与memory-v事实引用，禁止自动换引用。
- 通用店铺名词召回及拒绝照抄问题纳入本轮。提醒店外匹配不是店内证据，未指定类型不自行给查询加店型，历史目标不由当前相似对象代替。

这是增加可核查的检索路径，不是已完成可靠事件提取或跨经历身份识别。

# UnionCity下一步：因果、非唯一分段评测

## 样本接受与修订

用户接受整体样本，后续不再逐项审核；不将此表述为每帧人工验证。站内楼梯从播放30秒起算（源15秒），覆盖旧发布包28秒起点。修订记录：`data/annotations/unioncity-rerender-v2-user-acceptance.json`。当前按用户正在查看的2倍播放时钟理解30秒，两个时钟均记录，避免混用。原哈希绑定发布包不原地修改。

## 评测契约

42段是利用完整路线和离线证据整理的参考，不是在线Agent唯一正确的空间划分。不以段数、段ID、精确边界或标准地点名称的逐字匹配作为主准确率。允许合理合并、拆分、暂名及随后修订；不能要求Agent提前知道未见的下一场所。

Agent输入仅截至当前时刻已交付三摄、时间与允许的自身历史；地图、坐标、引擎实体名、未来图像、参考标注及答案仅供独立评分。展示时钟和源时钟分别保留，慢速运行结果不覆盖此前原速软实时测试。

## 下一阶段实施顺序

1. 先冻结输入可见性与评分规则，再建立带提问时刻的题目集；每题答案证据必须已在该时刻出现。
2. 覆盖当前观察、历史检索、空间关系/路线、重访和可观察事件；每个参考答案绑定图像/时间证据，而非仅引用段级物品清单。
3. 地点回答按可辨识指代、相对关系、路线一致性评分；合理粒度差异不扣分，未知和暂定命名允许。身份是否相同与名称是否相同分开。
4. E日志仅证明生成阶段输入重放；视觉Agent不能因拿不到按键/实体日志被判错。没有可见结果支持的“交互成功”不能成为确定答案。
5. 先离线检查因果边界、题目歧义、证据充分性及评分容错，再做有界运行。此计划本身不启动付费调用。

首轮不把动态重建当原始录像真值，也不把离线参考分段当Agent必须学出的唯一地图。

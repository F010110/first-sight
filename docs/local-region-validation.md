### Concrete rotation/revisit counterexamples

- W6 / W40: (x=4.0,z=3.75), yaw 0/180: scene-1 / scene-7.
- W7 / W39: (x=4.0,z=4.5), yaw 0/180: scene-2 / scene-6.
- W8 / W38: (x=4.0,z=5.25), yaw 0/180: scene-3 / scene-6.
- W13 / W33: (x=2.5,z=4.0), yaw 180/0: scene-3 / scene-4; W33 is unresolved, so its assignment must not be treated as verified.

Only 4/19 final endpoint-position pairs reuse an ID. Windows contain preceding motion, so these are endpoint diagnostics, not an independently measured recognition accuracy. The target was explicitly the last CURRENT frame, making these important identity-consistency counterexamples nonetheless.

### A protocol/association failure, not only model failure

Original W16 reason says the observer is now on the bathroom side of the doorway and this is a different activity region from the bedroom side. But contradictory identity/evidence fields cause the parser to return unresolved (confidence 0.59), and the provisional-hold policy keeps scene-3. W17 then confidently reuses scene-3 for bathroom fixtures and updates the description. This temporary association becomes a self-reinforcing identity history. W33 similarly recognizes a threshold change in its reason but remains provisionally associated with scene-4.

The reasoning text and structured identity fields must be reconciled explicitly. Suggested next fix: a single decision enum (same/known/new/unresolved), positive region-change evidence, rejection/reverification of contradictory combinations, and isolation of unresolved visit associations from confirmed identity evidence. Do not infer verified sameness from an unchanged provisional ID.

## Verdict

Seven final Places is a more moderate count, NOT proof of correct regions. Room purity 0.825 does not validate local-place identity. This run has no Spaces and no confirmed route edges. The later Flash-proposed provisional Space is a separate copied-memory experiment and does not retroactively validate this run.

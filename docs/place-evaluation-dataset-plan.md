# 地点评估数据：现成数据核查与扩采

2026-10-11。旧mini集只是开发smoke set，不能再用两个正例证明泛化改善。没有训练计划；数据用于评测。

## 现成数据结论

### Robot@Home：优先真实家庭结构评测

官方：https://mapir.isa.uma.es/robothome-dataset/

5套住宅、36个房间、81段序列、约75分钟；87,000+总观察中包括18,000+激光及69,000+ RGB-D图，不能称87,000张RGB。提供房间/对象实例标注与拓扑，适合跨房间误绑、对象查找和多视角检验。

限制：四摄为真实不同安装位姿，整体约180°，绝非目前模拟同光心±90°三面板。不能直接复用本项目的90°FOV/同光心几何假设。房间序列是否保留完整穿越、精确重访需下载后逐段核查；标签不直接提供床侧/入口等局部活动范围真值。官网提供分会话下载，本轮未下载，许可与再分发条款仍需核实。

### OpenLORIS-Scene：优先真实连续回访/困难外观

官网：https://lifelong-robotic-vision.github.io/dataset/scene.html
维护者下载与许可：https://github.com/lifelong-robotic-vision/OpenLORIS-Scene/blob/master/download.md
当前镜像：https://huggingface.co/datasets/shixuesong/openloris-scene

家庭、办公室、走廊等真实机器人序列；RGB、内参、轨迹、多次访问，有光照及环境变化。适合真实视频时序和回访稳定性。只用RGB识别；深度、里程计及GT隔离为评测信息。

维护页说明CC BY-ND 4.0，禁止未经允许再分发派生数据集；本地评测和公开代码/统计报告分开，不能把处理后图像当可自由发布。本轮查到2025年12月起旧Google Drive失效，应使用Hugging Face或百度镜像。已核查HF文件清单：home包18,974,105,600 bytes、office包10,618,337,280 bytes；有groundtruth.zip约11MB，但单独轨迹不能替代图像评测。没有声称已下载或导入。还没有局部活动区域标签，需要补审图标注。

## 现在正在构建的第一批

`sim/build_evaluation_captures.py`：3个已有ProcTHOR户型×2种沿途观察间隔=6段录制，每段2次成功完整折返；沿途每8/13次移动插入四次真实RotateRight，原地转一周后恢复路线朝向。每次动作端点保留原图，不插值视频充样本。采集失败记失败，截断单列。

输出 `run/sim/place-evaluation-captures-v1`；采集清单记录实际帧数、原地转向相邻正例候选数和标签状态。observe-every=1保证不再因为采样端点错位丢掉绝大多数同位置样本。此前录制与记忆不覆盖。

这6段共享3户型，路线也重复，不是6个独立环境或大量独立事件。val4/val5继续为开发；val3作为未用于当前参数设计的场景留出，两个interval不能分成训练/测试。只有一个留出户型仍不足以宣称可靠泛化。

## 标注与规模目标（不是已完成数量）

第一阶段每户型选至少10个不同观察足迹，标至少30对旋转/重访、20对不同核心、10项历史查找；以事件/位置分层抽样，不把所有相邻帧组合膨胀成独立样本。跨区域与区域内子范围混淆分级，边界点允许邻接归属。过门和透门共见物体负例必须人工看完整原图/实际轨迹，不能用room ID自动作全部活动区域标签。

扩大阶段目标≥10个不同环境、≥30段路线（加入支路、门口停留、遮挡，不只同一路线改观察间隔），≥300对稳定性、≥200对跨/内区域分离、≥100历史查找任务。至少一部分来自真实数据；同户型/同房屋的全部访问放同一split。场景没有足够覆盖就标缺项，不凑数或只报总帧数。

先冻结manifest、标签和计分版本，再在未参与参数设计的户型验证“原算法+局部几何正证据”。原始帧与标注说明一起可审计；AI单人审图必须标明，不冒称真人独立盲评。正式可信程度仍需真人抽检和分歧统计。

主报告：跨区域误合并事件/率、同足迹恢复、全部核心覆盖、历史查找完成；轻度子区域混淆单列；每环境逐项列，空样本无成绩。综合分只能辅助，不掩盖严重串组及漏覆盖。

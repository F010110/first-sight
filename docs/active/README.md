# 唯一活跃知识入口

更新：2026-11-02。状态：**有效 / 活跃 / 必须维护**。

本批文件替代散落文档的“当前设计/当前状态”职责；不是宣称算法已重写。先写清架构，再审计与恢复代码。本轮不改算法、不运行模型。

## 活跃白名单与阅读顺序

1. [01 空间记忆架构](01-spatial-memory-architecture.md)：用户确认的目标契约，含最早短期/长期分离与后续双模块设计。
2. [02 当前状态与下一步](02-current-state.md)：已经做过什么、哪里退化、禁止误报的结论。
3. [03 决定与不变约束](03-decisions.md)：决定层级、评测授权、模型、数据隔离。
4. [04 实现地图与差距](04-code-map.md)：候选代码在哪，哪些只是实验，不能按文件存在宣称接通。
5. [05 数据、运行与证据](05-artifacts-and-results.md)：原始数据、hash、冻结题集、失败、成绩的适用范围。
6. [06 评测与人工审核](06-evaluation.md)：裁判主评、硬指标辅助、人工对照，以及当前评测缺口。
7. [07 操作与其他项目资产](07-operations-and-assets.md)：服务、环境、安全、硬件与非主线研究。
8. [08 维护与历史溯源](08-maintenance.md)：持续更新规则、归档定义、已读范围和未读清单。
9. `source-catalog.json`：脚本生成的源文件目录/哈希/分类；**不是语义知识文件，不替代上面八篇**。

根 `AGENTS.md` 是强制维护入口。除此白名单以外的说明性文档默认全部归为历史参考，包括根README、TODO、旧同步区、旧产品/研究/应用/发布文档。历史“当前”只代表当时。没有物理删除或移动，路径仍可复现。

**分类不是停用代码：** `src/`、`scripts/`、`tests/`、运行Skill、原图、数据库和报告仍是实现或原始证据；是否启用由明确入口和运行事实决定，不因它们位于白名单外而作废。

## 核心防遗忘提醒

空间记忆 ≠ 图像描述数据库；持久Session ≠ 无限聊天；短期Context ≠ 从长期库自动拼出的摘要；保存成功 ≠ 空间判断成功；裁判分数 ≠ 人工认证；历史导航图 ≠ 当前空间模块已经具备的图。

# 设计理由与不可擅改的边界

本文件解释01架构中的要求，不是新增一套方案，也不表示功能已经实现。阶段结果及待办记入TODO；只有用户明确认可的架构变更才修改这里。

|设计要求|为什么需要|不能采用的替代方式|
|---|---|---|
|短期Context与长期记忆分离|工作上下文必须有界；长期经历不能因窗口过期丢失。长期能力需实际访问持久记忆才能检验|无限堆聊天；自动把全历史概览常驻prompt；把最近几条描述叫完整空间记忆|
|新观察先待判断，再维护当前位置|移动/转场后旧地点不能默认成立；用户需要真实的位置判断，不只是环境词句|沿用上一地点；从人工位置标签或裁判填位置；描述中抽一个地名冒充新推理|
|优先连续性，但暂定关联不等于确认|早期v1.1.0-test.1的SceneAgent区分same/known/new/unresolved：新建需正面变化证据，unresolved可保留provisional关联。用户要求先做好已有连续分组/重访复用|每窗重建地点；把转头/看不到旧锚点当换区；无条件继承旧位置；把暂定关联算成已证重访；为复用旧ID另加一次合并调用|
|独立当前感知与历史解释隔离|历史实验出现旧柜台替代街道、站台疑问跨场景残留；历史可能影响模型观察|把全历史猜测与当前原图混合生成直接事实；为了防污染删掉整个空间推理阶段|
|持续空间Agent维护状态|环境、空间关系、变化、关联与未决点需要随经历更新；单帧描述不会自动产生空间结构|只提取事实入库就标记空间处理完成；只在用户提问时临时补空间建模|

|已交付证据与历史看过分开|旧读回结果会污染下一场景；引用必须能对应本轮实际可用来源|永久保留旧检索权限；输出引用就当实际读取；调查Agent看图等同回答Agent看图|
|长期提交成功后才发布Context|下游必须读取耐久、一致的空间状态；独立提取乱序完成不能使空间状态越过失败前缀|数据库写失败仍发布位置；伪造Session/检查点；吞掉回调错误后声称全部完成|
|用户问答与空间生产分离|问题、猜测和答案不能变成下一次视觉事实；可重复问答不应重建空间记忆|问答写回空间库；静态fork代替持续空间模块；前题答案泄漏独立评测|

## 原因的历史来源

2026-11-04用户澄清：本轮地铁站内部可视为一个地点，原“地铁站台”只是过窄的名字。允许Agent在确认同一身份后有来源地更新名字，避免因最初暂名而不断拆ID，也避免把标签错误当空间身份错误；名字修订不覆盖历史。该批准不取消“看到同一地标不等于站在同一区域”，尤其街外人行道/车道及跨街仍需独立判断。物体分类/OCR质量暂缓处理，不因这一阶段暂缓而把猜测升级为事实。

2026-11-04用户批准三项收紧/放宽，原因分别记录：

- **强制实时＝不拖慢输入。** 实时系统的定义是来源按节拍进入，而不是Agent跑完后才继续投递；用`queue`阻塞投递把背压等待计入总时长，会让"实时"名不副实（本轮813实际投递跨度3290秒，其中大量是等待）。因此忙时改为跳过当次空间判断，把证据交给后继判断合并处理：这样既保住输入节拍，也不伪造早窗位置。不能用"跳过"降低证据要求或宣称逐窗覆盖。
- **地点粒度没有唯一答案。** 同一段街，可以一个地点，也可以按路段拆开；评审若把"合并/拆分不同"当错误，会把主观切分差异当成事实错误，掩盖真正的问题（声称的占据区域类别与图像矛盾）。因此评审只判“占据区域类别是否与证据矛盾”“是否完全无来源支持”，不再按参考切分粒度扣分。
- **本数据集只禁止“弃权式unknown”，保留boundary。** 用户判断本样本没有真正不清楚的窗口，单独unknown会掩盖应当完成的建模；但门口/街角这类真实跨区窗若被强制选一侧，会产生单侧归属错误，所以boundary（两侧区域、不认证已进入）保留为过渡判断。二者区别是：boundary断言“这一窗跨两侧”，unknown原本还可能表示“我不知道”。程序因此只拒绝裸unknown，接受unknown+boundary。
- **判断预算耗尽记为显式缺口，而不是整轮失败。** 强制实时下单个窗口的纠错轮次有上限，超过就只能二选一：伪造位置（禁止）或中止整轮（代价过大）。选择第三条：把该窗记为`judgment-budget-exhausted`跳过、单独计数并保留全部证据，沿用“跳过窗不算已判断”的语义；连续超过5次仍停止，避免用跳过掩盖系统性缺陷。代价是该窗没有位置贡献，报告必须把它与忙时跳过分开统计。

## 架构变更流程

2026-11-03用户批准：持续空间Session作为工作记忆主体，行为自动记录，模型预算触发压缩；结构化状态头仅作事务发布与恢复。理由是Agent需要记得自己的调查、失败和输出，不能只依赖应用摘取几条判断替代持续会话；历史消息仍不能冒充当前视觉证据。长期地点由Agent主动维护有来源的版本化档案。调度先跳过忙时调用机会并保留待处理观察，避免推测分支冲突；没有独立观察事实时等待或跳过，不用缺证状态充当完成。原始证据和旧运行记录不回写。

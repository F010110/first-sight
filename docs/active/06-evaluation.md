# 空间评测、裁判与人工复核

更新：2026-11-02。有效要求：**灵活裁判为主、硬指标辅助、人类最终审核**。目前只有已有状态评审实现，不是完整空间Agent能力闭环。

## 评测对象与顺序

1. 完整空间生产：确实执行01的空间判断、短期更新和长期空间写入，保存每时刻状态。
2. 结构审计：来源/图像hash、提交前缀、事件/知识时间、持久状态与Context一致、无未来/问答污染。
3. 标签驱动裁判：相同时刻的真实输出与位置标签比对，不让裁判替Agent补空间判断。
4. 人工审查差异、错误、未知、分歧及随机正确样本；独立记录决定。
5. 根据结果决定原15/37问答测试，再按原门槛考虑90题。不能步骤1没做却先评描述后放行。

## 主裁判的知识边界

Agent `qwen3.8-flash`，裁判 `qwen3.8-max-0902`；裁判额外真值是冻结位置标注/确定性派生关系。若给原图，那是原Agent本就能见的来源，不是额外隐藏答案。

位置、区域组织、历史关联与确定性表达分栏0–4、理由及精确原文引用。别名与合理表达允许，不逐字匹配地点名。标注观察者区域不等于全部可见视野。标签没有覆盖的视觉细节、连通、安全、精确坐标标“标准不足/需审核”，不能模型猜真值。

**未执行空间操作、执行后判断错、执行失败、裁判无效、标准不足分开。** 不适用不算满分或0分；但核心空间操作缺失意味着实现未完成，不能靠大量N/A绕过架构验收。分项显示全计划分母、有效评分项、不适用项与失败，不只报有效子集均分。

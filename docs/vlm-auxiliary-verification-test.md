# VLM辅助核验：双户型全候选试验

## 边界

普通视觉/短序列算法提出身份关联，VLM仅核验已提出的关联。不让VLM生成地图、从unknown创造关联或读评测标签。compatible只表示未发现矛盾，不是确认物理同一。unknown、错误JSON或调用失败保留原基线，另记待审。

明确透门远处对象与对象近侧的观察者关系冲突可以产生软否决；仅物体消失、左右面板变化、纹理差异不能否决。模型意见仍有错，不作为硬真值或导航授权。

## 范围

val-4新户型57观察，所有9个视觉节点内18对；val-5旧户型40观察，所有视觉节点内15对。共97观察、33个已合组对，固定提示，不按标签抽样、不跳过容易或困难对。比8对试验更完整，但仍只是两个开发户型的全候选测试，不是大规模跨场景基准。低覆盖意味着大量未知尚未被测；不声称检查了全部4656个跨两录制组合。

核验从两张三视图直接独立判断局部结构，不带此前感知描述（避免扩散幻觉），不提供位姿/room/action/组号。跨观察允许任意朝向与移动，面板不代表相同世界方向。

## 输出与对照

保留每次raw、结构化结果、错误和耗时。显式矛盾转成负关系，原非否决关系保持基线支持；分割器生成可撤销的修订建议，不修改原bundle。孤立观察保留unknown，不宣布新区域。求解违反证据会在输出中显示；必须人工查看每个否决，尤其旋转样本。

分别统计否决次数、未知、错误、延迟；val-4按冻结核心/边界标签比较串组、碎裂、覆盖；val-5用原关系标签比较误合并、误拆分、拒答。不能把不同标签标准汇成一个总准确率，不能把碎裂视觉节点等同于区域算法本身失败。


当前尚未接入在线关联控制器。本轮没有宽松阈值或pending补归属，因此不会解决未知覆盖；目的先确认辅助核验能否去错且不引入误拆。完成后才决定选择性触发规则。单次自报confidence不用于接受门槛。

## 实际结果：当前核验策略不通过

两批33次调用全部完成，无调用/schema错误、无unknown；总调用耗时约199秒（两批并行，不是总墙钟耗时或在线延迟）。不拒答不意味着可靠。

val-4：18对中11次否决。核心—核心否决4对：正确拒绝W7/W13、W7/W38的客厅/卧室错绑，但错误拒绝卧室内部W13/W38、W14/W17。其余7次涉及边界，需按允许邻接范围单列，不能全部称正确。特别是W13/W18、W9/W14、W9/W17、W20/W37在冻结标准中允许相邻内部归属；过度否决不符合边界宽容要求。

| val-4核心诊断 | 核验前 | 核验后 |
| --- | ---: | ---: |
| 混入不同区域核心的组 | 1 | 0 |
| 核心覆盖 | 17/44（38.6%） | 12/44（27.3%） |
| 有多个支持组的区域 | 3 | 2 |

碎裂数量下降部分源于成员退回unknown，不是恢复了统一区域。没有一个区域完整恢复；降低覆盖消除串组不是可用性通过。

val-5：15对均为此前同端点正例，错误否决W14/W32和W15/W31；同端点恢复15/19→13/19。39对局部标签诊断覆盖25/35→20/35。此处测试的基线是视觉身份节点，与人工3粗区域试验不是同一分组，不混用分数。

原图复核：val-5的W14/W32在卫生间内入口同位置，W15/W31在更内侧同位置；朝向反转后门由右面板换到左面板，VLM错误推断过门。val-4的W13/W38都是卧室内（先前小试验正确，本次却否决），W14/W17在床侧到卫生间开口接近段但仍属冻结卧室核心；模型把床/开口方位改变当作穿越。提示虽禁止这一推理，实际输出仍使用了它。

结论：辅助VLM能够发现目标错误，但单次二图否决泛化不稳，不能直接撤销关联。后续优先独立解析近侧地面/开口遮挡/遥见对象，时序或几何证据复核否决；无法确认的不同侧判断记待审。不要靠修改评测标签或追加提示后回测相同错例宣称通过。此批结果保存，不接入生产；需要未参与提示设计的新路线和样本验证。

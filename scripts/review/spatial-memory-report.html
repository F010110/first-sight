空间记忆：Context与长期数据库如何变化

本轮实际发现（来自保存记录，不是评分）

    ① 短期工作Context

    先选模型调用，查看当时真正收到的输入；再看提交后的真实Session。不是最近几条位置记录的模拟图。

    完整实际输入（包括system prompt、runtime和工具schema）
    本次原始模型输出 / 请求时延
    提交后Session：本次新增行为与结果
    提交后完整Session分支 / 压缩条目
    结构化发布/恢复检查点（不是完整工作Context）
    

    ② 长期记忆数据库
    地点 / 访问（累计）
    Agent主动维护的地点属性
    空间判断历史（累计）
    当前版本数据库投影原文
    

    ③ 当前输入与被跳过窗口的事实 / 原图
    

    ④ 整轮调用时间、失败与最终库
    完整性收据与用量（包括跳过和未知费用预留）
    最终归档事实表：与按版本绑定的来源视图区分
    最终数据库所有业务记录
    生产事件 / 失败原文
    说明与只读完整性

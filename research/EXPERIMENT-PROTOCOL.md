# 当前实验执行协议

用户最新执行顺序：先完成基础方法复现与首题失败审计，再考虑引入误差；暂停新的噪声／VIO／三摄批次。先确认完整原生链路、证据传递与答案评分，不以现有简化关联或单题错答作噪声结论。审计见 reports/minival-pilot-failure-audit.md。

模型控制：各方法的感知／描述／检索推理／评分后端分别审计。主实验统一qwen3.8-flash，不要求API提供原本地7B；标为统一后端适配。加入同后端直接历史图像／简单检索对照，以检验现代VLM是否已解决相关题目。模型不可用不冒称原模型复现。详见 reports/model-backend-audit.md。

补充优先约束：完整评测必须执行原生对象融合／更新、地图维护和快照检索，而非仅调用匹配函数。真实／估计器重力、初始速度／姿态、零偏／噪声及标定失配的分别定义见 [full-evaluation-and-sensor-errors.md](reports/full-evaluation-and-sensor-errors.md)。已有简化关联指标不作为完整方法成绩。

状态：用户确认开展；本文件规定执行与验收顺序，不代表实验已完成。
范围：所有新增改动位于 research/，不修改生产链路。此协议替代“先完成 FindingDory 再做噪声”的早期优先级。

## 1. 要回答的三个问题

1. 小幅传感器误差经 OpenVINS 后，是否造成空间记忆的对象／观察关联退化？
2. 内部关联退化后，检索和原生任务分数是否随之改变，还是评测对该类错误不敏感？
3. 原地转身或转身伴随小幅移动时，前／左／右三方向观察是否比前摄更能维持地点／证据关联？收益来自视觉覆盖还是多摄定位？

不预设三摄有效、不预设小噪声一定降分。3D-Mem／GraphEQA不一定含与First Sight相同的VLM地点身份模块，按各自原生关联机制测量，不强行把对象重复等同于地点拆分。

## 2. 方法与数据优先级

- 第一对象：3D-Mem，原生 A-EQA 和 GOAT-Bench，使用 HM3D 合法资产。仓库已有41／184问题子集及GOAT val_unseen，资产仍需准备。
- 第二批：Meta-Memory、First Sight；GraphEQA在成本核查后加入。各自先验证原生小样，再接公共输入；不将跨任务适配冒充原论文实验。
- FindingDory：后续补充历史交互／顺序任务，保留已有100 validation episodes元数据及配套矩阵，不作为当前首轮前置条件。不需要从零编题，但三摄／IMU新观察必须重新生成。
- HM3D不可用时明确记录阻塞；ReplicaCAD等替代场景只可用于管线验证，不命名为原版A-EQA／GOAT成绩。
- VLM统一 qwen3.8-flash，通过 QWEN_API_KEY / QWEN_BASE_URL 读取；不部署本地VLM。不输出或复制凭据。标注“统一API后端适配”。本地检测、分割、导航不是VLM替代，另记计算成本。

## 3. 端到端数据流

```text
连续可微真实运动轨迹 T_WI(t)
  ├─ 已知相机外参／曝光时间 → Habitat RGB-D
  ├─ 同一运动 → IMU理想角速度和比力 → 小幅噪声／偏置等
  └─ 仅评测侧保存真值
                    ↓
              实际 OpenVINS
                    ↓
        因果估计位姿＋时间／坐标系／质量
                    ↓
   3D-Mem等方法的投影、融合和位置检索入口
                    ↓
      内部关联 → 证据检索 → 任务结果
```

必须检查 world／IMU／camera坐标变换、相机光轴、重力、单位和时钟。不能把离散导航跳步直接二次差分为IMU；轨迹平滑后需重新渲染，且验证碰撞、可见性和任务仍成立。定位高频与VLM稀疏观察分离。

## 4. 分阶段验收

| 阶段 | 实际工作 | 通过标准 |
|---|---|---|
| E0 OpenVINS构建 | 独立无ROS构建、固定commit及依赖 | 可执行文件、退出码、完整日志；构建成功不是估计成功 |
| E1 官方仿真验证 | 跑通内建仿真并导出GT／估计状态 | 可对齐的时间戳轨迹、估计非GT拷贝、有限且合理的状态与误差 |
| E2 原生记忆小样 | 3D-Mem原生资产＋API后端 | GT位姿条件下完整任务、原始证据、官方适用评分可重跑 |
| E3 物理一致连接 | 同轨迹生成RGB和IMU，实际图像跟踪 | 时间／外参测试通过，图像来自同一轨迹，输出位姿确实进入方法 |
| E4 小误差配对 | 单因素及小幅组合噪声，固定轨迹／图像 | 多seed结果、三层指标、oracle负对照及失败日志齐全 |
| E5 三摄验证 | 先共享定位A/B，再多摄定位C/D | 等时间与等预算分别报告，不混合定位和覆盖收益 |
| E6 泛化 | 扩任务／未见场景／其他方法 | 冻结参数与预算后运行，不按三摄优势筛样本 |

E1可先做，因为不依赖HM3D；E2与资产准备可独立推进。E4正式系统结论必须建立在E3上。E1合成特征结果可作单独机制诊断，不能冒充E3。

OpenVINS内建视觉为合成特征而非RGB跟踪；官方run_simulation使用GT初始化。首轮保留时标注“已初始化追踪”，不声称验证初始化鲁棒性。无ROS模式需确认状态导出确实工作，必要的导出适配单独记录。

## 5. 小误差与变量控制

- 标准IMU：加速度计比力、陀螺仪角速度；每个轴均可注入，但先分因素后组合。
- 误差类型：测量白噪声、初始零偏、偏置随机游走；随后加入相机—IMU时间偏移、轻微内外参偏差。
- 标准OpenVINS不消费磁力计。磁航向若扩展，单列输入／融合方式与实验，不能以yaw扰动冒充磁力计。角加速度是轨迹量，不是独立陀螺仪输入。
- 首轮只用小幅档位，数值在E1依据实际配置单位审核后冻结，不能把未标定档位叫“真实设备参数”。比较低噪声参考及相邻小幅档位，不必追求绝对零噪声造成数值退化。
- 分开真实传感器参数和估计器假设：模型匹配／轻微失配两组。修改外参或时间时，不能同时把准确改动告知估计器而误称鲁棒性测试。
- 每个配置先使用相同三个预先固定seed作工程试跑；正式seed数与场景数依据试跑方差／预算决定，在测试前冻结。
- GT位姿是记忆上界；直接位姿扰动只作压力测试，不算原始IMU实验。全局共同刚体变换是负对照，不算地图退化。

## 7. 不能只看最终分数

| 层 | 必记指标 |
|---|---|
| 定位 | RPE、ATE及对齐规则、朝向误差、失效／初始化／恢复 |
| 内部表示 | GT实例对应下的拆分／错合并、重复对象、跨朝向观察关联、证据归属；First Sight另记地点错误拆分／合并 |
| 检索 | 正确证据召回、候选集合变化、位置近邻排名、错误肯定／拒答 |
| 任务 | A-EQA答案及官方适用评分；GOAT SR/SPL；后续FindingDory HL/LL及放松指标 |
| 资源 | 调用数、token、延迟、图像预算、运行时、失败与重试 |

固定图像／轨迹的回放先隔离记忆层；闭环探索后做，因其轨迹变化会引入额外变量。检查navmesh、GT位置、对象ID、路径规划和碰撞接口的权限边界；仿真真实状态可以供物理执行和评分使用，但不可暗中作为估计导航坐标输入。

配对报告四种结果：内部／任务都稳定；内部退化但任务不变；内部退化且任务下降；任务变化但内部未变化（进一步排查VLM随机性／导航）。区分几何不敏感语义题、空间／实例关系题和重访导航题。不能由一题无变化判定整个benchmark不敏感。

## 8. 产物与停止条件

每轮保存config、命令、版本／hash、数据许可／revision、seed、噪声单位、GT与因果估计、关键图像／关联、模型ID、usage、原始预测、评分和失败日志。配置相同尽量复用已缓存模型响应，不将缓存与新请求不加说明地混算。

不执行无限API重试；每轮先记录调用数和token上限，费用按实际usage及已核查价格估算，不能凭“flash”假定价格。遇到资产许可、坐标对齐、未导出状态、GT泄漏或运行失败，暂停该阶段并记录，不能继续出正式分数。

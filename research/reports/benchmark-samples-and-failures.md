# 官方样本与失败分析边界

## 样本来源

FindingDory 原论文 v1（https://arxiv.org/html/2506.15635v1）发布 100 validation episodes / 30 scenes、5876 validation task instances。60 是模板数量，不是 episode 数。官方 Habitat 数据说明见 `research/data/findingdory-metadata/README.md`。

原版复现使用已发布 episode、对象配置、任务及评分，补齐场景和对象资产后按官方经验采集流程回放／执行；不自行编题。离线历史数据另有发布，不能把 episodes.json.gz 当作已包含历史视频。三摄新视角、连续 IMU 与噪声是扩展采集，需维持任务有效性并另行标注，不能从现有单摄视频凭空补出。

本轮已取得同一固定 HF revision 的验证 episodes、viewpoints.npy、transformations.npy，文件大小和 SHA256 见 `findingdory-validation-inspection.json`。这些矩阵用于官方环境／评测，不得作为一般记忆模型的真值定位旁路。尚未下载完整场景或执行环境 reset。

## 已有论文实证，不是我们跑出的成绩

FindingDory v1 的分析：

- GPT-4o 27.3%、Gemini 2.0 Flash 25.7%、Qwen2.5-VL/Gemma 约13–16%的报告成绩对应该论文的高层评测讨论，不是我们的 API 模型成绩。
- 单目标空间关系任务困难；GPT-4o 该类14.5%。
- 多目标多数接近零；目标数量、顺序和覆盖均可失败，SFT 约20%，相应可达上界约99%。
- 能看见目标不等于选到满足距离／可见性约束的目标视点；正确目标也可能不是最近目标，损失 SPL。
- 更多抽帧不保证更好，冻结模型可能受无关上下文干扰。
- 高层正确后，低层 ImageNav 仍因目标图像分布偏移、提前停止、超时丢分。
- 历史帧动作空间存在可解性上限，例如未访问房间不能由任何已访问历史帧表示；不是记忆错误。

原文对放松指标的个别描述存在名称混用，解释时应以定义和代码为准：DTG-only 只看距离；semantic coverage 只看可见目标覆盖，不能互相颠倒。

## 待验证的方法局限假设

3D-Mem：几何对象关联／快照代表性受检测、遮挡、位姿及深度影响；不是完整事件档案。
Meta-Memory：描述及向量召回可能遗漏细节，观察位置不等于对象位置，空间邻域对漂移敏感，未原生覆盖完整交互顺序。
GraphEQA：检测与度量语义图误关联可污染层级；主动探索与导航会混入记忆评分；不是天然跨时对象版本库。
First Sight：视觉相似性及稀疏观察导致错关联或漏事件，序列不能提供独立米制约束。

这些是接口／表示层面的风险假设，尚无本项目 FindingDory 分数或错误占比。三摄可能改善覆盖、歧义与部分定位退化，不自动解决事件顺序、摘要丢失、推理、导航或共同漂移。

## 失分归因协议

记录：未观测 → 已观测未保留 → 已保留未召回 → 召回后推理错误 → 定位／关联错误 → 正确目标但导航失败 → 评分／动作空间不可达。

同时记录 HL-SR、HL-SPL、semantic coverage、DTG-only、LL-SR/LL-SPL。用 GT 位姿、共享估计位姿、单／三摄及统一低层执行器拆解，不将所有失败归因于 IMU 或记忆。

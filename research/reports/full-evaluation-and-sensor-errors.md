# 完整评测与物理误差：执行修订

## 已有结果的必要更正

此前 `run_3dmem_pose_association.py` 在匹配成功后只登记标签，没有调用原方法的对象融合／特征更新、周期去噪／合并及快照组织。故31→67、ARI 0.325等数字只属于简化的固定对象原型关联实验，不能作为完整3D-Mem结果，也不能由此断言任务分数下降。旧日志保留，不删除、不重命名为完整复现。密集采样只证明该简化实验在两种采样下有变化，不能排除其他实现混杂。

## 传感器层误差，不给最终位姿硬加漂移

冻结真实轨迹／真实传感器参数和估计器假设两套配置。不得同时把偏差告知估计器而抵消要测的误差。

| 用户关注因素 | 注入位置与区别 |
|---|---|
| 微小方向偏差 | 初始姿态／重力方向估计偏差，或相机—IMU旋转外参偏差；三者分别实验，不修改真实图像来迎合估计 |
| 零速度基准误差 | 初始速度估计偏差；另列ZUPT误触发／残余速度。不是加速度计的“零速度读数” |
| 重力实际与理论不同 | 仿真真实重力大小与估计器gravity_mag轻微失配；与倾角误差导致重力泄漏分开 |
| 设备精度限制 | 各轴角速度／比力白噪声、启动零偏、零偏随机游走；后续量化、比例因子、轴不正交及温度慢变有依据再加 |
| 同步／安装 | 曝光—IMU时差、抖动及外参微偏差；相机与IMU来自同一真实连续运动 |

标准OpenVINS没有磁力计输入，不将yaw扰动冒称磁力计误差。角加速度为运动导数，不是独立陀螺仪测量。噪声密度按采样时间正确离散；档位未经硬件标定只称敏感性测试。先小幅单因素，再小幅组合，多seed配对；不可为制造丢分而增大扰动。

初始状态由GT初始化的旧配置必须明确列为理想初始化参考，不能用它测试初始速度／方向估计错误。真实扰动配置与状态初始化适配要留独立diff，并核查没有GT再次覆盖。

# First Sight 科研工作区

本目录独立开展 FindingDory、基线复现及多摄／惯性误差鲁棒性研究，不修改生产链路。

- [实验计划](PLAN.md)
- [当前确认的实验流程与验收协议](EXPERIMENT-PROTOCOL.md)：OpenVINS → 3D-Mem原生评测 → 三摄对照；以此为执行优先级。
- [当前状态与已知阻塞](STATUS.md)
- `scripts/`：无模型调用的环境检查与复现工具。
- `reports/`：可追溯的环境／源码检查报告，不存密钥。
- `vendor/`：忽略的上游只读源码；不将其许可视为本项目许可。
- `envs/`、`data/`、`runs/`、`cache/`：隔离环境、数据、运行证据与缓存，默认忽略。

原论文设置的复现与 FindingDory 适配实验必须分开。环境检查、导入成功或玩具测试均不等于 benchmark 复现。

不自动启动付费模型、大规模下载、系统安装、设备采集或修改宿主 GPU／WSL 配置；必要时先记录需求与资源估算。
